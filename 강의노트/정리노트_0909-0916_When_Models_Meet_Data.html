머신러닝(ML)이란?

사람·사물 인식, 사람 말 알아듣기처럼 규칙을 손으로 짜기 어려운 문제가 많아요. ML은 선형대수 · 확률 · 수치최적화 · 통계를 써서, 데이터(경험)로부터 자동으로 배우는 프로그램을 만드는 방법이에요.

종류무엇이 주어지나하는 일
지도학습 (supervised learning)정답(라벨)이 달린 예시정답을 맞히는 규칙을 배운다
비지도학습 (unsupervised learning)라벨 없는 데이터데이터 속 "흥미로운 패턴"을 찾는다 (예: 비슷한 것끼리 묶기)
강화학습 (reinforcement learning)환경(world)과 상호작용하는 agentscalar reward(점수 신호)를 최대화하도록 배운다

요즘 AI ≈ DNN(Deep Neural Network) ≈ Deep Learning이라고 할 만큼 신경망이 중심이에요. Universal Approximation Theorem: 신경망은 (충분히 크면) 일반적인 함수를 원하는 만큼 가깝게 흉내 낼 수 있는 "일반 함수 근사기"라는 정리예요.

1. 데이터 · 모델 · 러닝

머신러닝의 3요소: 데이터 · 모델 · 러닝

📅 0909L01 s5
🧸 쉽게 말하면

머신러닝은 요리 배우기예요. 재료(데이터), 레시피(모델), 연습(러닝) 세 가지가 있어야 해요.

연습을 잘 했는지는 처음 오는 손님에게 요리를 내 봐야 알아요. 이 손님이 바로 한 번도 못 본 데이터(unseen data)예요.

📐 정식 버전

머신러닝 시스템의 세 가지 주요 구성요소 (three major components, L01 s5):

  1. 데이터 (Data): $\{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_N, y_N)\}$ — 입력 벡터와 출력(라벨)의 쌍 N개.
  2. 모델 (Models): deterministic function(함수) 또는 probabilistic model(확률 모델).
  3. 러닝 (Learning): training(학습)과 prediction/inference(예측·추론).

좋은 머신러닝 모델 = unseen(학습에 쓰지 않은) data에서 잘 동작하는 모델. ML 알고리즘 = training을 잘 해서 prediction을 잘 하는 것.

ML이 요즘 "임계점"을 넘은 세 요인: ① 인터넷·모바일이 만든 방대한 데이터, ② 그걸 처리하는 GPU·NPU 컴퓨팅 파워, ③ 최적화(학습 파라미터 튜닝) 기술. 데이터가 적으면 inference(추론)의 정확도가 크게 떨어진다.

오늘의 메인 레슨: 머신러닝은 귀납이다

📅 0909L01 s5
🧸 쉽게 말하면

탐정은 발자국(데이터)을 보고 범인(규칙)을 추리해요. 이렇게 증거에서 규칙을 찾아내는 게 귀납이고, 머신러닝이 하는 일이에요.

반대로 "규칙(수식)을 먼저 알고 데이터가 어떻게 나올지 계산하는 것"은 연역이에요. 우리가 지금까지 배운 과목들은 대부분 연역이었어요.

📐 정식 버전
연역 (deductive)귀납 (inductive) = 머신러닝
먼저 주어지는 것원리 · 수식데이터 (raw data)
하는 일수식으로 데이터(출력)를 예측하고, 어긋나면 노이즈로 해석데이터를 가장 잘 설명하는 수식(규칙)을 스스로 만들어 냄
예인덕터 $v = L \frac{di}{dt}$, 통신 $y(t) = x(t) * h(t) + n(t)$점들을 보고 "선형 관계일 거야" → $y = \theta_1 x + \theta_0$

통신·신호처리 식 $y(t) = x(t) * h(t) + n(t)$ 에서 $*$ 는 convolution, $h(t)$ 는 임펄스 응답, $n(t)$ 는 노이즈다. $h(t)$ 를 알면 입력 $x(t)$ 로부터 출력 $y(t)$ 를 예측할 수 있다.

  1. 데이터(파란 점)가 주어진다. 그림에서는 점이지만 실제로 점 하나는 $D$차원 실수 벡터다.
  2. 경향을 본다: x가 커지면 y도 선형적으로 커진다.
  3. 모델을 정한다: $y = \theta_1 x + \theta_0$.
  4. $\theta_0, \theta_1$ 을 최적화한다. 이 과정이 학습이다.

데이터 = 벡터

📅 0909L01 s6
🧸 쉽게 말하면

컴퓨터에게 사진 한 장은 아주아주 긴 숫자 줄이에요. 그중 중요한 숫자만 남기면 짧은 줄이 되는데, 이 짧은 줄을 "데이터"라고 불러요.

📐 정식 버전

데이터셋 표기

$$\mathcal{D} = \{(\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \dots, (\mathbf{x}_N, y_N)\}$$
  • 표기 관습 (convention): 볼드 소문자 $\mathbf{x}_n$ 은 벡터, $y_n$ 은 실수 하나(스칼라). 아래첨자 $n$ 은 n번째 데이터. 괄호로 묶은 $(\mathbf{x}_n, y_n)$ 은 짝꿍(세트)이다. 보통 입력은 $x$(벡터), 출력은 $y$(숫자)로 쓴다.
  • 빅데이터 = 데이터 개수 $N \to \infty$.
  • 차원: $\mathbf{x}_n \in \mathbb{R}^D$ — 실수 $D$개로 된 벡터. 예: $D = 3$ 이면 $\mathbf{x}_n = (x_{n1}, x_{n2}, x_{n3})$. 각 성분을 feature(또는 attribute, covariate)라고 부른다. $y_n$ 은 label(target, response variable, annotation)이라고 부른다.
  • 개/고양이 예시: 입력 사진은 (픽셀 수 × RGB 채널) 길이의 아주 긴 실수 벡터, 출력은 $y \in \{0,1\}$ (0 = 개, 1 = 고양이).

학습 방식

  • supervised learning: 라벨이 있다. 데이터가 $(\mathbf{x}_n, y_n)$ 쌍으로 주어진다.
  • unsupervised learning: 라벨이 없다. $\{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ 만 주어진다. 비슷한 것끼리 묶는 clustering이 대표적이다.

raw data vs feature vector: 수십만 개 실수로 된 고화질 사진(raw data)을 1비트 결정(개냐 고양이냐)에 다 넣는 건 낭비다. 줄이고 줄여 만든 feature vector를 이번 학기에는 "데이터"라고 부른다. 이 과정을 (data) preprocessing, feature extraction이라고 한다.

  • PCA = principal(주요한) + component(성분) + analysis(분석): 결정에 정말 중요한 성분만 체계적으로 압축한다. 선형대수의 SVD(특이값 분해)나 고유값 분해(EVD)로 low-dimensional approximation(저차원 근사)을 만든다.
  • feature map / kernel: 반대로 원래 feature를 비선형으로 조합해 더 높은 차원의 벡터로 만든다.
  • autoencoder 같은 딥러닝 모델도 데이터를 통과시키며 스스로 feature extraction을 한다("누가누가 압축을 잘하나?").

모델 = 수식 (정답은 없다)

📅 0909 · 0914L01 s5–7
🧸 쉽게 말하면

모델은 "데이터가 왜 이렇게 생겼는지 설명하는 이야기"예요. 그 이야기를 수식으로 쓴 거예요.

더 잘 들어맞는 이야기는 있어도, 딱 하나의 "정답" 이야기는 없어요. 모델은 정답은 없고, 더 좋은 것과 덜 좋은 것만 있어요.

📐 정식 버전

모델 = 수식. 데이터 밑에서 동작하는 기작(규칙)을 수식으로 쓴 것이다. 공학수학에서 RLC 회로를 미분방정식으로 푼 것도 모델이다.

  • deterministic (함수) 모델: 자연법칙처럼 정해진 공식이 있다고 본다. 예: $F = ma$, "이 데이터는 $y = ax + b$ 일 거야"(1차식), "$ax^2 + bx + c$ 일 거야"(2차식). 3차식·지수·사인·로그도 가능하다. 계수 값은 나중에 fitting해 봐야 알지만 꼴(모양)은 먼저 정한다.
  • probabilistic (확률) 모델: 불확실성(노이즈)까지 모델에 넣는다. → 다음 토픽.

모델 셋업 예: $\mathbf{x} = (x_1, x_2, x_3)$ 이라 두고 $y = 3x_1 + 5x_2 + 6x_3 + 0.6$ 이라고 "자신감 있게 질러야 된다". 그리고 "왜 그렇게 생각했어?"에 합리적으로 답해 가는 과정이 모델 셋업이다. (여기의 3, 5, 6, 0.6을 좋은 값으로 맞추는 게 러닝이다.)

큰 모델은 작은 모델을 포함한다: $ax^2 + bx + c$ 에서 $a = 0$ 이면 1차식이 된다. 모델 크기(파라미터 수)가 커질수록 표현력도 커진다. 1차식이 안 맞으면 2차, 3차로 바꿔 본다.

suppose vs assume (0914)

  • assume: 사실이 아닌 줄 알면서 그렇다고 가정하는 것.
  • suppose: 모르니까 그렇게 추측하는 것. 모델을 고르는 일은 suppose다. "뉴럴넷으로 해 보니 잘 예측되던데? 그러면 되는 거야."

그래서 모델은 correct/incorrect의 문제가 아니라 good/bad, 즉 취사선택(preference)의 문제다.

함수 모델 vs 확률 모델

📅 0909L01 s7
🧸 쉽게 말하면

과녁에 활을 쏘면 딱 한 점에만 꽂히지 않고 가운데 근처에 흩어져요. 그 흩어짐까지 설명하는 게 확률 모델이에요.

함수 모델은 "x가 60이면 답은 100!"이라고 점 하나로 말하고, 확률 모델은 "100 근처일 가능성이 제일 크고, 멀어질수록 드물어"라고 종 모양으로 말해요.

📐 정식 버전

noisy observation: 많은 데이터는 "진짜 효과(underlying effect) + 노이즈"로 관측된다고 본다.

  • 논리회로 실험: XOR 게이트의 1도 실제로는 5.3V, 6.2V처럼 전압에 노이즈가 낀다. 사진·언어 데이터에도 에러가 있다.
  • 동전 5번: 앞, 앞, 뒤, 뒤, 앞 → "앞면 확률 0.6, 뒷면 0.4구나"라고 판단하는 사고가 확률이다.
  • 노이즈를 어떻게 통계적으로 모델링하느냐에 따라 데이터 패턴의 해석이 달라진다. 그래서 불확실성을 모델에 넣는 확률 모델이 더 합리적이라고 여겨진다.
  • 이때 모델의 파라미터는 확률분포(PDF)의 파라미터다. 예: 가우시안 $\mathcal{N}(\mu, \sigma^2)$ 은 평균 $\mu$ 와 분산 $\sigma^2$, 실수 2개로 정해진다 → "실수 두 개를 최적화하는 문제".

x=60에서 비교 (unseen data $x = 60$ 이 들어왔을 때)

  • 함수(deterministic) 모델: 학습된 직선 $f$ 에 60을 넣어 $\hat{y} = f(60) = 100$ 을 내놓는다. 끝.
  • 확률(probabilistic) 모델: x가 주어졌을 때 y의 conditional PDF를 내놓는다. $$p(y \mid \mathbf{x}) = \mathcal{N}\big(y \mid f(\mathbf{x}), \sigma^2\big)$$ $x = 60$ 이면 평균 $f(60) = 100$, 분산 $\sigma^2$ 인 가우시안이다.

분포에서 답 하나 고르기: conditional PDF 자체가 "순수 베이지안의 결과"다. 여기서 숫자 하나를 고르는 기준(criterion)은 무엇을 중요하게 보느냐에 따라 다르다: MLE(가장 그럴듯한 값), MAP, MMSE(평균제곱오차 최소), Neyman–Pearson criterion 등. MLE와 MAP는 3절에서 정식으로 다룬다.

2. Empirical Risk Minimization (모델 = 함수)

Empirical Risk Minimization이라는 이름

📅 0914L01 s10
🧸 쉽게 말하면

"실제로 해 봤더니(empirical) 틀린 정도(risk)가 가장 작게(minimization)" 되도록 손잡이(파라미터)를 돌리는 거예요.

상상으로 "데이터는 이래야 해"라고 정하는 게 아니라, 가진 데이터를 진짜로 넣어 보고 얼마나 틀리는지 재서 그걸 줄여요.

📐 정식 버전

용어 해석: 강의 노트의 용어에는 뉘앙스가 다 있다.

  • Empirical = 실험적인. "모름지기 데이터는 이래야만 해"라고 머릿속으로 상상한 것이 아니라, 데이터를 실제로 넣어 봤다는 뜻이다.
  • Risk = 위험 요소, 즉 작을수록 좋은 부정적인 metric이다.
  • Minimization = 그것을 최소화한다.

정리하면: 함수 모델의 꼴을 먼저 suppose하고(파라미터는 아직 미지수), 현재 데이터를 가장 잘 설명하도록 파라미터를 최적화한다. 단, risk를 최소화하는 관점에서.

Predictor: ML 엔진은 보통 새 데이터의 정답을 예측하는 함수(predictor)다. 이 절에서 predictor는 deterministic 함수 $f(\mathbf{x}, \boldsymbol{\theta})$ 다. 학습 데이터는 $\{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_N, y_N)\}$ (supervised), $\mathbf{x}_n \in \mathbb{R}^D$, 파라미터를 모은 벡터가 $\boldsymbol{\theta}$ 다.

목표

$$\text{Find } \boldsymbol{\theta}^* \text{ such that } f(\mathbf{x}_n, \boldsymbol{\theta}^*) = \hat{y}_n \approx y_n, \ \forall n = 1, \dots, N$$
  • $y_n$ 은 데이터로 주어진 정답(라벨), $\hat{y}_n$ 은 튜닝된 모델의 출력이다. hat(^)은 추정치(estimate)를 뜻하는 관습이다.
  • 식의 뜻: "모델 출력 = $\hat{y}_n$ 인데, 이 $\hat{y}_n$ 이 정답 $y_n$ 과 비슷했으면 좋겠다."
  • regression, classification, PCA, 뉴럴넷, 딥러닝은 수학적으로 쓰면 모두 이것을 하는 것이다.

"for all"($\forall$)의 의미: $\mathbf{x}_1$ 을 넣었을 때 정확히 $y_1$ 이 나오도록 미친 듯이 튜닝하면, 같은 $\mathbf{x}_1$ 에는 완벽하지만 $\mathbf{x}_2$ 를 넣었을 때 $y_2$ 와 크게 다를 수 있다. 이것은 $\mathbf{x}_1$ 하나에 과적합된 나쁜 예측기다. 특정 데이터 하나가 아니라 모든 학습 데이터에 두루두루 그럴듯한 $\boldsymbol{\theta}^*$ 를 찾아야 한다.

가장 중요한 수식: affine 모델과 augmentation

📅 0914L01 s10
🧸 쉽게 말하면

입력마다 "중요도(가중치)"를 곱해서 다 더하고, 마지막에 기본 점수(bias)를 더하는 계산기예요.

기본 점수만 따로 떨어져 있는 게 귀찮으니, 입력 맨 앞에 숫자 1을 몰래 끼워 넣어요. 그러면 "1 × 기본 점수"가 되어 전부 한 번의 곱셈-덧셈(내적)으로 끝나요. 이걸 augmentation이라고 해요.

📐 정식 버전

원래 모델은 가중합에 bias를 더한 것이다: $f(\mathbf{x}_n, \boldsymbol{\theta}) = \theta_1 x_n^{(1)} + \dots + \theta_D x_n^{(D)} + \theta_0$.

  1. $\theta_0 = 1 \cdot \theta_0$ 이므로 데이터 맨 앞에 unit feature $x^{(0)} = 1$ 을 붙인다 (augmentation).
  2. $$\mathbf{x}_n = [1, x_n^{(1)}, \dots, x_n^{(D)}]^\top, \qquad \boldsymbol{\theta} = [\theta_0, \theta_1, \dots, \theta_D]^\top$$
  3. $$f(\mathbf{x}_n, \boldsymbol{\theta}) = \boldsymbol{\theta}^\top \mathbf{x}_n = \theta_0 + \sum_{d=1}^{D} \theta_d x_n^{(d)}$$ 누운 벡터 × 선 벡터 = 스칼라(내적).
  4. 데이터와 무관한 상수 $\theta_0$ 때문에 $f(\mathbf{0}) = \theta_0$, 즉 원점을 지나지 않을 수 있다. 그래서 linear가 아니라 affine 함수라고 부른다.

뉴런: $\hat{y} = \sigma\big(\sum_{i} w_i x_i + b\big)$. 여기서 $\sigma$ 는 sigmoid, ReLU 같은 activation function이다. DNN은 affine과 activation을 층층이 합성한 함수다.

데이터 행렬과 squared loss (김밥 말기)

📅 0914L01 s11
🧸 쉽게 말하면

김밥 재료(데이터 벡터)를 하나씩 눕혀서 차곡차곡 쌓아 두면(행렬), 한 번에 돌돌 말 수 있어요.

데이터 N개를 하나씩 계산하는 대신, 한 판에 모아 두고 "얼마나 틀렸나"를 한 줄의 식으로 계산해요.

📐 정식 버전

데이터 행렬 (대문자 볼드 = 행렬, 라벨은 빼고 입력만 모은 것)

$$\mathbf{X} := [\mathbf{x}_1, \dots, \mathbf{x}_N]^\top \in \mathbb{R}^{N \times D}, \qquad \mathbf{y} := [y_1, \dots, y_N]^\top$$

※ 교수님이 칠판에 처음엔 열벡터를 나란히 세운 D×N 모양으로 그렸다가, "여기 트랜스포즈가 들어가 있네요"라며 전치된 N×D 모양으로 정정했다 (0914 30:08). 각 행이 데이터 하나 $\mathbf{x}_n^\top$ 이다. augmentation(맨 앞에 1 추가)을 하면 열이 $D+1$ 개가 된다.

Empirical risk (average loss)

$$R_{\text{emp}}(f, \mathbf{X}, \mathbf{y}) = \frac{1}{N} \sum_{n=1}^{N} \ell(y_n, \hat{y}_n)$$
  • 이것도 정의(definition)다. 꼭 평균이어야 하는 건 아니고, 평균은 선택이다. 특정 데이터가 아니라 두루두루 잘 맞게 하려고 평균을 쓴다(학점 평점이 과목 점수들의 평균인 것처럼).
  • $\ell$ 은 loss의 L. 입력은 두 개: 정답 $y_n$ 과 추정치 $\hat{y}_n$. 훈련 중에는 정답이 있지만 없다고 치고 계산한 값이라 예측이 아니라 추정(estimate)이다.
  • loss는 $y_n$ 과 $\hat{y}_n$ 사이의 거리(distance)를 함수로 만든 것이다.

Squared loss ($y_n$ 이 스칼라이므로 norm 없이 차이의 제곱이면 된다. 딥러닝에서도 많이 쓴다)

$$\ell(y_n, \hat{y}_n) = (y_n - \hat{y}_n)^2$$

합에서 노름까지 (칠판 유도)

  1. $\hat{y}_n = \boldsymbol{\theta}^\top \mathbf{x}_n = \mathbf{x}_n^\top \boldsymbol{\theta}$ 를 대입한다: $$\frac{1}{N} \sum_{n=1}^{N} (y_n - \hat{y}_n)^2 = \frac{1}{N} \sum_{n=1}^{N} (y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2$$
  2. 행별로 풀어 쓴다: 1행 $(y_1 - \mathbf{x}_1^\top \boldsymbol{\theta})^2$, 2행 $(y_2 - \mathbf{x}_2^\top \boldsymbol{\theta})^2$, …, N행 $(y_N - \mathbf{x}_N^\top \boldsymbol{\theta})^2$.
  3. $\mathbf{X}$ 의 n번째 행이 $\mathbf{x}_n^\top$ 이므로, 벡터 $\mathbf{y} - \mathbf{X}\boldsymbol{\theta}$ 의 n번째 원소가 바로 $y_n - \mathbf{x}_n^\top \boldsymbol{\theta}$ 다.
  4. 유클리디안 norm의 제곱은 각 원소를 제곱해서 더한 것이므로, 합 전체가 norm 하나로 말린다: $$\min_{\boldsymbol{\theta}} \frac{1}{N} \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$$
  5. 여기서 $\mathbf{X}\boldsymbol{\theta} = \hat{\mathbf{y}} \in \mathbb{R}^{N \times 1}$, 즉 $\hat{\mathbf{y}} = [\hat{y}_1, \dots, \hat{y}_N]^\top$ 이다.

데이터 $\mathbf{X}, \mathbf{y}$ 는 고정이고, 바꾸는 것은 오직 $\boldsymbol{\theta}$ 다.

  • 체계적인 방법: 선형대수의 least squares, pseudo-inverse. → 다음 주 linear regression에서 배운다.

궁극 목표 = unseen data에 대한 risk 최소화 (true risk, expected risk)

$$R_{\text{true}}(f) = \mathbb{E}_{\mathbf{x}, y}\big[\ell(y, f(\mathbf{x}))\big]$$

새로운 $(\mathbf{x}, y)$ 에 대해 평균적으로 loss가 작기를 바란다. 하지만 미래의 데이터는 볼 수 없으니, 가진 데이터로 계산한 $R_{\text{emp}}$ 를 대신 최소화한다.

Overfitting과 Regularization

📅 0914L01 s12
🧸 쉽게 말하면

시험 문제의 답만 통째로 외운 학생(overfitting)에게 "너무 튀는 답은 벌점!"(penalty)을 주는 거예요.

벌점이 무서우면 학생은 억지로 외우지 않고, 무난하고 일반적인 풀이를 찾게 돼요. 벌점의 세기는 λ라는 손잡이로 정해요.

📐 정식 버전

Overfitting: 학습 데이터에 너무 가깝게 맞춰서(fit too closely) 새 데이터에 일반화(generalization)가 안 되는 현상. 해결책은 empirical risk에 penalty term을 더하는 것이다.

Regularized least squares

$$\min_{\boldsymbol{\theta}} \frac{1}{N} \|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \lambda \|\boldsymbol{\theta}\|^2$$
  • $\|\boldsymbol{\theta}\|^2$ = regularizer, $\lambda$ = regularization parameter = hyperparameter (학습으로 찾는 θ가 아니라 사람이 미리 정하는 값).
  • 모델 자체는 바뀌지 않는다. 모델은 여전히 affine $f(\mathbf{x}_n, \boldsymbol{\theta}) = \boldsymbol{\theta}^\top \mathbf{x}_n$ 이고, 바뀌는 것은 θ를 고르는 기준뿐이다.
  • $\lambda = 0$: penalty가 사라져 empirical risk만 최소화한다. 딱 과적합되기 좋다.
  • $\lambda = 1$ 처럼 λ가 있으면: 훈련 데이터에 가까워지려는 힘과, θ의 2-norm(원점에서의 거리)을 작게 하려는 힘 사이의 밸런스다. λ가 커질수록 θ가 원점 쪽으로 끌린다.

노름 (norm)

  • 2-norm의 제곱: $\|\boldsymbol{\theta}\|_2^2 = \sum_d \theta_d^2$ — 원점에서의 거리(의 제곱).
  • 1-norm: $\|\boldsymbol{\theta}\|_1 = \sum_d |\theta_d|$ — 파라미터를 자꾸 0으로 만드는 습성이 있어 sparse solution(0이 아닌 원소가 적은 해)이 나온다. 자세한 건 최적화 시간에 배운다.
  • p-norm: $\|\boldsymbol{\theta}\|_p = \big(\sum_d |\theta_d|^p\big)^{1/p}$

하이퍼파라미터 최적화: 1-norm이냐 2-norm이냐, λ를 얼마로 하느냐도 찾아야 한다. Gaussian Process를 이용하는 Bayesian Optimization이라는 방법이 있다(이름만 알아 두기).

Likelihood = 그럴듯함, 그리고 −log

📅 0914 · 0916L01 s14
🧸 쉽게 말하면

"이 동전이라면 이런 결과가 나올 법하네?" 하고 느끼는 정도가 likelihood(그럴듯함)예요.

여러 동전(파라미터 θ) 후보 중에서 지금 본 결과가 가장 그럴듯하게 나오는 동전을 고르는 게 MLE예요. 확률이 너무 작아서 비교하기 힘들 땐 log라는 돋보기로 작은 부분을 크게 확대해서 봐요.

📐 정식 버전

뜻: likely(~할 것 같은) + -hood(명사를 만드는 접미사, childhood처럼) = 그럴듯함. maximum likelihood는 "가장 그럴듯함"이다.

  • likelihood $p(\mathbf{x} \mid \boldsymbol{\theta})$ 는 데이터 $\mathbf{x}$ 를 고정하고 θ를 바꿔 가며 보는 θ의 함수다. θ에 대한 PDF가 아니다(θ로 적분해도 1이 된다는 보장이 없다).
  • 주어진 데이터가 그 파라미터로부터 나왔을 그럴듯함이 최대가 되는 θ를 학습 파라미터로 정한다.

Negative log-likelihood (NLL)

$$\mathcal{L}(\boldsymbol{\theta}) = -\log p(\mathbf{x} \mid \boldsymbol{\theta})$$

loss와 risk는 작을수록 좋은 "부정적 metric"으로 정의하므로 앞에 마이너스를 붙여 최소화 문제로 만든다. MLE는 θ를 바꿔 가며 $\mathcal{L}$ 을 최소화하는 θ를 찾는 것이다: $\arg\max_{\boldsymbol{\theta}} p(\mathbf{x} \mid \boldsymbol{\theta}) = \arg\min_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta})$.

왜 하필 log인가 (세 가지 이유)

  1. 단조증가 함수라서 값의 대소(우열)가 바뀌지 않는다. 그래서 log를 씌워도 argmax가 그대로 보존된다.
  2. 노이즈나 관측을 가우시안으로 모델링하는 경우가 많은데, log를 취하면 $\exp$ 가 사라져 계산이 쉬워진다.
  3. 확률이 0.0000…처럼 아주 작아지면 0.001과 0.002(두 배 차이)의 격차가 잘 드러나지 않는다. log는 1보다 작은 영역을 크게 늘려 준다(클로즈업, 위 그림).

※ 덧붙임: 확률밀도함수(PDF)의 값 자체는 1보다 클 수 있다. 1을 넘을 수 없는 것은 적분한 값(넓이)뿐이다.

latent parameter θ와 확률 모형을 "정의(define)"한다는 것

  • x가 주어졌을 때 y가 나오게 만드는 숨은 파라미터 θ를 latent parameter(latent variable, 숨겨진 변수)라고 부른다.
  • x와 y의 관계를 deterministic 함수로 둘지 PDF로 둘지는 내가 정하는 것이다. 그래서 "정의한다"고 말한다.
  • 예) 지수분포: $f(x) = \lambda e^{-\lambda x}$ ($x \ge 0$). λ에 따라 가파르게 또는 느리게 감소한다. 파라미터는 λ 하나다.
  • 예) 가우시안: $\theta_1 = \mu$, $\theta_2 = \sigma^2$ 로 두면 $f(x; \theta_1, \theta_2) = \frac{1}{\sqrt{2\pi\theta_2}} \exp\big(-\frac{(x - \theta_1)^2}{2\theta_2}\big)$ 이 되어, PDF가 θ의 식이 된다.

i.i.d.: 같은 공장에서 찍어낸 데이터

📅 0914 · 0916L01 s15
🧸 쉽게 말하면

같은 공장, 같은 기계에서 하나씩 따로따로 찍어낸 과자들이에요.

과자 하나가 다른 과자 모양에 영향을 주지 않고(따로따로), 모두 같은 기계(θ 하나)에서 나왔어요. 그래서 과자들을 잔뜩 모으면 그 기계가 어떻게 생겼는지 알아낼 수 있어요.

📐 정식 버전

i.i.d. = independent and identically distributed.

  • independent: $\mathbf{x}_1$ 은 짝인 $y_1$ 에만 영향을 주고 $y_2, y_3, \dots$ 에는 영향을 주지 않는다. 통계적으로 독립이면 $p(A, B) = p(A)\, p(B)$ 다.
  • identically distributed: 모든 데이터 쌍이 같은 PDF(같은 θ)에서 나왔다.
  • 데이터: $(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_N, y_N)$, $\mathbf{x}_n \in \mathbb{R}^D$. 입력들을 모은 집합을 $\mathcal{X}$, 정답들을 모은 집합을 $\mathcal{Y}$ 로 쓴다.

칠판 유도 (시작: $\mathcal{L}(\boldsymbol{\theta}) = -\log p(\mathcal{Y} \mid \mathcal{X}, \boldsymbol{\theta})$)

  1. independent → 곱: 데이터 쌍마다 따로 분해된다. 아직은 쌍마다 관계 파라미터가 다를 수 있으니 $\boldsymbol{\theta}_n$ 으로 둔다. $$-\log \prod_{n=1}^{N} p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta}_n)$$
  2. identical → θ 하나: 모두 같은 PDF이므로 첨자 n을 지우고 $\boldsymbol{\theta}$ 하나로 쓴다. $$-\log \prod_{n=1}^{N} p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta})$$
  3. log → 합: $\log(ab) = \log a + \log b$ 이므로 곱이 합이 된다.

최종 결과 (negative log-likelihood, log-likelihood loss라고도 부른다. 이것을 최소화하는 게 목표다)

$$\mathcal{L}(\boldsymbol{\theta}) = -\log p(\mathcal{Y} \mid \mathcal{X}, \boldsymbol{\theta}) = -\log \prod_{n=1}^{N} p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta}) = -\sum_{n=1}^{N} \log p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta})$$

왜 identical을 가정하나: 데이터 하나를 만들 때마다 PDF가 바뀐다면, PDF 하나를 추정하는 데 쓸 데이터가 1개뿐이다. 그러면 추정이 말이 안 된다(빅데이터가 아니다). 그래서 데이터 전체를 설명하는 PDF 하나를 두고 i.i.d.를 가정한다.

가우시안 노이즈면 MLE = Least Squares

📅 0914 · 0916L01 s15
🧸 쉽게 말하면

"오차는 종 모양(가우시안)으로 생겼을 거야"라고 믿으면, 가장 그럴듯한 선은 오차 제곱의 합이 가장 작은 선과 똑같아져요.

확률로 생각해서 풀어도, 그냥 "틀린 만큼 제곱해서 더한 걸 줄이자"로 풀어도 같은 답이 나와요. 두 길이 한 곳에서 만나요.

📐 정식 버전

가정(모델링)을 추가한다. 데이터가 affine 모델에 가우시안 노이즈가 더해져 나왔다고 suppose한다.

$$y_n = \mathbf{x}_n^\top \boldsymbol{\theta} + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2)$$

상수($\mathbf{x}_n^\top \boldsymbol{\theta}$)에 가우시안 확률변수를 더하면 여전히 가우시안이다. 평균만 상수만큼 이동하고 분산은 그대로다. 따라서 $y_n \mid \mathbf{x}_n, \boldsymbol{\theta} \sim \mathcal{N}(\mathbf{x}_n^\top \boldsymbol{\theta}, \sigma^2)$, 즉

$$p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\Big(-\frac{(y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2}{2\sigma^2}\Big)$$

A항 / B항 분리 유도 (i.i.d. 결과식에 대입)

  1. log 안의 곱을 둘로 나눈다: $$\mathcal{L}(\boldsymbol{\theta}) = -\sum_{n=1}^{N} \Big[ \underbrace{\log \frac{1}{\sqrt{2\pi\sigma^2}}}_{A} + \underbrace{\log \exp\Big(-\frac{(y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2}{2\sigma^2}\Big)}_{B} \Big]$$
  2. A항: n과 무관하므로 N번 더하면 $-N \log \frac{1}{\sqrt{2\pi\sigma^2}} = \frac{N}{2}\log(2\pi\sigma^2)$ 이다.
  3. B항: log와 exp가 상쇄되고, $\frac{1}{2\sigma^2}$ 은 n과 무관하므로 합 밖으로 뺀다.
  4. 결과: $$\mathcal{L}(\boldsymbol{\theta}) = \frac{N}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2} \sum_{n=1}^{N} (y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2$$
  5. 첫째 항은 θ와 무관하다. 최소화하는 θ(argmin)에 영향을 주지 않으므로 무시한다(칠판에서는 "=" 대신 "∝"로 바꿔 썼다).
  6. 둘째 항의 합은 벡터 $\mathbf{y} - \mathbf{X}\boldsymbol{\theta}$ 의 유클리드 노름 제곱이다: $\frac{1}{2\sigma^2}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$.

따라서 가우시안 노이즈 가정 하의 MLE = least squares. 2절의 squared loss에서 본 $\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$ 최소화와 같은 해를 준다. $y_n$ 은 실제 라벨, $\mathbf{x}_n^\top \boldsymbol{\theta} = \hat{y}_n$ 이니 결국 average empirical loss다.

노이즈 가정이 바뀌면: 이번 결과는 노이즈를 좌우 대칭인 가우시안으로 가정했기 때문에 나온 것이다. Laplace, exponential처럼 다른(비대칭 등) 노이즈를 가정하면 다른 loss 함수가 나온다.

왜 확률 모델이 대세인가: 상수는 delta PDF(한 점에 확률밀도가 모두 몰린 PDF)를 갖는 확률변수로 볼 수 있다. 불확실성이 0인 확률변수인 셈이다. 그래서 확률 모델은 deterministic 모델을 특수한 경우로 포함한다. 위의 결과처럼 deterministic 해법(least squares)도 확률 모델의 특별한 경우로 다시 얻어진다.

MAP: 데이터 + 선입견(prior)

📅 0916L01 s16
🧸 쉽게 말하면

데이터만 믿지 않고, "원래 이럴 거야"라는 선입견(prior)을 섞어서 판단해요.

선입견(점선)과 데이터가 말해 주는 것(파랑)을 합치면, 결론(초록)은 둘 사이 어딘가에 생겨요. 데이터가 많을수록 결론은 데이터 쪽으로 끌려가요.

prior (선입견)likelihood (데이터)posterior (결론)

📐 정식 버전

posterior = "사후" 분포. 죽은 후가 아니라 사건(관측)이 발생한 이후의 분포라는 뜻이다. 역시 조건부 확률(conditional probability)이다.

추론 문제의 틀: 나한테 주어진 것(데이터 $\mathbf{x}$)을 조건에 두고, 알고 싶은 것(파라미터 θ)을 앞에 두면 그것이 posterior $p(\boldsymbol{\theta} \mid \mathbf{x})$ 다.

Bayes 유도

  1. 조건부확률의 정의: $p(A \mid B) = \frac{p(A, B)}{p(B)}$
  2. 곱셈 규칙(multiplication rule)으로 분자를 푼다: $$p(\boldsymbol{\theta} \mid \mathbf{x}) = \frac{p(\mathbf{x}, \boldsymbol{\theta})}{p(\mathbf{x})} = \frac{p(\mathbf{x} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})}{p(\mathbf{x})}$$
  3. 분모 $p(\mathbf{x})$ 는 θ와 무관하므로 무시하고 비례(∝)로 쓴다: $p(\boldsymbol{\theta} \mid \mathbf{x}) \propto p(\mathbf{x} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})$
  4. max vs argmax: max는 "최대가 된 확률값이 얼마냐"이고, argmax는 "그 값을 최대로 만드는 θ가 무엇이냐"다. 우리가 찾는 것은 θ이므로 argmax를 쓴다.
  5. −log를 씌워 최소화 문제로 바꾼다(log는 단조증가, 곱은 합으로): $$\boldsymbol{\theta}_{\text{MAP}} = \arg\max_{\boldsymbol{\theta}} p(\boldsymbol{\theta} \mid \mathbf{x}) = \arg\min_{\boldsymbol{\theta}} \big[-\log p(\mathbf{x} \mid \boldsymbol{\theta}) - \log p(\boldsymbol{\theta})\big]$$ 앞 항 $-\log p(\mathbf{x} \mid \boldsymbol{\theta})$ 는 방금 한 MLE 항(NLL)이고, 뒤 항 $-\log p(\boldsymbol{\theta})$ 는 prior 항이다. 확률로 보면 prior가 곱해져 있는 셈이다.
  6. prior를 uniform(상수)으로 두면 뒤 항이 θ와 무관해진다. 이때 MAP = ML이다.

📎 가우시안 prior = L2 정규화

📅 0916L01 s12 · s16
🧸 쉽게 말하면

"θ는 작을 거야"라는 믿음(가우시안 prior)을 넣으면, θ가 커질 때마다 벌점 $\lambda\|\boldsymbol{\theta}\|^2$ 을 주는 것과 똑같아져요.

선입견을 넣는 것(MAP)과 벌점을 주는 것(정규화)은 이름만 다르고 같은 일을 해요.

📐 정식 버전

prior와 정규화의 연결

  • prior $p(\boldsymbol{\theta})$ 는 x를 관찰하기 전에 내가 가진 편견, 바이어스, preference다. "모름지기 θ는 이런 거 아니겠습니까?"
  • 이 선호가 2절 regularization의 벌점 항과 연결된다: $\min_{\boldsymbol{\theta}} \frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \lambda \|\boldsymbol{\theta}\|^2$. λ가 크면 "모름지기 θ는 벡터 크기가 작을수록 좋다"는 선호를 수식에 녹인 것이다.
  • 수업에서는 연결만 언급하고 "나중에 다시 썰 푸는 걸로"라며 수식 유도를 미뤘다 (0916 55:32). 유도는 아래 보충에 정리한다.
📎 보충 · 수업 미유도
  1. 가우시안 prior를 둔다: $$p(\boldsymbol{\theta}) = \mathcal{N}(\mathbf{0}, b^2 \mathbf{I}) \ \Rightarrow\ -\log p(\boldsymbol{\theta}) = \frac{1}{2b^2}\|\boldsymbol{\theta}\|^2 + \text{const}$$
  2. 가우시안 노이즈의 NLL(θ와 무관한 상수 제외)과 더하면 MAP 목적함수가 된다: $$\frac{1}{2\sigma^2}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \frac{1}{2b^2}\|\boldsymbol{\theta}\|^2$$
  3. 양수 $\frac{2\sigma^2}{N}$ 를 곱해도 argmin은 그대로다: $$\frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \frac{\sigma^2}{N b^2}\|\boldsymbol{\theta}\|^2$$
  4. 이것은 L2 정규화 식에서 $$\lambda = \frac{\sigma^2}{N b^2}$$ 로 둔 것과 같다.

해석: prior의 폭 $b$ 가 작을수록("θ는 0 근처라고 강하게 믿을수록") λ가 커진다. 데이터 수 N이 커지면 λ가 작아져 데이터의 목소리가 더 커진다.

참고: MML 8.3.2, 9.2.3. 복습문제 P5에서 직접 유도해 본다.

Model fitting: 과적합 · 과소적합 · 적정적합

📅 0916L01 s17
🧸 쉽게 말하면

옷 맞추기와 같아요. 너무 딱 붙으면 움직일 때 찢어지고(과적합), 너무 헐렁하면 몸에 안 맞아요(과소적합).

진짜 정답 모델(★)은 요정만 알아요. 우리는 "이런 모양일 거야"라고 정한 동그라미(모델 클래스) 안에서 최선을 찾을 뿐이에요.

📐 정식 버전

model fitting vs parameter fitting: training, learning, optimization, fitting은 모델 파라미터를 튜닝할 때 쓰는 말이다. Model fitting은 모델 자체를 바꾸는 것이다. 최선을 다해 파라미터를 튜닝했는데도 성능이 나쁘면 모델을 바꿔 봐야 한다.

  • $M^*$: x에서 y가 생성되는 진짜 과정. 요정만 아는 ideal unknown model.
  • $M_{\boldsymbol{\theta}}$: 내가 가정한 모델 클래스(linear, Gaussian, mixed Gaussian 등).
  • 초기값 $M_{\boldsymbol{\theta}_0}$ 에서 gradient descent 같은 최적화로 파라미터를 학습해 $M_{\boldsymbol{\theta}^*}$ 에 도착한다(★ 표시는 보통 optimal을 뜻한다). $M_{\boldsymbol{\theta}^*}$ 는 그 모델 클래스 안에서의 최선이다.
  • $M_{\boldsymbol{\theta}^*}$ 와 $M^*$ 사이의 빨간 거리가 클수록 나쁜 모델이다. 가까우면 좋은 학습을 한 것이다.

Overfitting (과적합)

  • 가진 데이터 점들만 기가 막히게 설명하는 추정을 한 경우다. 새 입력에서는 크게 틀린다. 예) 학습 점 근처가 아닌 입력 −2에서 −100을 예측한다.
  • 결과: unseen data에 대해 예상치 못한 큰 에러가 난다.
  • 원인: 데이터 개수에 비해 너무 복잡한 모델. 옛날에는 underfitting이 많았고 요즘은 overfitting이 더 흔하다(GPU를 많이 돌려 파라미터가 아주 많은 모델을 쓰기 때문).
  • 모델 크기 = 최적화할 파라미터 개수 (the number of parameters to be optimized). LLaMA, GPT 같은 모델이 "크다"는 것도 이 개수가 많다는 뜻이다.

Underfitting (과소적합): 데이터는 많은데 너무 단순한 모델("난 모르겠고 리니어로 해")을 쓴 경우다. 내 데이터조차 설명하지 못한다. 대신 모델이 안정적이라 어떤 데이터가 와도 적당히는 맞춘다(아주 잘 맞추지는 못한다).

Good fitting (적정적합): 데이터 크기와 모델 크기가 적절해서 현재 데이터와 앞으로 들어올 데이터를 모두 잘 설명하는 상태다. 컴퓨팅 자원의 양, 풀려는 문제의 크기, 손에 쥔 데이터의 개수를 모두 고려해 판단한다. 과적합을 막는 한 가지 도구가 정규화다.

Generative process: 데이터는 이렇게 만들어졌을 거야

📅 0916L02 s5
🧸 쉽게 말하면

케이크(데이터)를 먹어 보고 "이 레시피(생성 과정)로 만들었을 거야"라고 추측하는 것과 같아요.

레시피에는 정해진 재료(θ)도 있지만, 오븐 온도가 살짝씩 달라지는 것 같은 우연(노이즈)도 섞여 있어요. 그래서 같은 레시피로 구워도 케이크가 매번 조금씩 달라요.

📐 정식 버전

ML의 목적: 많은 ML task의 목적은 unseen event의 prediction과, expected risk를 최소화하는 decision making이다. 이를 위해 확률 모형을 많이 쓴다.

Generative process: 관측 데이터가 어떤 generative process(random process)로 만들어졌을 거라고 suppose하고 모델을 세운다. 예를 들어 affine 모델에 노이즈가 더해져 나왔다고 가정한다.

$$y_n = \mathbf{x}_n^\top \boldsymbol{\theta} + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2)$$

데이터는 온전하지 않다: 온도 측정값이나 사진은 물리 세계의 정보를 전부 담지 못하고, 소리에는 잡음이 낀다. 이 노이즈를 random variable(불확실성)로 가정하는 것이 probabilistic model이다.

칠판 설명

  1. $\mathbf{x}_n$ 은 주어진 값(given)이고 θ는 추정할 대상이다. 여기서는 둘 다 확률변수로 보지 않으므로 $c_n = \mathbf{x}_n^\top \boldsymbol{\theta}$ 는 상수다.
  2. 따라서 $y_n = c_n + \varepsilon \Rightarrow y_n \sim \mathcal{N}(c_n, \sigma^2)$ 이다. 가우시안에 상수를 더하면 평균만 $c_n$ 으로 이동하고 분산은 그대로다(3절 MLE = LS에서 쓴 사실).
  3. $c_n$ 은 θ의 함수다. 즉 θ는 평균을 바꾸는 방식으로 데이터에 영향을 준다. θ를 바꾸면 종 모양 분포의 중심이 움직인다.

벡터 버전(선형 변환 + 가우시안 노이즈)은 복습문제 P9에서 직접 풀어 본다.

Joint · Marginal · Latent

📅 0916L02 s5
🧸 쉽게 말하면

두 사람의 키를 각각 적어 둔 기록(marginal)보다, 둘이 나란히 찍힌 사진(joint)에 정보가 더 많아요.

사진이 있으면 각자의 키도 알 수 있고, "누가 더 큰지"처럼 둘 사이의 관계도 알 수 있어요. 따로 적은 기록만으로는 관계를 알 수 없어요.

📐 정식 버전
  • 확률변수의 PDF/PMF를 알면 그 확률변수의 평균, 분산, 함수의 기댓값 등 모든 것을 안다.
  • 변수가 둘 이상이면 joint 분포를 알아야 전부 안다(공분산처럼 둘 사이의 관계까지). 각자의 분포 $p(\mathbf{x})$, $p(\boldsymbol{\theta})$ 는 marginal이며 자기 자신의 불확실성만 설명한다. 그래서 probabilistic modeling에서는 가능하다면 joint distribution을 알아야 한다.
  • 주변화(marginalization): joint를 관심 없는 변수에 대해 적분하면 marginal이 된다. $p(\mathbf{x}) = \int p(\mathbf{x}, \boldsymbol{\theta})\, d\boldsymbol{\theta}$ (이산이면 적분 대신 합 $\sum_{\boldsymbol{\theta}}$).
  • θ는 확률론에서는 hidden parameter, ML에서는 latent variable이라고 부른다. 겉으로 보이지 않지만 x를 설명할 단서를 준다.

슬라이드에서는 joint distribution과 hidden parameter가 "encapsulate the key information"한다고 쓴다. 이 문장을 어떻게 읽어야 하는지는 아래 ⚠️에 있다. joint 표에서 marginal과 조건부확률을 직접 구하는 연습은 복습문제 P6에 있다.

🎙️ 교수님 한마디

인셉션 비유: "왜 꿈속의 꿈으로 들어가요?" 겉으로 보이는 현상이 x이고, 꿈 깊은 곳의 코어(기작)가 θ예요. θ를 바꿔 가며 현상이 어떻게 변하는지 보고 싶은 게 ML의 습성이에요. (0916 47:37)

머신러닝을 연구할 때 그런 생각은 없애야 된다니까. (0916 51:00)

θ가 원래부터 key information을 담고 있는 게 아니다. ML은 연역이 아니라 귀납이므로, θ가 key information을 머금도록 모델을 잘 설정하고 만들어 가고 최적화하는 것이다. 모델 가정이 잘못되면(빨간 거리) 최적화에 한계가 있다. 목표는 가진 데이터뿐 아니라 unseen data도 잘 예측하는 θ다.

Prior × Likelihood → Posterior

📅 0916L02 s5
🧸 쉽게 말하면

"원래 믿음(prior)" × "데이터가 말해 주는 것(likelihood)" = "업데이트된 믿음(posterior)"이에요.

원래 믿음과 데이터를 곱해서 합친 다음, 전체 합이 1이 되도록 나눠 주면 새 믿음이 돼요.

📐 정식 버전

joint의 분해: joint는 곱셈 규칙(multiplicative rule)으로 항상 인수분해된다.

$$p(\mathbf{x}, \boldsymbol{\theta}) = p(\mathbf{x} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})$$
  • $p(\boldsymbol{\theta})$ = prior(사전). x를 관찰하기 전에 내가 가진 편견, 바이어스, 선호(preference), 의도다. "모름지기 파라미터는 이런 거 아니겠습니까?"
  • $p(\mathbf{x} \mid \boldsymbol{\theta})$ = likelihood. 확률 수업에서 배운 forward probability, 또는 transition probability다. θ(원인)에서 x(관측)로 가는 방향의 확률이며 보통 주어지는 경우가 많다.

prior와 정규화의 연결: 정규화 식 $\min_{\boldsymbol{\theta}} \frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \lambda \|\boldsymbol{\theta}\|^2$ 에서 λ = 0이면 "편견 없음", λ가 크면 "θ는 작을수록 좋다"는 prior를 녹인 것이다. 가우시안 prior에서 λ가 정확히 어떻게 나오는지는 3절 보충(가우시안 prior = L2 정규화)에 있다.

posterior와 marginal likelihood: 조건부확률의 정의에 대입하고, 분모를 주변화로 쓴다.

$$p(\boldsymbol{\theta} \mid \mathbf{x}) = \frac{p(\mathbf{x}, \boldsymbol{\theta})}{p(\mathbf{x})} = \frac{p(\mathbf{x}, \boldsymbol{\theta})}{\int p(\mathbf{x}, \boldsymbol{\theta})\, d\boldsymbol{\theta}}$$
  • 분모 $p(\mathbf{x}) = \int p(\mathbf{x} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})\, d\boldsymbol{\theta}$ 를 marginal likelihood라고 한다. θ에 대해 적분했으므로 θ와 무관하다.
  • 그래서 θ를 찾을 때(MAP)는 분모를 무시하고 $p(\boldsymbol{\theta} \mid \mathbf{x}) \propto p(\mathbf{x} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})$ 로 쓴다. 분모는 posterior의 전체 넓이를 1로 맞추는 역할을 한다.

"위, 아래, 위, 아래… 팔짱 끼고 쳐다보면" 분자도 joint이고 분모도 joint예요. "왜 꼭 저렇게 합니까?" → "엔지니어링적으로 효과적"이니까요. joint 함수 하나만 계산하면 분자에 그대로 쓰고, 적분해서 분모에도 쓸 수 있어요. (0916 55:38–58:59)

ML vs MAP vs Fully Bayesian

📅 0916L02 s6
🧸 쉽게 말하면

장군님은 "그래서 앞이야, 뒤야?"라며 단답을 원해요(ML·MAP). 엔지니어는 분포 전체를 보고해요(Fully Bayesian).

단답은 듣기 편하지만 정보가 버려져요. 분포 전체는 설명이 길지만 "얼마나 확실한지"까지 담고 있어요.

📐 정식 버전

예측 문제: 러닝이 끝난 뒤, 데이터셋 $\mathbf{X}$ 가 주어졌을 때 unseen data에 대한 사건 A를 예측한다: $P(A \mid \mathbf{X})$. 예) 새 사진이 개인지 고양이인지, 수신 신호에 재밍(jamming)이 있었는지를 분류하는 문제.

세 가지 답

  • ML: 데이터만 보고 θ를 하나 고른 뒤 그 값으로 예측한다. $$\text{ML: } P(A \mid \mathbf{X}) \approx P(A \mid \boldsymbol{\theta}_{\text{ML}}), \quad \boldsymbol{\theta}_{\text{ML}} = \arg\max_{\boldsymbol{\theta}} P(\mathbf{X} \mid \boldsymbol{\theta})$$
  • MAP: prior까지 반영해 θ를 하나 고른다(3절 MAP). $$\text{MAP: } P(A \mid \mathbf{X}) \approx P(A \mid \boldsymbol{\theta}_{\text{MAP}}), \quad \boldsymbol{\theta}_{\text{MAP}} = \arg\max_{\boldsymbol{\theta}} P(\boldsymbol{\theta} \mid \mathbf{X})$$
  • Fully Bayesian: θ를 하나로 결정하지 않고 posterior 분포 전체를 사용한다(posterior predictive). 성능은 Fully Bayesian이 가장 좋다.

ML과 MAP은 "≈"다. 분포 전체 대신 점 하나로 근사했기 때문이다.

🎙️ 교수님 한마디

장군님 비유(확률 수업에서 자주 쓴 비유): 장군님은 복잡하고 긴 말을 싫어하고 Yes/No 단답을 요구해요. 엔지니어와 데이터 사이언티스트는 "원재료"인 분포 전체를 가지고 있어요. Fully Bayesian은 엔지니어가 좋아하는 방식(복잡하지만), ML과 MAP은 단답을 원하는 장군님이 좋아하는 대답이에요. (0916 60:40–69:25)

0909 수업의 대령 일화("숫자로 얘기해 주세요")와 같은 이야기예요. 분포를 알아도 단답을 요구받으면 가장 그럴듯한 값 하나를 말하게 돼요.

동전으로 보는 세 가지 답

📅 0916L02 s6
🧸 쉽게 말하면

동전을 10번 던져 앞면이 2번 나왔어요. 다음에 앞면이 나올 확률은 얼마일까요?

  • "데이터만 믿는 사람": 10번 중 2번이니까 0.2.
  • "동전은 원래 반반이라고 믿는 사람": 그래도 0.5.
  • "둘을 섞는 사람": 그 사이인 약 0.3.
📐 정식 버전
  • Fully Bayesian: "앞면일까, 뒷면일까?"라는 질문에 한 학생이 "앞면 0.5, 뒷면 0.5"라고 답했다. 하나를 고르지 않고 PMF 자체를 보고했으므로 Fully Bayesian식 답이다.
  • ML: 10번 중 앞면 2번이 관측됐으므로 앞면 확률 θ = 0.2로 추정한다. 반반(θ = 0.5)이라면 binomial 분포의 peak는 앞면 5번에 선다. 관측값(앞면 2번)에 peak가 서는 binomial을 만드는 θ가 0.2다. 장군님께는 "뒷면입니다"라고 답한다. 교수님은 "미분해 보면 나오거든요"라며 계산을 미뤘다 → 아래 보충에서 유도한다.
  • MAP: 데이터만 믿지 않고 "모름지기 동전이면 반반이어야 되는 거 아니야?"라는 prior를 섞는다. 그러면 앞면 확률은 0.2와 0.5 사이, 0.3 정도가 된다. 교수님은 "정확하게 어떻게 반영했는지는 나중에 설명할게"라고 했다 (0916 68:15).
🎙️ 교수님 한마디

머니볼: 오클랜드 야구팀이 데이터 사이언티스트를 활용한 이야기를 다룬 영화예요. 데이터만 보고 판단하는 사람의 대답이 ML이에요. (0916 60:40–69:25)

야구 코치 vs 데이터 사이언티스트: 선수 출신 코치는 "내가 해봐서 아는데 어제 술 먹은 거다, 혼내면 다음엔 잘 던진다"고 하고, 데이터 사이언티스트는 "이미 꺾였다, 구속이 안 나온다"고 해요. 교수님 결론은 "온전한 솔루션은 항상 그 사이에 있다." 경험(prior)과 데이터를 섞는 것, 이게 MAP의 직관이에요.

📎 보충 · 수업 미유도

ML 유도 (N = 10, k = 2)

  1. likelihood는 binomial이다: $p(k \mid \theta) = \binom{N}{k} \theta^{k} (1-\theta)^{N-k}$.
  2. log를 씌운다: $\ell(\theta) = \log\binom{10}{2} + 2\log\theta + 8\log(1-\theta)$
  3. 미분해서 0으로 둔다(첫째 항은 θ와 무관): $$\frac{2}{\theta} - \frac{8}{1-\theta} = 0 \ \Rightarrow\ \theta_{\text{ML}} = 0.2$$ 일반적으로 $\theta_{\text{ML}} = \frac{k}{N}$ 이다.

MAP 유도 ("반반" prior를 Beta 분포로 표현)

  1. prior를 $\mathrm{Beta}(\alpha, \beta)$ 로 둔다: $p(\theta) \propto \theta^{\alpha - 1} (1-\theta)^{\beta - 1}$. $\alpha = \beta$ 이면 0.5를 중심으로 대칭이고, 값이 클수록 "반반"을 강하게 믿는 것이다.
  2. posterior ∝ likelihood × prior: $p(\theta \mid k) \propto \theta^{k + \alpha - 1} (1-\theta)^{N - k + \beta - 1}$, 즉 $\mathrm{Beta}(\alpha + k, \beta + N - k)$ 다. prior와 posterior가 같은 Beta 꼴이다.
  3. prior Beta(4, 4)이면 사후분포는 Beta(6, 12)이다.
  4. posterior의 봉우리(log를 미분해서 0)가 MAP이다: $$\theta_{\text{MAP}} = \frac{k + \alpha - 1}{N + \alpha + \beta - 2} = \frac{5}{16} = 0.3125$$
  5. 참고로 Fully Bayesian 예측값은 posterior의 평균 $\frac{6}{18} = \frac{1}{3}$ 이다(posterior predictive).

연결: 복습문제 P8(Beta prior의 posterior와 MAP), 복습문제 P10(미분으로 극값 찾기).

Posterior predictive와 조건부 독립

📅 0916L02 s6
🧸 쉽게 말하면

하나만 골라 말하지 말고, 가능한 모든 θ의 의견을 믿는 만큼 가중평균해서 예측하자는 거예요.

θ = 0.2라는 친구, θ = 0.3이라는 친구, θ = 0.5라는 친구가 있으면, 더 믿을 만한 친구의 말에 더 큰 무게를 줘서 평균을 내요.

📐 정식 버전

분포를 요약하는 방법: θ의 분포가 연속 곡선으로 나오면, 장군님께 그림을 그려 가며 설명해야 해서 말이 길어진다.

  • 가우시안으로 가정하면 파라미터 두 개(평균과 분산)로 요약된다. 예) "평균 7.8, 분산 3.2인 가우시안입니다." θ처럼 값이 [0, 1] 범위라면 Beta 분포로 요약하는 것이 어울린다.
  • 봉우리가 여럿이면 가우시안 여러 개의 가중합, 즉 mixture로 요약한다: $\sum_k \pi_k \mathcal{N}(\mu_k, \sigma_k^2)$. 이 모델은 학기 말에 EM(Expectation-Maximization) 알고리즘에서 다룬다.

posterior predictive 유도

  1. θ를 끼워 넣었다가 적분으로 없앤다(주변화를 거꾸로 이용): $P(A \mid \mathbf{X}) = \int P(A, \boldsymbol{\theta} \mid \mathbf{X})\, d\boldsymbol{\theta}$
  2. 곱셈 규칙으로 joint를 조건부 × posterior로 나눈다: $\int P(A \mid \boldsymbol{\theta}, \mathbf{X})\, P(\boldsymbol{\theta} \mid \mathbf{X})\, d\boldsymbol{\theta}$
  3. θ가 주어지면 $\mathbf{X}$ 는 A에 대해 더 알려 주는 것이 없으므로 $P(A \mid \boldsymbol{\theta}, \mathbf{X}) = P(A \mid \boldsymbol{\theta})$ 이다. 한 줄로 쓰면: $$P(A \mid \mathbf{X}) = \int P(A, \boldsymbol{\theta} \mid \mathbf{X})\, d\boldsymbol{\theta} = \int P(A \mid \boldsymbol{\theta}, \mathbf{X})\, P(\boldsymbol{\theta} \mid \mathbf{X})\, d\boldsymbol{\theta} = \int P(A \mid \boldsymbol{\theta})\, P(\boldsymbol{\theta} \mid \mathbf{X})\, d\boldsymbol{\theta}$$
  4. 이것이 posterior predictive distribution이다. "θ의 예측 $P(A \mid \boldsymbol{\theta})$"를 "θ를 믿는 정도 $P(\boldsymbol{\theta} \mid \mathbf{X})$"로 가중평균한 것이다.

마지막 등호의 근거는 조건부 독립이다: $P(x_1, \dots, x_N, A \mid \boldsymbol{\theta}) = \prod_{i=1}^{N} P(x_i \mid \boldsymbol{\theta}) \cdot P(A \mid \boldsymbol{\theta})$. θ가 주어지면 관측 데이터들과 새 사건 A가 서로 독립이다. 즉 θ가 주어지면 X는 A에 대해 더 알려 주는 것이 없다(i.i.d.와 같은 생각).

위젯과의 연결: 위 동전 위젯의 "다음에 앞면 나올 확률"이 바로 이 값이다. 동전의 경우 $P(A \mid \boldsymbol{\theta}) = \theta$ 이므로 posterior Beta(k + a, N − k + a)의 평균, 즉 $\frac{k + a}{N + 2a}$ 가 된다.

연속 곡선을 말로 설명하는 건 "everybody dislikes this." 그래서 가우시안이나 mixture처럼 파라미터 몇 개로 요약해서 보고해요. (0916 69:27–71:32)
