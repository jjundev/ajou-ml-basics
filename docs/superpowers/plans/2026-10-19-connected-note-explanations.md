**Goal:** 이번 학습 대화에서 효과가 확인된 설명법을 작성 지침에 반영하고 1014·1019 정리노트 HTML과 대응 MD에 시범 적용한다.

**Architecture:** 기존 ml-review-pack의 큰 그림·본문·리뷰 지침을 확장한다. 첫 토픽에서 결과 사이의 관계를 보여주고, 상세 본문은 이미 아는 결과를 다음 계산에 재사용하도록 수정한다. 생성기·스키마·템플릿은 유지하고 노트별 검증을 통과한 HTML·MD 쌍만 반영한다.

**Tech Stack:** Markdown 지침, 기존 HTML/TeX, Python 표준 라이브러리 검사기, 기존 KaTeX·브라우저 검증 도구.

**Spec:** 이 파일의 [설계 기준](#설계-기준). 2026-10-19 대화의 grill-yourself 설계를 함께 담았다. 범위 #7은 후속 요청에서 변경되지 않아 추천안인 지침 개선 + 1014·1019 시범 적용을 기본 확정으로 기록한다. 실행 방식은 아직 선택되지 않았다.

## Global Constraints

- 설명의 중심은 “기존 결과에서 다음 결과로 연결하기”다.
- “수식 유도·개념 연결이 있는 부분에 적용하며, 모든 토픽에 같은 형식을 강제하지 않습니다.”
- “일반 공식 → 이번 문제의 대입 → 결과”를 끊기지 않게 설명한다.
- “수업 공식 / 동치인 재표현 / 보충 설명”을 등장 지점에서 구분한다.
- “설명을 무조건 길게 하는 것이 아니라, 식과 식 사이의 연결을 빠뜨리지 않는 것”을 목표로 한다.
- 수업의 행벡터 미분 관례를 유지한다. 벡터 자체는 열벡터이며 미분 결과는 행벡터다.
- 기존 토픽 ID·수식의 정확한 내용·위젯·PDF/인터랙티브 링크·출처를 보존한다. 표기 교체는 의미를 보존하고 HTML/MD를 동기화한다.
- 원자료로 수업 범위를 판단한다. 대화의 학습 반응은 설명 전략의 근거이며 교수님 발언이나 독립 풀이 숙달의 증거가 아니다.
- 관련 없는 토픽, 복습문제·답안 PDF·문제설명·영상·공유 vendor·다른 스킬은 변경하지 않는다.
- 이번 요청은 계획 작성이다. 실행 승인 전에는 계획 외 파일을 변경하지 않는다. 실행 중에도 자동 커밋·외부 게시를 하지 않고 작업별 커밋 명령만 제안한다.

## Review Focus

1. 기존 임시 기호 A,b와 A_g,q_g의 스케일 충돌: A=A_g/σ², b=q_g/σ²를 명시하고 공분산의 σ²을 잃지 않는다. Task 2의 수학 검산과 기호 검토로 확인한다.
2. 수업에 없는 연결을 강의의 직접 내용으로 오인: 동치 재표현임을 해당 문단에서 밝히고 원래 수업 공식도 남긴다. Tasks 1–3의 출처 대조로 확인한다.
3. 큰 그림을 추가했지만 토픽 이동으로 연결이 끊김: 도입은 한 곳에 두고 각 상세 토픽은 필요한 출발식과 링크를 제공한다. Tasks 2–3의 직접 해시 진입 검사로 확인한다.
4. 표본·잡음·예측 대상 혼동: θ의 사후공분산, 잠재 출력 분산, 새 관측 잡음을 구별하며 독립성·선형 가우시안 조건을 밝힌다. Tasks 2–3의 반례/극한 검산으로 확인한다.
5. 두 노트의 MD 위치 차이와 숨겨진 화면 누락: 실제 경로를 보존하고 모든 화면을 순회한다. Tasks 2–3의 쌍 검증·링크 검사·375px/1440px 두 테마 검증으로 확인한다.

## 설계 기준

사용자가 반응한 지점은 전체 흐름의 일괄 설명, 기억한 MAP 결과에서 FB 복원, ML 관측 모형 재사용, 익숙한 공분산 공식의 대입이었다. 따라서 다음 여섯 기능을 기존 레이어 안에 구현한다.

1. 전체 연결 먼저: 출발점·비교 축·최종 결과를 짧은 표로 제시한다.
2. 기억할 출발점: 이미 구한 식이나 필요한 기존 공식 하나를 상기한다.
3. 변경점 비교: 새 가정에 따라 바뀌는 항과 그대로인 항을 보여준다.
4. 한 줄씩 유도: 한 단계에 핵심 연산 하나와 짧은 이유를 둔다.
5. 다음 결과 연결: 결과를 다음 계산의 어느 자리에 대입하는지 명시한다.
6. 복원용 요약: 핵심 규칙과 대입 관계를 남긴다. 요약 패널에 본문에 없는 새 공식을 넣지 않는다.

임시 기호는 정의·원래 식·역할·임시 이름임을 함께 설명한다. 동치인 재표현의 정확성을 짧은 대수로 확인하며 새로운 가정/근사와 구분한다. 필수 연결은 접지 않고, 선택적 보충을 핵심 이해의 유일한 통로로 만들지 않는다. 모든 토픽에 비유·그림·세부 증명을 일괄 추가하지 않는다.

### Task 2: 1014 노트에서 ML·MAP·FB 결과 연결

**Files:** Modify 파일 구조의 1014 HTML·MD 쌍. 대상 토픽은 `s0-learning-map`, `s1-expand`, `s1-match`, `s2-weighted`, `s3-cheatsheet`. 필요한 인접 문장은 읽되 정규화·모형·기존 적분 유도를 전면 재작성하지 않는다.

**Interfaces:**
- Consumes: Task 1 지침, STT/1014 관련 전사, L03 p25 및 L04 p12–14, 기존 노트/대응 MD.

- [x] **Step 2: 도입을 보강한다.** 기존 첫 토픽에서 ML 점 추정 → MAP 점 추정 → θ 사후분포 → 관측 예측이라는 관계와 결과 종류를 한 표로 보여준다. 수업에서 이전에 배운 내용과 이번 목표를 구분한다. 새 큰 그림 토픽이나 개별 방법의 긴 증명을 중복 생성하지 않는다.
- [x] **Step 3: 상세 본문에 MAP→FB 재사용 연결을 쓴다.** 기존 이차식·계수 비교를 보존하고, 행벡터 미분으로 `θᵀA_g=q_gᵀ`를 거쳐 `A_gθ=q_g`가 되는 짧은 연결을 허용된 본문/보충 위치에 둔다. 이후 공통인수 `1/σ²`을 묶어 사후평균·공분산을 복원한다. 기존 `A=S_N⁻¹`, `b=S_N⁻¹m_N`와 새 기호를 같은 값처럼 쓰지 말고 `A=A_g/σ²`, `b=q_g/σ²`를 명시한다. 임시 이름이며 재표현이지 새 이론이 아님을 등장 지점에서 밝힌다.
- [x] **Step 4: 독립 계산으로 수학을 확인한다.** RUN에 표준 라이브러리 `fractions.Fraction` 기반 검산을 작성하고, 서로 다른 경로로 계산한 평균/공분산이 같음을 assert한다. 고정 입력은 `ΦᵀΦ=diag(3,2)`, `Φᵀy=(3,2)ᵀ`, `S₀=[[2,1/2],[1/2,1]]`, `m₀=(1,-2)ᵀ`, `σ²=2`. 기대 평균은 `(73/61,-35/61)ᵀ`, 공분산은 `[[30/61,4/61],[4/61,29/61]]`. 추가로 `m₀=0,S₀=b²I` 대입이 단순 사전 MAP 식으로 돌아가는지 확인한다. 미분의 각 항이 `1×K`인지 사람이 검토한다. 결과는 `evidence/math-check.txt`에 기록한다.
  검산 스크립트의 두 계산 경로 결과 이름을 아래로 고정한다. `F`는 `fractions.Fraction`, 벡터는 원소 tuple, 행렬은 행 tuple의 tuple로 표현한다.

  ```python
  assert mean_posterior == mean_map == (F(73, 61), F(-35, 61))
  assert cov_posterior == cov_from_map == ((F(30, 61), F(4, 61)), (F(4, 61), F(29, 61)))
  ```
