# 1102 개념 연결과 학습자 설명 기준 구현 계획

> 실행: 승인된 설계를 현재 세션에서 직접 구현한다. `executing-plans`의 연속 실행과 검증 원칙을 적용한다.

**목표:** 1102 노트의 고유벡터·P·직교성 연결을 보완하고, 관찰한 이해 방식을 앞으로의 노트 작성과 검토에 전달한다.

**구조:** 기존 설명 개선 경로로 HTML과 동반 MD만 갱신한다. 스킬의 references에 학습자 기준을 저장하고 메인·작성자·리뷰어 경로에 연결한다. 생성기·스키마는 변경하지 않는다.

**기술:** HTML/KaTeX, Markdown, 기존 Python 검사기·변환기, Playwright.

**설계 근거:** 현재 대화의 2026-11-06 수정 설계와 사용자의 후속 ‘구현해’ 승인.

## 공통 조건

- 대상 노트는 `복습노트/1102/정리노트_1102_PCA.html`과 `.pack/`의 대응 MD다.
- 기존 ID·수식·위젯·링크·학습 기록 동작을 보존한다. 문제·PDF·영상은 재생성하지 않는다.
- 예제는 설명용 재구성으로 표시한다. 교수님 발언과 수업 범위 근거를 만들지 않는다.
- 관찰·추정·미확인을 구별하고 설명 제공을 숙달로 기록하지 않는다.
- 커밋·푸시하지 않는다. 백업·초안·검증 증거는 이번 RUN에 둔다.

## 검토 초점

- ‘새 축’의 일반적 의미와 대각화에서 고유벡터로 제한된 P를 구별하는가.
- 단위 길이·직교·독립 조건이 뒤섞이지 않는가.
- 대칭행렬에서는 정규직교 기저를 선택할 수 있음과 임의 선택의 차이를 보존하는가.
- HTML·본문 요약·MD가 같은 조건을 전달하는가.
- lite·기존 수정·다른 주제에도 학습자 레퍼런스가 전달되며 무관한 예제는 복사하지 않는가.
