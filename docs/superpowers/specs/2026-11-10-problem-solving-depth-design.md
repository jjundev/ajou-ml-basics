# 문제풀이에 필요한 설명량 설계

## 의도와 확정 범위

사용자의 학습 목표는 “문제를 푸는 데 지장이 없을 정도로만” 아는 것이다. 필요한 개념의 역할·선택 이유·조건은 설명하되, 충분한 연결 뒤의 재증명·재검산·주변 지식은 필수 학습에 쌓지 않는다. 조건이나 숫자가 조금 바뀌어도 풀이 방법을 선택할 수 있어야 하며 단순 공식 목록으로 축약하지 않는다.

2026-11-10 채팅의 grill-yourself 설계를 구현한다. 사용자가 writing-plans로 진행하면서 별도의 범위를 지정하지 않았으므로 결정 #1은 권장값인 **1102·1104 정리노트 두 개**로 기본 확정했다. 결정 #2–#8도 이전 설계의 권장안을 따른다. 스킬 수정과 기존 정리노트 수정은 같은 기준을 공유하는 하나의 작업이다. 분류는 기존 흐름을 개선하는 bounded 작업이다.

## 완료 후 행동

- 강의 순서와 기존 화면을 유지하고, 핵심 개념·조건·대표 유도에 집중한다.
- 같은 원리를 재사용할 때에는 필요한 식과 기호 대응을 짧게 상기한다.
- 설명 부족과 과잉을 함께 검토한다. 과잉을 줄인 결과 필요한 연결이 없어지면 보완한다.
- 강의 핵심과 교과서 확장을 구분한다. 선정한 확장 문제를 근거로 강의 필수 범위를 거꾸로 넓히지 않는다.
- 작성자의 독립 검산은 수행하되 그 과정을 독자에게 전부 보여 줄 의무와 구별한다.

## 공통 제약

- 기존 자료 수정은 1102·1104 정리노트 HTML과 각각의 `.pack` 동명 MD로 한정한다.
- 기존 복습문제·문제설명·인터렉티브·PDF의 내용은 수정하지 않는다.
- 향후 작성 기준은 신규 생성·기존 설명 수정·lite에 동일하게 적용한다.
- 글자 수나 모든 토픽에 동일한 구성은 강제하지 않는다.
- 기호·목적·조건 연결은 유지한다. 이전 설명 요청을 철회한 것으로 해석하지 않는다.
- 기존 토픽 ID·연결되는 앵커·위젯·읽음 상태를 유지한다.
- 기존 강의 순서·좌우 패널·테마·폰트 크기·문제 및 인터렉티브 링크를 유지한다.
- HTML과 기존 대응 MD 및 요약을 함께 갱신한다.
- 필요한 풀이 판단·필수 유도는 본문에 남긴다. 반복은 삭제하고 독립적인 가치가 있는 내용만 선택 보충으로 둔다.
- 학습자 발언·이해 반응을 독립 수행이나 숙달의 증거로 확대하지 않는다.
- 스키마·공개 HTML 속성·생성기 인터페이스·문제설명 일곱 구역 계약을 새로 만들거나 변경하지 않는다.
- 이번 계획 작성은 구현을 포함하지 않는다. 실행 중의 커밋·푸시는 별도 사용자 지시가 없는 한 제안만 한다.

## 편집 판단

| 처리 | 판단 기준 |
|---|---|
| 본문 유지 | 방법 선택·조건 판단·실제 계산·답의 해석에 직접 필요 |
| 짧게 상기 | 앞에서 설명한 원리를 새로운 대상에 적용 |
| 선택 보충 | 별도의 증명·다른 접근법으로서 독립적인 학습 가치가 있음 |
| 삭제 | 같은 결론의 반복, 불필요한 주변 지식, 제작·검증 과정의 상세 |

검토 질문은 “이 부분을 빼면 어떤 풀이 판단이 어려워지는가?”이다. 생산용 기록에는 위치·짧은 원문·관련 풀이 판단·편집 결정·남길 최소 연결을 적는다. 이 기록과 학습자 이력은 독자용 노트에 넣지 않는다. ‘검토자가 이미 안다’와 ‘본문에 필요한 연결이 있다’를 구분한다.

증명 자체가 학습 대상인 경우에는 증명 경로가 필수이다. 1104의 고유기저 전개·교차항 소거·가중평균·상한과 도달 논리는 남기고, 여러 축의 공동 최적성이라는 추가 증명은 선택 보충으로 둔다. ‘증명은 모두 불필요’라는 규칙을 만들지 않는다.

## 스킬 수정

공통 정본은 `.claude/skills/ml-review-pack/references/problem-solving-depth.md` 하나로 둔다. `.agents/skills/*`는 `.claude/skills/*`를 가리키는 심볼릭 링크이므로 정본만 고친다.

- `ml-review-pack/SKILL.md`: 공통 기준을 생성·기존 수정·lite·감사 브리프에 전달한다. 기존 수정의 ‘수식 보존’은 의미와 계약 보존으로 구체화해 사용자가 허용한 불필요한 설명·수식 삭제와 충돌하지 않게 한다.
- `content-rules.md`: 강의의 모든 비유·인용을 싣는 요구를 필요한 설명 기능에 따른 선택으로 변경한다. 필수 설명을 간결성 때문에 생략하지 않는다.
- `manifest-guide.md`: 기존 `layers` 목록에서 필요한 레이어만 선택한다. 비유 단어를 의무적인 `required_terms`로 넣거나 분량을 채우지 않는다. 수업·풀이에 필요한 용어와 조건은 유지한다.
- `big-picture-first.md`: 도입은 목표·관계·결과·수식의 역할·주요 혼동을 짧게 안내한다. 상세 유도는 본문에서 한 번 한다. 기존 data-map 다섯 역할은 유지한다.
- `learner-reasoning-patterns.md`: 과거 설명 요청과 현재 최소 학습 목표가 함께 성립하도록 설명을 멈출 기준을 추가한다. 이 파일 외의 전역 메모리 파일은 수정하지 않는다.
- `staged-body.md`: 레이아웃만 수정할 때의 원문·수식 보존과, 내용 축약 요청 시의 선별 편집을 구분한다. 요약 내용도 수정된 본문과 동기화할 수 있게 한다.
- `problem-selection.md`: 교과서 확장을 수업 핵심으로 승격하지 않는다. 8~12문항 목표·명세표 비율을 맞추려고 수업 밖 개념이나 중복 심화를 억지로 더하지 않는다. 적합한 문항 부족 시 이유와 충족하지 못한 명세를 보고하며 자동 승인하지 않는다. 기존 문제 수·난이도 계약의 광범위한 재설계는 하지 않는다.
- `review-prompt.md`, `ml-note-audit/SKILL.md`, `ml-note-audit/references/audit-brief.md`: 기존 여섯 설명 결함 범주와 Critical/Important/Minor를 유지하고, 별도 ‘설명량 검토’ 절에 반복 유도·추가 계산·불필요한 선행 지식·보충의 필수화를 보고한다. 수학적 결함과 편집 권고를 섞지 않는다.
- `ml-problem-explain/SKILL.md`, `references/authoring.md`: 향후 해설에도 공통 기준을 연결한다. 일곱 구역과 소문항 solve/verify는 유지하되 단서·기준·답을 간결하게 연결하고, 새 숫자 문제나 오답 행렬 계산을 구역 채우기용으로 만들지 않는다. 독립 검산 증거는 evidence에 보관하고 독자용 verify는 필요한 점검에 집중한다. 이 계약상 본문 details는 금지이므로 선택 펼침을 강제하지 않는다.

## 기존 노트 수정

### 1102

대상: `복습노트/1102/정리노트_1102_PCA.html` 및 `.pack/정리노트_1102_PCA.md`.

- 큰 그림에서 상세 분산 유도·긴 주의 목록을 덜어내고 목표와 경로를 남긴다.
- 기둥·골프 등 같은 의미의 비유와 강의 대화 복기를 선별한다. 의미 전달에 필요한 그림·예시는 남긴다.
- `Ap_i=λ_i p_i → AP=PD → A=PDP⁻¹` 경로를 남기고 역방향 재유도를 축약한다.
- 푸리에의 델타함수·복소지수 수식과 모든 정방행렬과 교환하는 `cI` 분류를 덜어낸다. 곱 순서 주의는 남긴다.
- `V=bᵀSb`의 일반 합 전개를 기본 경로로 정한다. D=2 성분 계산은 이해를 돕는 최소 연결로 선별하고 일반 Cov(Ax) 규칙의 별도 장문 재유도를 반복하지 않는다.
- 최대 분산의 결론·필요한 직관을 남기고 완결 증명의 중복 상세는 선택 보충으로 정리한다. 위젯의 삼각함수·배각공식 재해석은 덜어낸다.
- `PᵀP` 각 칸의 의미, 고유벡터 조건, 중근과 대각화, Gram–Schmidt 목적·사영·고유공간 및 직교성 보존 연결을 남긴다.

### 1104

대상: `복습노트/1104/정리노트_1104_PCA_Part2.html` 및 `.pack/정리노트_1104_PCA_Part2.md`.

- `s0-directions-joint`의 여러 축 공동 최적성은 짧은 결론과 선택 보충으로 전환한다. 필수 순차 선택 단계 수·이동 링크를 실제 본문에 맞춘다.
- 헤시안·양의 정부호를 통한 유일성 증명을 덜어내고 정규방정식과 정규직교 조건에서 좌표를 얻는 연결을 남긴다.
- 버린 축의 방향 분산을 앞의 식에 대응시키고 같은 전치·합 전개를 다시 길게 하지 않는다.
- SVD의 0 블록을 차례로 곱하는 설명과 `N<M≤D` 경계 사례는 본문에서 축약한다. 절단 SVD·한 층의 외적·버린 특잇값 제곱합은 남긴다.
- 안테나·압축센싱·연구 조언과 새 확장 모델 이름을 풀이 본문에 쌓지 않는다.
- `PᵀP`, `BᵀB`와 `BBᵀ`의 구별, 사영·복원·잔차, 고유기저 전개와 상한 논리를 남긴다.

## 검증과 완료 기준

수정 전 두 날짜 전체를 RUN에 백업하고 범위 밖 학습 파일의 SHA-256 및 대상의 ID·링크·위젯·스크립트 계약을 기록한다. 파일명은 macOS NFC/NFD를 실제 경로에서 확인한다.

기존 `check_learning_map.py`, `check_html.py`, `html2md.check_md`와 관련 스킬 테스트를 사용한다. html2md의 기본 CLI는 문제 MD와 그림도 갱신하므로 공개 폴더에 직접 실행하지 않는다. 정리노트 MD를 직접 동기화하고 누락 검사 및 삭제된 설명·수식의 잔존 여부를 실제 대조한다.

375px와 데스크톱, 라이트·다크에서 첫 토픽, 변경 토픽, 단계 이동, 보충, 요약, 위젯, 링크, 읽음 상태를 확인한다. 앵커로 이동한 경우 필요한 설명이 닫힌 details에 가려지면 위치·요약을 조정한다.

회귀 사례는 강의와 문제 조건으로 제한된 입력을 사용해 실제 저작/감사 결과를 본다. 규칙 키워드가 있다는 사실만으로 성공 처리하지 않는다. 최소 사례는 그림 읽기, 증명 뒤 불필요한 추가 검산, Gram–Schmidt의 필수 연결, 공동 최적성 보충, core/extension 경계이다. 같은 입력의 수정 전후 결과를 기록하고 관찰하지 않은 실패·성공을 쓰지 않는다.

대표 풀이에서 방법 선택·조건 확인·계산·답이 유지되는지 본문으로 재현한다. 이 검증은 사용자의 숙달 확인이 아니다. 원래 있던 무관한 테스트 실패는 수정한 내용의 성공으로 덮지 않고 원인·영향을 보고한다.

## 제외

기존 문제·해설·인터렉티브·PDF 재저작, 다른 날짜 정리노트 수정, 새 문제 생성, 전면 UI 개편, 자동 의미 채점기, 단어 수 제한, 전체 생성 파이프라인 재설계는 포함하지 않는다.
