# 머신러닝기초 복습 영상 스킬 설계

## 목표와 확정 결정

완성된 머신러닝기초 복습노트에서 애니메이션이 이해를 돕는 부분을 선정하여 독립된 학습 질문마다 한국어 복습 영상을 만든다. 생명과학의 bio-review-video를 기반으로 입력·선정·설명·검증을 과목에 맞게 바꾼다.

이전 grill-yourself 설계의 #1–6을 유지한다. 사용자가 #7–8을 변경하지 않았으므로 추천안을 기본 확정한다: 주제별 1–3분 목표·필요시 연장, Aoede·가로형·자동 완주·비용 상한 없음·사용량 기록. 사용자의 후속 요구로 생명과학 저장소의 .env를 머신러닝기초 저장소 루트에 복사하고 API 키를 사용한다.

## 구현 경계

- 설치 위치는 `.agents/skills/ml-review-video/`. 생명과학 스킬의 실행 코드와 회귀 검사를 로컬에 포함한다. 런타임에 다른 과목 폴더를 import하거나 심볼릭 링크로 참조하지 않는다.
- `/ml-review-video MMDD`, `MMDD-MMDD`, 노트 폴더, `--review`, `--resume`, `--revoice --voice NAME`을 지원한다. CLI는 기존 scripts/video.py의 명령 체계를 유지한다.
- 입력은 복습노트 HTML·MD, 복습문제, 그림이다. STT·강의노트·MML은 충돌 해결과 조건·수식 확인에 사용한다. 원자료에서 노트 생성은 ml-review-pack이 담당한다.
- 생명과학의 장마감 문서는 필수 입력이 아니다. 수업 범위·교과서 보충·다음 시간 예고를 구분하고 예고는 기본 선정에서 제외한다.
- 선정 기록에 전체 개념, 선정/비선정 이유, 영상별 학습 질문·선수 개념·구체적인 화면 상태를 남긴다. 0·1·N개 가능. 0개에는 TTS를 호출하지 않는다. 통합 영상은 명시 요청 때만 만든다.
- 단순 정의·목록보다 계수 변화, 잔차와 손실, 분포 갱신, 주변화, 공분산과 아핀 변환처럼 실제 상태 변화가 도움이 되는 부분을 선정한다. 최적화는 배운 범위에 있을 때만 포함한다.
- 설명은 작은 예시 → 화면 변화 → 대응 수식 → 조건·오개념 순서다. 기호·축·단위·차원을 일관되게 유지한다. 새 예시는 설명용으로 표시하고 출처의 원문 수치와 혼동하지 않는다.
- 화면은 ml-review-pack의 실제 HTML 템플릿 스냅샷을 사용한다. 다크모드·Pretendard·로컬 KaTeX·1920×1080·30fps, 한국어 Vertex AI Aoede를 사용한다. 모델은 기존 설정 `gemini-2.5-flash-tts`를 유지하되 실제 API 가능 여부는 제작 시 확인한다. 공급자·모델·음성을 자동 대체하지 않는다.
- 기존 motion JSON의 move/highlight/reveal/path 등을 재사용한다. 곡선 변형 엔진을 새로 만들지 않고 계산된 SVG 상태를 순서대로 보여준다. 단계별 변화는 연속 변화처럼 오해되지 않게 표시한다.
- 수치 예시는 실행 가능한 계산 스크립트로 확인한다. 그래프 시작·중간·끝 상태의 좌표와 수식을 대조한다. 자동 검사는 계산 증거·파일 무결성을 확인하며 수학적 의미의 정확성은 별도 내용 검토가 담당한다.
- `--review`에서만 사용자 검토를 기다린다. 기본은 선정 목록과 예상 길이를 알리고 자동 진행한다. 기본 예산 상한은 null이며 요청별 공용 ledger를 유지한다.

## .env 복사와 키 사용

- 원본: `/Users/hyunjun_macbook_pro/Documents/Univ/생명과학/.env`.
- 목적지: 머신러닝기초 저장소 루트의 `.env`. 이 계획 작성 시 원본은 존재하고 목적지는 없으며 목적지 저장소의 `.gitignore`는 `.env`를 제외한다. 실행 시 다시 확인한다.
- 최초 설치 시 파일을 로컬로 복사하고 권한을 0600으로 설정한다. 원본·목적지가 심볼릭 링크이거나 원본이 없으면 중단한다. 목적지에 동일 바이트의 일반 파일이 있으면 재사용하고, 다른 파일이면 덮어쓰지 않고 충돌을 보고한다.
- 내용·키·키 해시는 출력하지 않는다. `.env`를 원자료 스냅샷, 제작자료, 테스트 fixture, Git에 넣지 않는다. 키는 비밀 없는 config.json에 저장하지 않는다.
- TTS 준비와 실행에 `--env-file <REPO>/.env`를 전달한다. 명시적인 env_file이 있을 때 키는 해당 파일의 GOOGLE_API_KEY, GEMINI_API_KEY 순서로 선택한다. 프로세스 환경변수 때문에 복사된 파일의 키가 조용히 대체되지 않게 한다. env_file이 없을 때만 기존 환경변수 fallback을 유지한다.
- 복사·키 로딩 확인은 네트워크 요청 없이 수행한다. 인증·모델 접근의 실제 성공은 영상 제작 때 확인하고 구분해서 보고한다.

## 출력과 완료 조건

`복습영상/<기간>/`에는 자연스러운 한국어 제목의 최종 MP4 N개와 `<기간>_제작자료/` 하나를 둔다. 제작자료 안에 실행별 selection.json, batch.json, 원자료 스냅샷, 대본, 자막, 시간표, 계산 스크립트·결과, HTML, 음성, 검증, ledger를 둔다.

모든 선정 영상의 현재 입력 지문으로 내용·음성·화면·동기화·편집 소스·최종 MP4 검증이 끝나야 publish-set과 latest를 갱신한다. 일부 실패 때 성공 결과를 재사용한다. 같은 기간 재제작은 기존 결과와 링크를 이전버전으로 보존한다. revoice는 별도 RUN에서 수행한다.

스킬 구현 완료는 로컬 회귀 검사, 가짜 TTS 통합 검사, 실제 브라우저/렌더 smoke 검사를 통과한 상태다. 유료 TTS를 포함한 실사용 영상 제작은 이 스킬 구현과 별도 요청이다. 커밋·푸시는 직접 요청이 있을 때만 한다.
