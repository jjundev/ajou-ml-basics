# 과제1 음성·자막 일치 수정 명세

2026-10-11 대화의 grill-yourself 설계를 기록한다. 사용자는 적용 범위를 과제1 P1–P25 전체, 음성 처리 방식을 같은 목소리로 청크 재합성으로 확정하고 writing-plans를 요청했다. 실행 방식은 아직 선택하지 않았다.

## 목표와 동작

음성 원고의 설명을 생략하지 않는 문장·의미 구절별 자막을 표시한다. 한국어 숫자·수학 발음은 해당 문맥의 숫자와 수학 기호로 표기하되 한글 숫자를 전역 치환하지 않는다. 음성 청크 하나와 표시 cue 하나를 대응시킨다. 각 청크의 실제 PCM 길이로 자막을 갱신하고 새 길이에 맞춰 필기·페이지 전환을 재계산한다.

## 고정 조건

- 대상은 과제1 P1–P25의 기존 25편이다.
- Vertex AI Express / gemini-2.5-flash-tts / Aoede / ko-KR / mono PCM 24kHz 16bit를 유지한다.
- 기존 원고의 의미·설명·수치·순서를 유지한다. 청크 분할 후 공백 정규화한 text 결합은 기존 원고와 같아야 한다.
- 최대 2줄/줄당 34자의 cue를 사용한다. 긴 문장은 의미 구절에서 나누고 보호된 수식은 자르지 않는다.
- SRT 반올림 오차 ≤1ms, 영상 경계 오차 ≤1프레임이다. 단어 내부 정렬은 주장하지 않는다.
- 1920×1080, 30fps, 원본 PDF 공개·필기·페이지 계약과 기존 자막 스타일을 유지한다.
- 기존 raw WAV, 캐시, 이전 영상과 PDF 원본을 보존한다. 변경되지 않은 text/config 청크는 캐시를 재사용한다.
- 음성 청크별 합성으로 발화 속도와 영상 길이가 달라질 수 있다.
- 자동 에너지 절단, 글자 수 비례 배분, 임의 연결 무음, 모델 자동 대체를 하지 않는다.
- 실제 전청크·최종 영상 청취 근거가 없으면 complete=false/live_audio=unverified이며 공식 publish/latest를 갱신하지 않는다. 이때 사용자가 볼 수 있는 수정 검토용 영상 25편과 한계를 전달한다.
- 실패 문항의 기존 영상은 유지하고 성공 문항은 보존 교체한다. 25편 전체 성공 후 목록·상태를 일치시킨다.

## 범위 밖

풀이·PDF·목소리 변경, 단어별 강조 자막, 기존 긴 음성의 강제 정렬, 다른 과목·복습영상 변경.

## 원인과 검증 경계

author-homework.py의 segment()는 긴 text와 요약 caption_text를 c1 하나에 넣는다. 기존 speech_chunks.py는 부모 필드가 청크 결합과 같은지 검사하지만 음성과 자막의 의미 대응은 증명하지 않는다. 원고·PCM·SRT·최종 MP4 hash 비교에서 25편 모두 요약 방식이며 168개 청크가 여러 문장을 포함했다. 기록상 PCM/SRT 경계는 맞았지만 실제 청취는 수행되지 않았다.
