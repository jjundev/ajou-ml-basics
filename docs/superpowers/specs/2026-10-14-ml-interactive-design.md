## 스킬 동작

## 공통 계산·장면 계약

작은 교육용 모델은 `phi(x)=[1,x]^T`, `K=2`로 제한한다. 범용 고차원 행렬 계산기를 만들지 않는다. `MLMath.posterior({xs,ys,n,m0,S0,sigma2})`는 `{mean,cov,n}`을 반환하며 `MLMath.predict(posterior,x,sigma2)`는 `{mean,functionVariance,observationVariance}`를 반환한다. 브라우저와 Node 검사기는 같은 `assets/ml-math.js`를 사용한다. 독립 Python Fraction 계산은 테스트의 정답 근거다.

공분산은 대칭 양의 정부호여야 하고 `sigma2>0`, `n`은 0부터 데이터 길이까지 정수여야 한다. NaN·Infinity·차원 오류·음수 분산·잘못된 n은 명시적 RangeError다. 퇴화한 함수 분포는 밀도 곡선으로 계산하지 않고 평균 위치의 점질량 표식으로 표시한다.

셸은 기존 패널·테마·서랍·크기 조절·재생·모드별 단계 기능을 유지한다. 2D가 기본이며 3D는 공간적 의미가 있는 주제만 허용한다. 기존 `k=1` 선분으로 곡선·축을 그리며, `k=6` 평면 다각형 primitive를 추가하여 분산 띠를 채운다. 다각형 좌표도 유한값 검사 대상이다. 축 눈금은 자동 범위에 대응하는 실제 수치여야 한다.

주제 훅 `topic/buildScene/extraState/extraVals`는 유지하고 순수 `compute(state)`를 추가한다. 패널·그래프는 이 결과를 사용한다. `PRESETS`에 초기·최소·최대·대표 입력을 명시하며 checker가 각 상태를 렌더링하고 그린다. 재생 주제의 단계는 `f/phase`를 유지한다. 실험 주제의 단계는 `preset`을 지정하며 누르면 해당 입력을 적용하고 재생을 멈춘다. 프레임 진행과 실험 입력을 혼동하지 않는다.

수식은 정적 공식만 KaTeX로 표시하고, 현재 숫자는 일반 DOM readout에 표시한다. `ref`는 정적 공식 렌더링에 사용한다. `onChange`는 기존 런타임에서 input 이벤트로 처리되므로 새 이벤트를 도입하지 않는다. 표본 기능이 있는 자료는 고정 seed와 초기화 기능을 가진다.

## 1014 자료 2개

공통 교육용 데이터: `xs=[-1,0,1]`, `ys=[0,1,2]`, 기본 `m0=[0,0]`, `S0=I`, `sigma2=1`. 사전분산을 `tau2 I`로 조절하며 `tau2=0.25..4`, `sigma2=0.1..2`, `n=0..3`을 사용한다. 기본은 `tau2=1,sigma2=1,n=3`이다.

1. `사전분포와_사후분포`: θ0·θ1 평면에서 사전·사후의 동일한 마할라노비스 거리 1, 2 등고선을 비교한다. 등고선이 2D 확률 68%·95%라는 문구를 쓰지 않는다. 별도 회귀 모드에서 동일 결과의 평균선과 seed 고정 함수 표본을 보여 준다. 데이터 개수·사전분산·학습 잡음 분산을 조작한다. 단계는 사전만→한 관측→전체 관측→강한 사전의 preset이다. `s1-match`의 formal 설명 뒤 연결한다.
2. `함수와_관측값의_예측분포`: 전체 x축의 함수·관측값 ±2 표준편차 띠를 비교하고, 밀도 모드에서 선택한 x*의 두 정규분포를 비교한다. x*는 -3..3이다. 학습 잡음 분산을 바꾸면 사후분포부터 다시 계산한다. 고정 사후분포에 독립적으로 더하는 잡음과 혼동되는 조작을 만들지 않는다. 표시값은 `mu,nu,sigma2,nu+sigma2,sqrt(nu),sqrt(nu+sigma2)`이며 1D 밀도에서만 약 95%를 설명한다. `s2-uncertainty` 안의 `widget-uncertainty` 뒤 연결한다.

두 자료는 단순 슬라이더 복제와 구별되도록 사후분포·회귀선·입력 위치를 함께 볼 수 있어야 한다. 각 모드에 실제로 혼동하기 쉬운 내용 세 개를 적는다. 1014 예고에만 있는 주변우도·Kalman 필터·직교투영은 새 본문 주제로 추가하지 않는다.

## 링크 및 팩 갱신

연결 도구는 offset 기반 삽입을 유지하고 표식을 `data-ml-interactive`로 바꾼다. dry-run은 쓰지 않으며 기존 목적지 링크는 문구를 유지하고 target/rel만 보정한다. 누락·중복 ID·잘못된 앵커·깨진 목적지는 해당 연결만 skipped로 보고한다.

각 자료의 `note-links.json`은 `v:1`과 `links`를 가지며 `note/html`은 REPO 기준 상대 경로다. 절대 경로는 실행 때 다시 계산하므로 worktree에 옮겨도 유지된다. REPO 밖 경로는 거절한다. `relink.cjs REPO MMDD`는 저장된 명세 중 해당 노트 폴더를 대상으로 한 연결만 모아 같은 도구를 실행한다. 검증 시 실제 경로에서 다른 번호가 정해졌으면 명세에는 save 결과를 기록한다.

`ml-review-pack`은 기본 팩과 문제설명 처리 뒤 기존 자료가 있는 경우 재연결만 실행하고 결과를 보고한다. 없으면 건너뛴다. ID가 바뀌어 연결을 복원할 수 없으면 agent가 실제 노트·자료를 읽어 명세를 갱신하거나 skipped 이유를 보고한다. 새 자료 생성과 문제설명 검토 결과를 대체하지 않는다.
