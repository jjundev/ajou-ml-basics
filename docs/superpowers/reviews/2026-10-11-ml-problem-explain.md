# ml-problem-explain 구현 검증

복습문제와 과제 카드에서 첫 줄·이유·완성 답·검산을 펼친 HTML/MD를 만드는 독립 로컬 스킬을 구현했다. 기존 문제·정리노트·PDF·그림은 변경하지 않았다. `.agents/skills/ml-problem-explain`은 실제 `.claude` 스킬의 상대 심볼릭 링크다.

## 독립 리뷰와 수정

검토 범위는 `f01def7..abb387f`였다. 별도 컨텍스트의 리뷰 에이전트가 읽기 전용으로 코드·설계와 임시 재현을 확인했다. 다음 기능 결함을 한 번의 수정 작업에 묶어, 각 재현 테스트가 실패하는 것을 확인한 뒤 통과시켰다.

- 인자 없는 최신 선택에서 종료일이 같은 통합/개별 팩을 모두 모아 모호함을 거부한다.
- 원본 하나가 변경되어도 정상 팩은 build/check/publish를 계속 수행한다.
- 질문 목록이 빠져도 원문 소문항 표지를 확인해 `main`으로 축약하지 않는다.
- 래스터 그림을 MD에 보존하고 그림 대응 누락을 기계 검사한다.
- build 후 변경된 설명을 check가 통과시키지 않는다.
- 명시한 HTML 경로도 NFC/NFD 차이를 보정한다.
- 원 카드의 동일 문항 anchor로 돌아가는 링크를 제공한다.

리뷰어가 Minor로 분류한 뒤 세 항목은 실제 호출·검토·탐색을 방해하므로 구현자가 Important로 재분류했다. 미해결 Critical/Important와 보류한 Minor는 없다. 수정 뒤 두 번째 리뷰를 요청하지 않고 재현 테스트와 전체 검증으로 확인했다.

## 구현 판단과 한계

- 기존 작업폴더의 `codex/ml-problem-explain` 브랜치에서 구현했다. 로컬 스킬을 바로 발견하게 하는 목적이며 main은 보존했다. 별도 checkout과 달리 구현 중 작업폴더를 공유한다.
- Windows PowerShell에서 Bash 실행 기록 도구 대신 동일한 작업·테스트·커밋 기록을 직접 작성했다. 자동 장부 기록 대신 수동 관리가 필요했다.
- 오래된 check, 명시적 정규화 경로, 원 문제 링크는 기능 결함으로 수정했다. 판단이 과했다면 추가 회귀 테스트의 유지 비용이 든다.
- 이번 요청은 스킬 구현이므로 실제 수업 자료의 완성 설명 전체는 발행하지 않았다. 수학적 정확성은 사용할 때 문항별 독립 검산·내용 검토를 수행하고 승인한다.
- 브라우저 확인은 구현자가 실행한 실제 Playwright 검사다. 독립 리뷰어는 화면 검사를 다시 수행하지 않았으므로 별도의 시각 검토 의견은 없다.
- 검토 JSON은 수행한 판단의 기록이다. 조립기는 자동 승인하지 않으며 해시·누락을 검사하지만, 허위 의미 승인을 자동 판별할 수는 없다. 실제 검토자의 기록이 필요하다.

## 검증 근거

새 스킬 테스트 49개 통과. 기존 스킬·과제 회귀 검증은 165개 통과, 2개 건너뜀, 252개 subtest 통과였다. 저장소 기본 테스트는 40개 통과, 22개 건너뜀, 206개 subtest 통과였다. 스킬 frontmatter 검사와 등록 링크 읽기, 전체 변경의 `git diff --check main`이 통과했다.

현재 저장된 복습문제 8팩과 과제1, 총 9팩·80문항을 테스트 설명으로 임시 조립하여 원문·소문항·MD·자원 검사를 수행했다. 임시 테스트 설명은 수업 자료로 발행하지 않았다.

실제 첫 문항 기반 복습·과제 샘플을 로컬 서버와 headless Chromium에서 1280×900/375×812, light/dark의 8조건으로 검사했다. 외부 네트워크 요청을 차단한 상태에서 콘솔·KaTeX 오류·깨진 이미지·문서 가로 넘침이 0이었다. 목차·이전/다음·모바일 요약 패널·마지막 설명까지의 본문 스크롤과 긴 행렬의 국소 가로 스크롤을 확인했다. 원 파일 링크는 최종 발행 위치 기준으로 실제 파일·anchor를 대조했다.

현재 스킬을 호출하면 extract → 에이전트 저작/독립 검산 → build/check → 화면 검토 → 검토 기록 승인 → 백업 후 발행 흐름을 사용한다. 실제 자료 대조와 의미 검토는 기계 검사와 별도다.

임시 검증 작업폴더 `.superpowers/sdd/2026-10-11-ml-problem-explain/` 정리는 경로를 확인한 뒤 정확한 절대경로로 재시도했지만 자동 승인 검토에서 `blocked by policy`로 차단됐다. 구체적인 정책 사유는 제공되지 않았다. 이 Git 무시 폴더에 임시 HTML·스크린샷·검사 기록을 보존했다. 원 수업 자료나 스킬 등록에는 영향이 없다.
