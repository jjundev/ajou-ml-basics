> 참고 자료(수업 STT 정밀 요약): `docs/plans/2026-09-21-lecture-notes-refs/stt-{0909,0914,0916}-summary.md`

## Intent
정방철 교수님 머신러닝기초의 0909·0914·0916 수업(STT), 강의노트(Lecture00~02), MML 교과서를 바탕으로 HTML 파일 두 개를 만든다.
- **정리노트**: 수업에서 실제로 다룬 모든 개념, 칠판 유도, 교수님 비유와 강조 발언을 ELI5 방식으로 푼다(비유·그림 먼저, 정식 수식은 그다음).
- **복습문제**: 교과서에서 수업 내용만으로 풀 수 있는 문제를 골라 힌트와 단계별 풀이를 토글로 넣는다.

두 파일을 브라우저에서 열어 시험공부에 바로 쓸 수 있고, 노트의 모든 토픽이 STT 기준 실제 수업 범위와 1:1로 맞으면 완료다.

Classification: architectural. 고칠 기존 흐름 없이 새로 만드는 산출물이다. 스타일 선례는 `강의노트/추가 강의/eli5_lecture10~12_*.html`이다.

## Behavior when done
- **정리노트**
  - 상단 고정 목차에서 섹션 0~5로 이동한다.
  - 각 토픽은 4층 구조다: 🧸 비유와 그림 → 📐 정식 정의·수식·유도 → 🎙️ 교수님 한마디 → ⚠️ 강조.
  - 각 토픽에 📅 날짜와 슬라이드 태그를 붙인다.
  - 수업에서 "나중에"로 미룬 유도는 📎 보충(수업 미유도) 배지로 구분한다.
  - 위젯은 두 개다: ① λ·차수 슬라이더로 과적합과 정규화 보기, ② 동전 ML·MAP·사후분포 보기.
  - 확률 추가강의 eli5 노트로 가는 링크를 둔다.
- **복습문제**
  - 10문항 카드로 구성한다. 카드마다 출처 배지, 난이도, 관련 노트 섹션 링크가 있다.
  - 문제는 한국어로 쓰고, 원문·힌트·풀이는 토글로 숨긴다.
  - "풀었음" 체크를 localStorage에 저장한다.
- **실패 시 동작**
  - 오프라인이면 KaTeX가 로드되지 않아 TeX 원문이 보이지만 읽을 수는 있다.
  - localStorage가 막혀 있으면 체크 상태만 저장되지 않는다.
