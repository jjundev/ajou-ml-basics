무엇을 구하는 문제인가요?

시계열 모델에서 한 걸음 앞 예측하기를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

한 걸음 예측(predictive distribution)은 현재 posterior를 선형 변환하고 새 독립 잡음을 더해요. $\mu_{t+1}=A\mu_t$, $P=A\Sigma_tA^\top+Q$예요. 모든 평균·공분산은 과거 관측을 조건으로 계산해요.

종이에 적을 첫 줄

$x_{t+1}-A\mu_t=A(x_t-\mu_t)+w$예요.

왜 이렇게 푸는지 함께 따라가요

풀이

아래의 평균과 분산은 모두 $\mathbf{y}_1, \dots, \mathbf{y}_t$를 본 상태에서 계산해요. 이때 $\mathbb{E}[\mathbf{x}_t] = \boldsymbol{\mu}_t$, $\mathbb{V}[\mathbf{x}_t] = \boldsymbol{\Sigma}_t$예요.

평균은 합을 그대로 통과해요. 아핀 변환 규칙과 $\mathbb{E}[\mathbf{w}] = \mathbf{0}$을 써요. $$\mathbb{E}[\mathbf{x}_{t+1}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}_t] + \mathbb{E}[\mathbf{w}] = \mathbf{A}\boldsymbol{\mu}_t$$

$\mathbf{A}\mathbf{x}_t$의 공분산 행렬은 아핀 변환 규칙으로 구해요. $$\mathbb{V}[\mathbf{A}\mathbf{x}_t] = \mathbf{A}\,\mathbb{V}[\mathbf{x}_t]\,\mathbf{A}^\top = \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top$$

$\mathbf{A}\mathbf{x}_t$와 $\mathbf{w}$ 사이의 공분산을 확인해요. $\mathbb{E}[\mathbf{w}] = \mathbf{0}$이라서 $$\operatorname{Cov}[\mathbf{A}\mathbf{x}_t, \mathbf{w}] = \mathbb{E}[\mathbf{A}\mathbf{x}_t\mathbf{w}^\top] - \mathbb{E}[\mathbf{A}\mathbf{x}_t]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{A}\,\mathbb{E}[\mathbf{x}_t\mathbf{w}^\top]$$ $\mathbf{x}_t$와 $\mathbf{w}$가 독립이라 $\mathbb{E}[\mathbf{x}_t\mathbf{w}^\top] = \mathbb{E}[\mathbf{x}_t]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{0}$이에요. 그래서 $\operatorname{Cov}[\mathbf{A}\mathbf{x}_t, \mathbf{w}] = \mathbf{0}$이에요.

교차 공분산이 0이니까 합의 분산은 분산의 합이에요. $\mathbb{V}[\mathbf{w}] = \mathbf{Q}$를 넣어요. $$\mathbb{V}[\mathbf{x}_{t+1}] = \mathbb{V}[\mathbf{A}\mathbf{x}_t] + \mathbb{V}[\mathbf{w}] = \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}$$

가우시안이라는 사실은 주어졌어요. 평균과 공분산만 알면 분포가 정해지니까 $$p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t) = \mathcal{N}\big(\mathbf{A}\boldsymbol{\mu}_t,\; \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}\big)$$ 한 걸음 나아가면 노이즈 $\mathbf{Q}$만큼 불확실성이 더해져요.

수업과의 연결: 0930 수업의 아핀 변환 규칙 $\mathbb{E}[\mathbf{y}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}] + \mathbf{b}$, $\mathbb{V}[\mathbf{y}] = \mathbf{A}\,\mathbb{V}[\mathbf{x}]\,\mathbf{A}^\top$에서 $\mathbf{b} = \mathbf{0}$으로 둔 거예요. 여기에 독립이거나 적어도 공분산이 0일 때 쓸 수 있다고 한 $\mathbb{V}[\mathbf{x} + \mathbf{y}] = \mathbb{V}[\mathbf{x}] + \mathbb{V}[\mathbf{y}]$를 더했어요.

완성 답과 검산

검산

편차 외적의 교차항은 새 잡음과 과거 상태의 조건부 독립으로0이에요. A=I,Q=0이면 현재 평균·공분산이 그대로 복원돼요.

정답: $p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t) = \mathcal{N}\big(\mathbf{A}\boldsymbol{\mu}_t,\; \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}\big)$

여기서 주의해요

아직 다음 관측을 보지 않았으므로 R이나 C를 상태 예측분산에 더하지 않아요.

설명을 닫고 다시 해요

  1. $x_{t+1}-A\mu_t=A(x_t-\mu_t)+w$예요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 아직 다음 관측을 보지 않았으므로 R이나 C를 상태 예측분산에 더하지 않아요.
