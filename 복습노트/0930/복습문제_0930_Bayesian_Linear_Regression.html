A. 교과서 예제 변형

P1. 종속인데 공분산이 0인 경우

확률변수 $X$는 평균이 0이고($\mathbb{E}[x] = 0$), 세제곱의 평균도 0이에요($\mathbb{E}[x^3] = 0$). 새 확률변수를 $y = x^2$으로 만들어요. $y$는 $x$로 정해지니까 $Y$는 $X$에 종속이에요. 이때 $X$와 $Y$의 공분산 $\operatorname{Cov}[x, y]$를 구해 보세요.
교과서 원문 보기"Let $y = x^2$ (hence, $Y$ is dependent on $X$)" — Example 6.5
힌트 보기공분산은 "곱의 평균 빼기 평균의 곱"이에요. $xy$ 자리에 $y = x^2$을 넣으면 $x^3$이 돼요.
풀이 보기
  1. 공분산 식을 적어요. $$\operatorname{Cov}[x, y] = \mathbb{E}[xy] - \mathbb{E}[x]\,\mathbb{E}[y]$$
  2. $y = x^2$을 넣으면 $xy = x \cdot x^2 = x^3$이에요. 그래서 첫 항은 $\mathbb{E}[xy] = \mathbb{E}[x^3]$이에요.
  3. 둘째 항은 $\mathbb{E}[x]\,\mathbb{E}[y] = \mathbb{E}[x]\,\mathbb{E}[x^2]$이에요. $\mathbb{E}[x] = 0$이라서 $\mathbb{E}[x^2]$이 얼마든 이 항은 0이에요.
  4. 문제에서 $\mathbb{E}[x^3] = 0$이라고 했어요. 두 항을 합치면 $$\operatorname{Cov}[x, y] = \mathbb{E}[x^3] - \mathbb{E}[x]\,\mathbb{E}[x^2] = 0 - 0 = 0$$
  5. 그런데 $X$와 $Y$는 독립이 아니에요. $x$를 알면 $y = x^2$이 바로 정해지기 때문이에요. 공분산이 0이어도 독립이라고 말할 수는 없어요.
  6. 수업과의 연결: 0930 수업의 $\operatorname{Cov}[X, Y] = \mathbb{E}[XY] - \mathbb{E}[X]\,\mathbb{E}[Y]$를 그대로 쓴 거예요. 합의 분산 식에 붙인 조건 "독립이거나, 적어도 공분산이 0"에서 두 조건이 서로 다른 말이라는 걸 보여 주는 예예요.

정답: $\operatorname{Cov}[x, y] = \mathbb{E}[x^3] - \mathbb{E}[x]\,\mathbb{E}[x^2] = 0$ ($Y$는 $X$에 종속이지만 공분산은 0이에요.)

P2. 독립인 가우시안의 가중합

서로 독립인 가우시안 확률변수 $\mathbf{x}$와 $\mathbf{y}$가 있어요. $\mathbf{x}$의 평균은 $\boldsymbol{\mu}_x$, 공분산 행렬은 $\boldsymbol{\Sigma}_x$이고, $\mathbf{y}$의 평균은 $\boldsymbol{\mu}_y$, 공분산 행렬은 $\boldsymbol{\Sigma}_y$예요. 상수 $a$, $b$로 가중합 $a\mathbf{x} + b\mathbf{y}$를 만들어요. 이 가중합도 가우시안이라는 사실은 주어진 것으로 써요. 가중합의 평균과 공분산 행렬을 구해서 $p(a\mathbf{x} + b\mathbf{y})$를 적어 보세요.
교과서 원문 보기"we can obtain the weighted sum of independent Gaussian random variables" — Example 6.7
힌트 보기평균은 상수가 그대로 나오고, 분산은 상수가 제곱해서 나와요. 독립이면 합의 분산은 분산의 합이에요.
풀이 보기
  1. 평균부터 구해요. 기댓값은 합과 상수배를 그대로 통과시켜요. $$\mathbb{E}[a\mathbf{x} + b\mathbf{y}] = a\,\mathbb{E}[\mathbf{x}] + b\,\mathbb{E}[\mathbf{y}] = a\boldsymbol{\mu}_x + b\boldsymbol{\mu}_y$$
  2. $a\mathbf{x}$는 $\mathbf{A} = a\mathbf{I}$, $\mathbf{b} = \mathbf{0}$인 아핀 변환이에요. 그래서 $$\mathbb{V}[a\mathbf{x}] = (a\mathbf{I})\,\boldsymbol{\Sigma}_x\,(a\mathbf{I})^\top = a^2\boldsymbol{\Sigma}_x$$ 같은 방법으로 $\mathbb{V}[b\mathbf{y}] = b^2\boldsymbol{\Sigma}_y$예요.
  3. $a\mathbf{x}$와 $b\mathbf{y}$ 사이의 공분산을 확인해요. $$\operatorname{Cov}[a\mathbf{x}, b\mathbf{y}] = \mathbb{E}[a\mathbf{x}\,b\mathbf{y}^\top] - \mathbb{E}[a\mathbf{x}]\,\mathbb{E}[b\mathbf{y}]^\top = ab\,\operatorname{Cov}[\mathbf{x}, \mathbf{y}]$$ $\mathbf{x}$와 $\mathbf{y}$가 독립이라서 $\operatorname{Cov}[\mathbf{x}, \mathbf{y}] = \mathbf{0}$이고, 이 값도 $\mathbf{0}$이에요.
  4. 교차 공분산이 0이니까 합의 분산은 분산의 합이에요. $$\mathbb{V}[a\mathbf{x} + b\mathbf{y}] = \mathbb{V}[a\mathbf{x}] + \mathbb{V}[b\mathbf{y}] = a^2\boldsymbol{\Sigma}_x + b^2\boldsymbol{\Sigma}_y$$
  5. 가중합이 가우시안이라는 사실은 주어졌어요. 가우시안은 평균과 공분산만 알면 정해지니까 $$p(a\mathbf{x} + b\mathbf{y}) = \mathcal{N}\big(a\boldsymbol{\mu}_x + b\boldsymbol{\mu}_y,\; a^2\boldsymbol{\Sigma}_x + b^2\boldsymbol{\Sigma}_y\big)$$
  6. 수업과의 연결: 0930 수업의 "상수는 분산에서 제곱해서 나온다"($\mathbb{V}[aX] = a^2\,\mathbb{V}[X]$)와, 독립이거나 적어도 공분산이 0일 때 쓸 수 있다고 한 $\mathbb{V}[\mathbf{x} + \mathbf{y}] = \mathbb{V}[\mathbf{x}] + \mathbb{V}[\mathbf{y}]$를 이어 쓴 거예요.

정답: $p(a\mathbf{x} + b\mathbf{y}) = \mathcal{N}\big(a\boldsymbol{\mu}_x + b\boldsymbol{\mu}_y,\; a^2\boldsymbol{\Sigma}_x + b^2\boldsymbol{\Sigma}_y\big)$

B. 교과서 연습문제

P3. 시계열 모델에서 한 걸음 앞 예측하기

시간에 따라 변하는 상태 $\mathbf{x}_t$를 아래 시계열 모델로 나타내요. $$\mathbf{x}_{t+1} = \mathbf{A}\mathbf{x}_t + \mathbf{w}, \quad \mathbf{w} \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})$$ $$\mathbf{y}_t = \mathbf{C}\mathbf{x}_t + \mathbf{v}, \quad \mathbf{v} \sim \mathcal{N}(\mathbf{0}, \mathbf{R})$$ $\mathbf{A}$, $\mathbf{C}$는 상수 행렬이고, $\mathbf{w}$, $\mathbf{v}$는 상태와 독립인 가우시안 노이즈예요. $\mathbf{y}_t$는 상태를 측정한 값이에요. 시각 $t$까지의 측정값을 본 뒤 $\mathbf{x}_t$의 분포가 $p(\mathbf{x}_t \mid \mathbf{y}_1, \dots, \mathbf{y}_t) = \mathcal{N}(\boldsymbol{\mu}_t, \boldsymbol{\Sigma}_t)$라고 해요. 같은 측정값만 가지고 다음 상태의 분포 $p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t)$를 구해 보세요. 이 분포가 가우시안이라는 사실은 주어진 것으로 써요.
교과서 원문 보기"Compute $p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t)$." — Exercise 6.5
힌트 보기$\mathbf{x}_{t+1}$은 $\mathbf{x}_t$에 상수 행렬 $\mathbf{A}$를 곱하고 독립인 노이즈 $\mathbf{w}$를 더한 거예요. 평균과 공분산을 따로 구해요.
풀이 보기
  1. 아래의 평균과 분산은 모두 $\mathbf{y}_1, \dots, \mathbf{y}_t$를 본 상태에서 계산해요. 이때 $\mathbb{E}[\mathbf{x}_t] = \boldsymbol{\mu}_t$, $\mathbb{V}[\mathbf{x}_t] = \boldsymbol{\Sigma}_t$예요.
  2. 평균은 합을 그대로 통과해요. 아핀 변환 규칙과 $\mathbb{E}[\mathbf{w}] = \mathbf{0}$을 써요. $$\mathbb{E}[\mathbf{x}_{t+1}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}_t] + \mathbb{E}[\mathbf{w}] = \mathbf{A}\boldsymbol{\mu}_t$$
  3. $\mathbf{A}\mathbf{x}_t$의 공분산 행렬은 아핀 변환 규칙으로 구해요. $$\mathbb{V}[\mathbf{A}\mathbf{x}_t] = \mathbf{A}\,\mathbb{V}[\mathbf{x}_t]\,\mathbf{A}^\top = \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top$$
  4. $\mathbf{A}\mathbf{x}_t$와 $\mathbf{w}$ 사이의 공분산을 확인해요. $\mathbb{E}[\mathbf{w}] = \mathbf{0}$이라서 $$\operatorname{Cov}[\mathbf{A}\mathbf{x}_t, \mathbf{w}] = \mathbb{E}[\mathbf{A}\mathbf{x}_t\mathbf{w}^\top] - \mathbb{E}[\mathbf{A}\mathbf{x}_t]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{A}\,\mathbb{E}[\mathbf{x}_t\mathbf{w}^\top]$$ $\mathbf{x}_t$와 $\mathbf{w}$가 독립이라 $\mathbb{E}[\mathbf{x}_t\mathbf{w}^\top] = \mathbb{E}[\mathbf{x}_t]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{0}$이에요. 그래서 $\operatorname{Cov}[\mathbf{A}\mathbf{x}_t, \mathbf{w}] = \mathbf{0}$이에요.
  5. 교차 공분산이 0이니까 합의 분산은 분산의 합이에요. $\mathbb{V}[\mathbf{w}] = \mathbf{Q}$를 넣어요. $$\mathbb{V}[\mathbf{x}_{t+1}] = \mathbb{V}[\mathbf{A}\mathbf{x}_t] + \mathbb{V}[\mathbf{w}] = \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}$$
  6. 가우시안이라는 사실은 주어졌어요. 평균과 공분산만 알면 분포가 정해지니까 $$p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t) = \mathcal{N}\big(\mathbf{A}\boldsymbol{\mu}_t,\; \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}\big)$$ 한 걸음 나아가면 노이즈 $\mathbf{Q}$만큼 불확실성이 더해져요.
  7. 수업과의 연결: 0930 수업의 아핀 변환 규칙 $\mathbb{E}[\mathbf{y}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}] + \mathbf{b}$, $\mathbb{V}[\mathbf{y}] = \mathbf{A}\,\mathbb{V}[\mathbf{x}]\,\mathbf{A}^\top$에서 $\mathbf{b} = \mathbf{0}$으로 둔 거예요. 여기에 독립이거나 적어도 공분산이 0일 때 쓸 수 있다고 한 $\mathbb{V}[\mathbf{x} + \mathbf{y}] = \mathbb{V}[\mathbf{x}] + \mathbb{V}[\mathbf{y}]$를 더했어요.

정답: $p(\mathbf{x}_{t+1} \mid \mathbf{y}_1, \dots, \mathbf{y}_t) = \mathcal{N}\big(\mathbf{A}\boldsymbol{\mu}_t,\; \mathbf{A}\boldsymbol{\Sigma}_t\mathbf{A}^\top + \mathbf{Q}\big)$

P4. 분산은 제곱의 평균 빼기 평균의 제곱

확률변수 $X$의 평균을 $\mu = \mathbb{E}[x]$라고 해요. 분산의 정의는 평균에서 벗어난 정도를 제곱해 평균 낸 값이에요. $$\mathbb{V}[x] = \mathbb{E}[(x - \mu)^2]$$ 이 정의에서 출발해 아래 식을 증명해 보세요. $$\mathbb{V}[x] = \mathbb{E}[x^2] - (\mathbb{E}[x])^2$$
교과서 원문 보기"Prove the relationship in (6.44)" — Exercise 6.6
힌트 보기제곱을 펼친 다음 항마다 기댓값을 취해요. $\mu$는 상수라서 기댓값 밖으로 나와요.
풀이 보기
  1. 제곱을 펼쳐요. $$(x - \mu)^2 = x^2 - 2\mu x + \mu^2$$
  2. 기댓값은 합과 상수배를 그대로 통과시켜요. $\mu$는 상수예요. $$\mathbb{E}[(x - \mu)^2] = \mathbb{E}[x^2] - 2\mu\,\mathbb{E}[x] + \mu^2$$
  3. $\mathbb{E}[x] = \mu$를 넣어요. $$\mathbb{E}[x^2] - 2\mu \cdot \mu + \mu^2 = \mathbb{E}[x^2] - \mu^2$$
  4. $\mu$를 다시 $\mathbb{E}[x]$로 적으면 증명이 끝나요. $$\mathbb{V}[x] = \mathbb{E}[x^2] - (\mathbb{E}[x])^2$$
  5. 수업과의 연결: 0930 수업의 "곱의 평균 빼기 평균의 곱" $\operatorname{Cov}[X, Y] = \mathbb{E}[XY] - \mathbb{E}[X]\,\mathbb{E}[Y]$에서 $Y$ 자리에 $X$를 넣은 것과 같아요. 분산은 자기 자신과의 공분산이에요.

정답: $\mathbb{V}[x] = \mathbb{E}[(x - \mu)^2] = \mathbb{E}[x^2] - 2\mu\,\mathbb{E}[x] + \mu^2 = \mathbb{E}[x^2] - (\mathbb{E}[x])^2$

P5. 노이즈가 섞인 선형 변환의 가능도

가우시안 확률변수 $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$가 있어요($\mathbf{x} \in \mathbb{R}^D$). 여기에 상수 행렬 $\mathbf{A}$를 곱하고 상수 벡터 $\mathbf{b}$와 노이즈 $\mathbf{w}$를 더해요. $$\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b} + \mathbf{w}$$ $\mathbf{y} \in \mathbb{R}^E$이고, $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})$는 $\mathbf{x}$와 독립인 가우시안 노이즈예요. $\mathbf{x}$ 값이 주어졌을 때 $\mathbf{y}$의 분포, 즉 가능도(likelihood) $p(\mathbf{y} \mid \mathbf{x})$를 적어 보세요.
교과서 원문 보기"Write down the likelihood $p(\mathbf{y} \mid \mathbf{x})$." — Exercise 6.12
힌트 보기$\mathbf{x}$가 주어지면 $\mathbf{A}\mathbf{x} + \mathbf{b}$는 정해진 값이에요. 불확실한 건 노이즈 $\mathbf{w}$뿐이에요.
풀이 보기
  1. $\mathbf{x}$가 주어졌다고 해요. 그러면 $\mathbf{A}\mathbf{x} + \mathbf{b}$는 더 이상 흔들리지 않는 상수 벡터예요.
  2. $\mathbf{w}$는 $\mathbf{x}$와 독립이에요. $\mathbf{x}$를 알아도 $\mathbf{w}$의 분포는 그대로 $\mathcal{N}(\mathbf{0}, \mathbf{Q})$예요.
  3. $\mathbf{y}$는 상수에 $\mathbf{w}$를 더한 것이에요. 평균은 상수만큼 옮겨져요. $$\mathbb{E}[\mathbf{y} \mid \mathbf{x}] = \mathbf{A}\mathbf{x} + \mathbf{b} + \mathbb{E}[\mathbf{w}] = \mathbf{A}\mathbf{x} + \mathbf{b}$$
  4. 상수를 더해도 퍼진 정도는 바뀌지 않아요. $$\mathbb{V}[\mathbf{y} \mid \mathbf{x}] = \mathbb{V}[\mathbf{w}] = \mathbf{Q}$$
  5. 가우시안 노이즈를 상수만큼 옮긴 것이라 종 모양은 그대로예요. 그래서 $$p(\mathbf{y} \mid \mathbf{x}) = \mathcal{N}(\mathbf{y} \mid \mathbf{A}\mathbf{x} + \mathbf{b}, \mathbf{Q})$$
  6. 수업과의 연결: 0930 수업의 가능도 $p(y \mid \mathbf{x}, \boldsymbol{\theta}) = \mathcal{N}\big(y \mid \boldsymbol{\phi}^\top(\mathbf{x})\boldsymbol{\theta},\, \sigma^2\big)$와 같은 논리예요. 조건으로 주어진 것은 상수가 되고, 불확실성은 노이즈에만 남아요.

정답: $p(\mathbf{y} \mid \mathbf{x}) = \mathcal{N}(\mathbf{y} \mid \mathbf{A}\mathbf{x} + \mathbf{b}, \mathbf{Q})$

P6. 노이즈가 섞인 선형 변환의 평균과 공분산

가우시안 확률변수 $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$가 있어요($\mathbf{x} \in \mathbb{R}^D$). 여기에 상수 행렬 $\mathbf{A}$를 곱하고 상수 벡터 $\mathbf{b}$와 노이즈 $\mathbf{w}$를 더해요. $$\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b} + \mathbf{w}$$ $\mathbf{y} \in \mathbb{R}^E$이고, $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})$는 $\mathbf{x}$와 독립인 가우시안 노이즈예요. $\mathbf{y}$의 분포 $p(\mathbf{y})$가 가우시안이라는 사실은 주어진 것으로 써요. 그 평균 $\boldsymbol{\mu}_y$와 공분산 행렬 $\boldsymbol{\Sigma}_y$를 단계별로 유도해 보세요.
교과서 원문 보기"Compute the mean $\boldsymbol{\mu}_y$ and the covariance $\boldsymbol{\Sigma}_y$. Derive your result in detail." — Exercise 6.12
힌트 보기$\mathbf{y}$를 아핀 변환 $\mathbf{A}\mathbf{x} + \mathbf{b}$와 노이즈 $\mathbf{w}$의 합으로 봐요. 두 조각이 독립이면 분산은 더하면 돼요.
풀이 보기
  1. $\mathbf{y}$를 두 조각으로 나눠요. $\mathbf{u} = \mathbf{A}\mathbf{x} + \mathbf{b}$라고 두면 $\mathbf{y} = \mathbf{u} + \mathbf{w}$예요.
  2. 평균은 합을 그대로 통과해요. 아핀 변환 규칙과 $\mathbb{E}[\mathbf{w}] = \mathbf{0}$을 써요. $$\boldsymbol{\mu}_y = \mathbb{E}[\mathbf{u}] + \mathbb{E}[\mathbf{w}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}] + \mathbf{b} + \mathbf{0} = \mathbf{A}\boldsymbol{\mu}_x + \mathbf{b}$$
  3. $\mathbf{u}$의 공분산 행렬은 아핀 변환 규칙으로 구해요. 상수 $\mathbf{b}$는 퍼짐에 영향을 주지 않아요. $$\mathbb{V}[\mathbf{u}] = \mathbf{A}\,\mathbb{V}[\mathbf{x}]\,\mathbf{A}^\top = \mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top$$
  4. $\mathbf{u}$와 $\mathbf{w}$ 사이의 공분산을 확인해요. $\mathbb{E}[\mathbf{w}] = \mathbf{0}$이라서 $$\operatorname{Cov}[\mathbf{u}, \mathbf{w}] = \mathbb{E}[(\mathbf{A}\mathbf{x} + \mathbf{b})\mathbf{w}^\top] - \mathbb{E}[\mathbf{u}]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{A}\,\mathbb{E}[\mathbf{x}\mathbf{w}^\top]$$ $\mathbf{x}$와 $\mathbf{w}$가 독립이라 $\mathbb{E}[\mathbf{x}\mathbf{w}^\top] = \mathbb{E}[\mathbf{x}]\,\mathbb{E}[\mathbf{w}]^\top = \mathbf{0}$이에요. 그래서 $\operatorname{Cov}[\mathbf{u}, \mathbf{w}] = \mathbf{0}$이에요.
  5. 교차 공분산이 0이니까 합의 분산은 분산의 합이에요. $\mathbb{V}[\mathbf{w}] = \mathbf{Q}$를 넣어요. $$\boldsymbol{\Sigma}_y = \mathbb{V}[\mathbf{u}] + \mathbb{V}[\mathbf{w}] = \mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top + \mathbf{Q}$$
  6. $p(\mathbf{y})$는 가우시안이라고 주어졌으니 $p(\mathbf{y}) = \mathcal{N}(\mathbf{y} \mid \boldsymbol{\mu}_y, \boldsymbol{\Sigma}_y)$로 정해져요.
  7. 수업과의 연결: 0930 수업의 아핀 변환 규칙 $\mathbb{V}[\mathbf{y}] = \mathbf{A}\,\mathbb{V}[\mathbf{x}]\,\mathbf{A}^\top$에, 독립이거나 적어도 공분산이 0일 때 쓸 수 있다고 한 $\mathbb{V}[\mathbf{x} + \mathbf{y}] = \mathbb{V}[\mathbf{x}] + \mathbb{V}[\mathbf{y}]$를 더한 거예요.

정답: $\boldsymbol{\mu}_y = \mathbf{A}\boldsymbol{\mu}_x + \mathbf{b}$, $\boldsymbol{\Sigma}_y = \mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top + \mathbf{Q}$

P7. 한 번 더 변환해서 측정하기

가우시안 확률변수 $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}_x, \boldsymbol{\Sigma}_x)$로 $\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b} + \mathbf{w}$를 만들어요. $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})$는 $\mathbf{x}$와 독립인 가우시안 노이즈예요. 이때 $\mathbf{y}$는 평균이 $\boldsymbol{\mu}_y = \mathbf{A}\boldsymbol{\mu}_x + \mathbf{b}$, 공분산 행렬이 $\boldsymbol{\Sigma}_y = \mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top + \mathbf{Q}$인 가우시안이에요. 이 결과는 주어진 것으로 써요. 이제 $\mathbf{y}$를 상수 행렬 $\mathbf{C}$로 한 번 더 변환해서 측정해요. $$\mathbf{z} = \mathbf{C}\mathbf{y} + \mathbf{v}$$ $\mathbf{v} \sim \mathcal{N}(\mathbf{0}, \mathbf{R})$은 $\mathbf{y}$와 독립인 가우시안 측정 노이즈예요. $p(\mathbf{z})$가 가우시안이라는 사실도 주어진 것으로 써요.
  1. (a) $p(\mathbf{z} \mid \mathbf{y})$를 적어 보세요.
  2. (b) $p(\mathbf{z})$의 평균 $\boldsymbol{\mu}_z$와 공분산 행렬 $\boldsymbol{\Sigma}_z$를 단계별로 유도해 보세요.
교과서 원문 보기"Write down $p(\mathbf{z} \mid \mathbf{y})$. Compute $p(\mathbf{z})$" — Exercise 6.12
힌트 보기(a)는 $\mathbf{y}$가 주어지면 $\mathbf{C}\mathbf{y}$가 상수라는 점을 써요. (b)는 아핀 변환 $\mathbf{C}\mathbf{y}$와 노이즈 $\mathbf{v}$의 합으로 봐요.
풀이 보기
  1. (a) $\mathbf{y}$가 주어지면 $\mathbf{C}\mathbf{y}$는 상수 벡터예요. $\mathbf{v}$는 $\mathbf{y}$와 독립이라 분포가 그대로 $\mathcal{N}(\mathbf{0}, \mathbf{R})$이에요.
  2. (a) 상수에 가우시안 노이즈를 더했으니 평균만 $\mathbf{C}\mathbf{y}$로 옮겨지고 퍼짐은 $\mathbf{R}$ 그대로예요. $$p(\mathbf{z} \mid \mathbf{y}) = \mathcal{N}(\mathbf{z} \mid \mathbf{C}\mathbf{y}, \mathbf{R})$$
  3. (b) 평균은 합을 그대로 통과해요. $\mathbb{E}[\mathbf{v}] = \mathbf{0}$이에요. $$\boldsymbol{\mu}_z = \mathbf{C}\,\mathbb{E}[\mathbf{y}] + \mathbb{E}[\mathbf{v}] = \mathbf{C}\boldsymbol{\mu}_y$$
  4. (b) $\mathbf{C}\mathbf{y}$의 공분산 행렬은 아핀 변환 규칙으로 $\mathbf{C}\,\mathbb{V}[\mathbf{y}]\,\mathbf{C}^\top = \mathbf{C}\boldsymbol{\Sigma}_y\mathbf{C}^\top$이에요.
  5. (b) $\mathbf{y}$와 $\mathbf{v}$가 독립이라 $\mathbb{E}[\mathbf{y}\mathbf{v}^\top] = \mathbb{E}[\mathbf{y}]\,\mathbb{E}[\mathbf{v}]^\top = \mathbf{0}$이에요. 그래서 $\operatorname{Cov}[\mathbf{C}\mathbf{y}, \mathbf{v}] = \mathbf{C}\,\mathbb{E}[\mathbf{y}\mathbf{v}^\top] - \mathbf{C}\boldsymbol{\mu}_y\,\mathbb{E}[\mathbf{v}]^\top = \mathbf{0}$이에요.
  6. (b) 교차 공분산이 0이니까 분산을 더해요. $$\boldsymbol{\Sigma}_z = \mathbb{V}[\mathbf{C}\mathbf{y}] + \mathbb{V}[\mathbf{v}] = \mathbf{C}\boldsymbol{\Sigma}_y\mathbf{C}^\top + \mathbf{R}$$
  7. (b) 주어진 $\boldsymbol{\mu}_y$, $\boldsymbol{\Sigma}_y$를 넣으면 처음 재료로도 적을 수 있어요. $$\boldsymbol{\mu}_z = \mathbf{C}(\mathbf{A}\boldsymbol{\mu}_x + \mathbf{b})$$ $$\boldsymbol{\Sigma}_z = \mathbf{C}(\mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top + \mathbf{Q})\mathbf{C}^\top + \mathbf{R}$$
  8. 수업과의 연결: 0930 수업의 아핀 변환 규칙 $\mathbb{E}[\mathbf{y}] = \mathbf{A}\,\mathbb{E}[\mathbf{x}] + \mathbf{b}$, $\mathbb{V}[\mathbf{y}] = \mathbf{A}\,\mathbb{V}[\mathbf{x}]\,\mathbf{A}^\top$를 한 번 더 쓴 거예요. 변환을 거칠 때마다 공분산 양옆에 행렬과 그 전치가 붙고, 독립인 노이즈의 공분산이 더해져요.

정답: (a) $p(\mathbf{z} \mid \mathbf{y}) = \mathcal{N}(\mathbf{z} \mid \mathbf{C}\mathbf{y}, \mathbf{R})$ (b) $\boldsymbol{\mu}_z = \mathbf{C}\boldsymbol{\mu}_y = \mathbf{C}(\mathbf{A}\boldsymbol{\mu}_x + \mathbf{b})$, $\boldsymbol{\Sigma}_z = \mathbf{C}\boldsymbol{\Sigma}_y\mathbf{C}^\top + \mathbf{R} = \mathbf{C}(\mathbf{A}\boldsymbol{\Sigma}_x\mathbf{A}^\top + \mathbf{Q})\mathbf{C}^\top + \mathbf{R}$

P8. 쌍끼리의 차이로 보는 분산

확률변수 $X$에서 얻은 관측값 $x_1, \dots, x_N$이 있어요. 모든 쌍 $(x_i, x_j)$의 차이를 제곱해 평균 내면, "제곱의 평균 빼기 평균의 제곱"의 두 배가 돼요. $$\frac{1}{N^2}\sum_{i,j=1}^{N}(x_i - x_j)^2 = 2\left[\frac{1}{N}\sum_{i=1}^{N} x_i^2 - \left(\frac{1}{N}\sum_{i=1}^{N} x_i\right)^2\right]$$ 이 식을 증명해 보세요.
교과서 원문 보기"Prove the relationship in (6.45)" — Exercise 6.7
힌트 보기$(x_i - x_j)^2$을 세 항으로 펼쳐요. 그다음 $i$에 대한 합과 $j$에 대한 합을 항마다 따로 계산해요.
풀이 보기
  1. 제곱을 펼쳐요. $$(x_i - x_j)^2 = x_i^2 - 2x_i x_j + x_j^2$$
  2. 첫 항을 $i$, $j$ 모두에 대해 더해요. $x_i^2$은 $j$와 상관없으니 $j$에 대한 합은 같은 값을 $N$번 더하는 거예요. $$\sum_{i,j=1}^{N} x_i^2 = N\sum_{i=1}^{N} x_i^2$$
  3. 셋째 항도 같아요. 이번에는 $i$에 대한 합이 $N$번 더하는 역할을 해요. 합의 첨자 이름은 바꿔도 값이 같아요. $$\sum_{i,j=1}^{N} x_j^2 = N\sum_{j=1}^{N} x_j^2 = N\sum_{i=1}^{N} x_i^2$$
  4. 가운데 항은 두 합의 곱으로 나눠져요. $$\sum_{i,j=1}^{N} x_i x_j = \left(\sum_{i=1}^{N} x_i\right)\left(\sum_{j=1}^{N} x_j\right) = \left(\sum_{i=1}^{N} x_i\right)^2$$
  5. 세 결과를 모으고 $\frac{1}{N^2}$을 곱해요. $$\frac{1}{N^2}\sum_{i,j=1}^{N}(x_i - x_j)^2 = \frac{1}{N^2}\left[2N\sum_{i=1}^{N} x_i^2 - 2\left(\sum_{i=1}^{N} x_i\right)^2\right]$$
  6. $\frac{1}{N^2}$을 괄호 안에 나눠 넣어요. 둘째 항에서는 $\frac{1}{N^2} = \left(\frac{1}{N}\right)^2$이라 제곱 안으로 들어가요. $$= 2\left[\frac{1}{N}\sum_{i=1}^{N} x_i^2 - \left(\frac{1}{N}\sum_{i=1}^{N} x_i\right)^2\right]$$
  7. 수업과의 연결: 괄호 안은 관측값으로 계산한 "제곱의 평균 빼기 평균의 제곱"이에요. 0930 수업의 $\operatorname{Cov}[X, Y] = \mathbb{E}[XY] - \mathbb{E}[X]\,\mathbb{E}[Y]$에서 $Y$ 자리에 $X$를 넣고, 기댓값을 $N$개 관측값의 평균으로 바꾼 모양이에요.

정답: $\frac{1}{N^2}\sum_{i,j=1}^{N}(x_i - x_j)^2 = \frac{1}{N^2}\left[2N\sum_{i=1}^{N} x_i^2 - 2\left(\sum_{i=1}^{N} x_i\right)^2\right] = 2\left[\frac{1}{N}\sum_{i=1}^{N} x_i^2 - \left(\frac{1}{N}\sum_{i=1}^{N} x_i\right)^2\right]$
