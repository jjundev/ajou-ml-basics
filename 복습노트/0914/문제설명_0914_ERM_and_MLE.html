P1. 1을 붙여 어파인 예측기 계산하기

MML Example 8.1 · 원 문제 보기

주어진 조건

특징이 $D = 2$개인 예제 하나가 있어요. 특징 값은 $x_n^{(1)} = 2$, $x_n^{(2)} = -1$이에요. 교과서처럼 맨 앞에 단위 특징 $x^{(0)} = 1$을 붙여서 예측기를 $f(\mathbf{x}_n, \boldsymbol{\theta}) = \boldsymbol{\theta}^\top \mathbf{x}_n$으로 써요. 파라미터는 $\boldsymbol{\theta} = [\theta_0, \theta_1, \theta_2]^\top = [\tfrac{1}{2}, 3, 2]^\top$이에요.

구할 것

  1. (a) 1을 붙인 벡터 $\mathbf{x}_n$을 써 보세요. 길이는 몇인가요?
  2. (b) 예측값 $f(\mathbf{x}_n, \boldsymbol{\theta})$를 구해 보세요.

무엇을 구하는 문제인가요?

1을 붙여 어파인 예측기 계산하기를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

“맨 앞에 1”은 바이어스(bias)를 내적에 흡수하는 단서예요. $f=\theta_0+\theta_1x^{(1)}+\theta_2x^{(2)}$에서 상수항도 $\theta_0\cdot1$로 써요. 특징과 계수의 순서가 같아야 해요.

종이에 적을 첫 줄

$\mathbf x=[1,2,-1]^\top$을 적어요.

왜 이렇게 푸는지 함께 따라가요

맨 앞에 1을 붙이면 $\mathbf{x}_n = [1, x_n^{(1)}, x_n^{(2)}]^\top = [1, 2, -1]^\top$이에요.

길이는 $D + 1 = 3$이에요. 그래서 예측기는 $f : \mathbb{R}^{D+1} \to \mathbb{R}$인 함수가 돼요.

내적을 계산해요: $\boldsymbol{\theta}^\top \mathbf{x}_n = \tfrac{1}{2} \cdot 1 + 3 \cdot 2 + 2 \cdot (-1)$

$= \tfrac{1}{2} + 6 - 2 = \frac{9}{2}$

어파인 꼴로 확인해요: $\theta_0 + \theta_1 x_n^{(1)} + \theta_2 x_n^{(2)} = \tfrac{1}{2} + 6 - 2$로 같아요.

수업과의 연결: 교수님이 "가장 중요한 수식"이라고 한 바이어스 흡수예요. $b = \theta_0 \cdot 1$로 보고 1을 붙이면 어파인 함수가 내적 하나가 돼요 (0914 26:00).

(a)

첫 성분은 1이고 나머지는 주어진 입력이에요. 계수 벡터와 모두 길이 3이에요.

(b)

어파인 식으로 직접 계산해도 $1/2+6-2=9/2$예요.

완성 답과 검산

(a) 검산

첫 성분은 1이고 나머지는 주어진 입력이에요. 계수 벡터와 모두 길이 3이에요.

(b) 검산

어파인 식으로 직접 계산해도 $1/2+6-2=9/2$예요.

정답: (a) $\mathbf{x}_n = [1, 2, -1]^\top$, 길이 $D + 1 = 3$ (b) $f(\mathbf{x}_n, \boldsymbol{\theta}) = \frac{9}{2}$

여기서 주의해요

특징 두 개와 바이어스 한 개라서 길이는 2가 아니라 3이에요.

설명을 닫고 다시 해요

  1. $\mathbf x=[1,2,-1]^\top$을 적어요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 특징 두 개와 바이어스 한 개라서 길이는 2가 아니라 3이에요.

떠올릴 개념·공식

“맨 앞에 1”은 바이어스(bias)를 내적에 흡수하는 단서예요. $f=\theta_0+\theta_1x^{(1)}+\theta_2x^{(2)}$

첫 줄

$\mathbf x=[1,2,-1]^\top$을 적어요.

검산

첫 성분은 1이고 나머지는 주어진 입력이에요. 계수 벡터와 모두 길이 3이에요. 어파인 식으로 직접 계산해도 $1/2+6-2=9/2$예요.

P2. 두 파라미터의 제곱 손실 평균 비교하기

MML Example 8.2 · 원 문제 보기

주어진 조건

학습 데이터가 세 개 있어요: $(x, y) = (0, 1), (1, 4), (2, 4)$. 각 입력 앞에 1을 붙여 $\mathbf{x}_n = [1, x_n]^\top$으로 쓰고, 예측기는 $f(\mathbf{x}_n, \boldsymbol{\theta}) = \boldsymbol{\theta}^\top \mathbf{x}_n$이에요. 제곱 손실의 평균은 행렬로 $\frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$이에요.

구할 것

  1. (a) 데이터 행렬 $\mathbf{X}$와 라벨 벡터 $\mathbf{y}$를 써 보세요.
  2. (b) $\boldsymbol{\theta}_A = [1, 2]^\top$과 $\boldsymbol{\theta}_B = [\tfrac{3}{2}, \tfrac{3}{2}]^\top$ 각각에 대해 $\frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$를 구해 보세요.
  3. (c) 둘 중 어느 쪽의 평균 손실이 더 작나요?

무엇을 구하는 문제인가요?

두 파라미터의 제곱 손실 평균 비교하기를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

제곱 손실(squared loss)은 오차를 제곱한 값이에요. $N^{-1}\|\mathbf y-X\theta\|^2$에서 $X$의 한 행은 한 예제, $\mathbf y$는 실제 출력이에요. 같은 데이터의 두 후보를 이 값으로 비교해요.

종이에 적을 첫 줄

$X=[[1,0],[1,1],[1,2]]$, $\mathbf y=[1,4,4]^\top$을 적어요.

왜 이렇게 푸는지 함께 따라가요

$\mathbf{X} = [\mathbf{x}_1, \mathbf{x}_2, \mathbf{x}_3]^\top \in \mathbb{R}^{3 \times 2}$이고, 행은 차례로 $[1, 0]$, $[1, 1]$, $[1, 2]$예요. $\mathbf{y} = [1, 4, 4]^\top$이에요.

$\boldsymbol{\theta}_A$: $\hat{\mathbf{y}} = \mathbf{X}\boldsymbol{\theta}_A = [1, 3, 5]^\top$

$\mathbf{y} - \hat{\mathbf{y}} = [0, 1, -1]^\top$, 제곱합은 $0 + 1 + 1 = 2$

$\frac{1}{3}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}_A\|^2 = \frac{2}{3}$

$\boldsymbol{\theta}_B$: $\hat{\mathbf{y}} = \mathbf{X}\boldsymbol{\theta}_B = [\tfrac{3}{2}, 3, \tfrac{9}{2}]^\top$

$\mathbf{y} - \hat{\mathbf{y}} = [-\tfrac{1}{2}, 1, -\tfrac{1}{2}]^\top$, 제곱합은 $\tfrac{1}{4} + 1 + \tfrac{1}{4} = \tfrac{3}{2}$

$\frac{1}{3}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}_B\|^2 = \frac{1}{2}$

$\frac{1}{2} \lt \frac{2}{3}$이니까 $\boldsymbol{\theta}_B$가 이 데이터에 더 잘 맞아요.

수업과의 연결: 칠판에서 $\frac{1}{N}\sum_n (y_n - \boldsymbol{\theta}^\top \mathbf{x}_n)^2$을 $\frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$ 한 줄로 바꾼 "김밥 재료 손질"을 숫자로 해 본 거예요. 교수님이 "산수니까 해 보세요"라고 남긴 부분이에요 (0914 37:24).

(a)

3예제×2특징이므로 X는 3×2, y는 3×1이에요.

(b)

A의 잔차는 [0,1,-1], B는 [-1/2,1,-1/2]예요. 제곱합 2와 3/2를 3으로 나누면 2/3과 1/2예요.

(c)

$2/3-1/2=1/6>0$이므로 B예요. 이는 두 후보끼리 비교한 결과이며 전역 최적해를 증명한 것은 아니에요.

완성 답과 검산

(a) 검산

3예제×2특징이므로 X는 3×2, y는 3×1이에요.

(b) 검산

A의 잔차는 [0,1,-1], B는 [-1/2,1,-1/2]예요. 제곱합 2와 3/2를 3으로 나누면 2/3과 1/2예요.

(c) 검산

$2/3-1/2=1/6>0$이므로 B예요. 이는 두 후보끼리 비교한 결과이며 전역 최적해를 증명한 것은 아니에요.

정답: $\boldsymbol{\theta}_A$는 $\frac{2}{3}$, $\boldsymbol{\theta}_B$는 $\frac{1}{2}$이에요. $\boldsymbol{\theta}_B$가 더 작아요.

여기서 주의해요

노름과 노름의 제곱을 구별하고 마지막에 N=3으로 나눠요.

설명을 닫고 다시 해요

  1. $X=[[1,0],[1,1],[1,2]]$, $\mathbf y=[1,4,4]^\top$을 적어요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 노름과 노름의 제곱을 구별하고 마지막에 N=3으로 나눠요.

떠올릴 개념·공식

제곱 손실(squared loss)은 오차를 제곱한 값이에요. $N^{-1}\|\mathbf y-X\theta\|^2$

첫 줄

$X=[[1,0],[1,1],[1,2]]$, $\mathbf y=[1,4,4]^\top$을 적어요.

검산

3예제×2특징이므로 X는 3×2, y는 3×1이에요. A의 잔차는 [0,1,-1], B는 [-1/2,1,-1/2]예요. 제곱합 2와 3/2를 3으로 나누면 2/3과 1/2예요. $2/3-1/2=1/6>0$이므로 B예요. 이는 두 후보끼리 비교한 결과이며 전역 최적해를 증명한 것은 아니에요.

P3. λ에 따라 달라지는 정규화 최소제곱의 선택

MML Example 8.3 · 원 문제 보기

주어진 조건

학습 데이터가 $(x, y) = (0, 1), (1, 3), (2, 5)$예요. 입력 앞에 1을 붙여 $\mathbf{x}_n = [1, x_n]^\top$으로 쓰고, 예측기는 $\boldsymbol{\theta}^\top \mathbf{x}_n$이에요. 정규화된 문제의 목적함수는 다음과 같아요.

$$J(\boldsymbol{\theta}) = \frac{1}{N}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2 + \lambda \|\boldsymbol{\theta}\|^2$$

후보는 $\boldsymbol{\theta}_A = [1, 2]^\top$과 $\boldsymbol{\theta}_B = [1, 1]^\top$ 두 개예요.

구할 것

  1. (a) $\lambda = 0$일 때 두 후보의 $J$를 구하고, 더 작은 쪽을 골라 보세요.
  2. (b) $\lambda = 1$일 때 두 후보의 $J$를 구하고, 더 작은 쪽을 골라 보세요.

무엇을 구하는 문제인가요?

λ에 따라 달라지는 정규화 최소제곱의 선택를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

정규화(regularization)는 적합 오차와 계수 크기를 함께 재요. $J=N^{-1}\|y-X\theta\|^2+\lambda\|\theta\|^2$에서 λ는 벌점의 세기예요. 이 문제는 바이어스까지 벌점에 포함해요.

종이에 적을 첫 줄

$J_A=0+5\lambda$, $J_B=5/3+2\lambda$를 적어요.

왜 이렇게 푸는지 함께 따라가요

$\boldsymbol{\theta}_A$의 추정치는 $[1, 3, 5]^\top$이라 $\mathbf{y}$와 똑같아요. 그래서 $\frac{1}{3}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}_A\|^2 = 0$이에요.

$\boldsymbol{\theta}_B$의 추정치는 $[1, 2, 3]^\top$이고 잔차는 $[0, 1, 2]^\top$이에요. 그래서 $\frac{1}{3}(0 + 1 + 4) = \frac{5}{3}$이에요.

파라미터 크기: $\|\boldsymbol{\theta}_A\|^2 = 1 + 4 = 5$, $\|\boldsymbol{\theta}_B\|^2 = 1 + 1 = 2$

(a)

$\lambda = 0$: $J_A = 0$, $J_B = \frac{5}{3}$이라 $\boldsymbol{\theta}_A$를 골라요.

(b)

$\lambda = 1$: $J_A = 0 + 5 = 5$, $J_B = \frac{5}{3} + 2 = \frac{11}{3}$이라 $\boldsymbol{\theta}_B$를 골라요.

학습 데이터에 딱 맞는 $\boldsymbol{\theta}_A$도 크기가 크면 $\lambda \|\boldsymbol{\theta}\|^2$ 벌점을 받아 밀려나요.

수업과의 연결: 교수님이 $\lambda = 0$이면 "딱 과적합되기 좋지"라고 하고, $\lambda = 1$처럼 양수를 주면 원점에서의 거리까지 따져 균형을 잡는다고 한 장면이에요 (0914 48:44–49:53).

완성 답과 검산

(a) 검산

λ=0을 대입하면 0<5/3이므로 A예요.

(b) 검산

λ=1에서는 11/3<5예요. 교차점은 λ=5/9이므로 1에서 B를 고르는 것이 일관돼요.

정답: (a) $\lambda = 0$이면 $J_A = 0$, $J_B = \frac{5}{3}$ 이라 $\boldsymbol{\theta}_A$ (b) $\lambda = 1$이면 $J_A = 5$, $J_B = \frac{11}{3}$ 이라 $\boldsymbol{\theta}_B$

여기서 주의해요

평균 손실의 1/N을 벌점에도 임의로 곱하지 않아요.

설명을 닫고 다시 해요

  1. $J_A=0+5\lambda$, $J_B=5/3+2\lambda$를 적어요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 평균 손실의 1/N을 벌점에도 임의로 곱하지 않아요.

떠올릴 개념·공식

정규화(regularization)는 적합 오차와 계수 크기를 함께 재요. $J=N^{-1}\|y-X\theta\|^2+\lambda\|\theta\|^2$에서 λ는 벌점의 세기예요.

첫 줄

$J_A=0+5\lambda$, $J_B=5/3+2\lambda$를 적어요.

검산

λ=0을 대입하면 0<5/3이므로 A예요. λ=1에서는 11/3<5예요. 교차점은 λ=5/9이므로 1에서 B를 고르는 것이 일관돼요.

조건·구분

이 문제는 바이어스까지 벌점에 포함해요. 평균 손실의 $1/N$을 벌점에 추가로 곱하지 않고, 주어진 두 후보끼리 비교해요.

P4. 가우시안 우도의 평균과 분산 읽기

MML Example 8.4 · 원 문제 보기

주어진 조건

라벨에 평균 0인 가우시안 노이즈 $\varepsilon_n \sim \mathcal{N}(0, \sigma^2)$가 더해지고, 예측에는 선형 모델 $\mathbf{x}_n^\top \boldsymbol{\theta}$를 쓴다고 가정해요. 그러면 예제 하나의 우도는 $p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta}) = \mathcal{N}(y_n \mid \mathbf{x}_n^\top \boldsymbol{\theta}, \sigma^2)$예요. 이제 $\mathbf{x}_n = [1, 2]^\top$, $\boldsymbol{\theta} = [1, 2]^\top$, $\sigma^2 = 1$이라고 해요.

구할 것

$y_n$의 조건부 분포의 평균과 분산을 구해 보세요.

무엇을 구하는 문제인가요?

가우시안 우도의 평균과 분산 읽기를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

조건부 가우시안(Gaussian likelihood)은 입력과 계수를 고정한 뒤 잡음만 랜덤하게 봐요. $y=x^\top\theta+\epsilon$이면 평균은 $x^\top\theta$, 분산은 잡음 분산 σ²예요.

종이에 적을 첫 줄

$x^\top\theta=1\cdot1+2\cdot2=5$예요.

왜 이렇게 푸는지 함께 따라가요

풀이

평균: $\mathbf{x}_n^\top \boldsymbol{\theta} = 1 \cdot 1 + 2 \cdot 2 = 5$

분산: 노이즈 분산이 그대로 남아서 $\sigma^2 = 1$이에요.

그래서 $y_n \mid \mathbf{x}_n, \boldsymbol{\theta} \sim \mathcal{N}(5, 1)$이에요.

수업과의 연결: 칠판에서 $y_n = \mathbf{x}_n^\top \boldsymbol{\theta} + w$로 suppose하고, 상수를 더하면 평균만 옮겨지고 분산은 그대로라서 $\mathcal{N}(\mathbf{x}_n^\top \boldsymbol{\theta}, \sigma^2)$가 된다고 한 부분이에요 (0914 65:40–69:39).

완성 답과 검산

검산

$E[y]=5+E[\epsilon]=5$, $Var(y)=Var(\epsilon)=1$로 정의에서 확인돼요.

정답: 조건부 분포의 평균 $5$, 분산 $1$

여기서 주의해요

가우시안 두 번째 인자는 표준편차가 아니라 분산이에요.

설명을 닫고 다시 해요

  1. $x^\top\theta=1\cdot1+2\cdot2=5$예요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 가우시안 두 번째 인자는 표준편차가 아니라 분산이에요.

떠올릴 개념·공식

조건부 가우시안(Gaussian likelihood)은 입력과 계수를 고정한 뒤 잡음만 랜덤하게 봐요. $y=x^\top\theta+\epsilon$이면 평균은 $x^\top\theta$, 분산은 잡음 분산 σ²예요.

첫 줄

$x^\top\theta=1\cdot1+2\cdot2=5$예요.

검산

$E[y]=5+E[\epsilon]=5$, $Var(y)=Var(\epsilon)=1$로 정의에서 확인돼요.

조건·구분

입력·계수를 고정한 조건부 분포이고, 가우시안의 두 번째 인자는 표준편차가 아닌 분산이에요.

P5. 음의 로그우도와 최소제곱의 순서 비교하기

MML Example 8.5 · 원 문제 보기

주어진 조건

데이터는 $(x, y) = (0, 1), (1, 4), (2, 4)$이고, 입력 앞에 1을 붙여 $\mathbf{x}_n = [1, x_n]^\top$으로 써요. 각 라벨은 $p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta}) = \mathcal{N}(y_n \mid \mathbf{x}_n^\top \boldsymbol{\theta}, \sigma^2)$를 따르고 $\sigma^2 = 1$이에요. 예제들은 i.i.d.라고 가정해요.

구할 것

  1. (a) 음의 로그우도 $\mathcal{L}(\boldsymbol{\theta}) = -\sum_{n=1}^{N} \log p(y_n \mid \mathbf{x}_n, \boldsymbol{\theta})$를 제곱합 항과 상수항으로 나눠 써 보세요.
  2. (b) $\boldsymbol{\theta}_A = [1, 2]^\top$과 $\boldsymbol{\theta}_B = [\tfrac{3}{2}, \tfrac{3}{2}]^\top$의 $\mathcal{L}$을 자연로그로 소수 셋째 자리까지 구해 보세요.
  3. (c) 어느 쪽의 $\mathcal{L}$이 더 작나요? 제곱 손실 합으로 비교한 순서와 같은가요?

무엇을 구하는 문제인가요?

음의 로그우도와 최소제곱의 순서 비교하기를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

i.i.d. 가우시안은 우도가 곱이고 로그우도는 합이에요. 음의 로그우도(negative log likelihood)는 $SSE/(2\sigma^2)+N\log(2\pi\sigma^2)/2$예요. 분산이 고정이고 공통이면 SSE와 같은 순서를 줘요.

종이에 적을 첫 줄

$SSE=\sum_n(y_n-x_n^\top\theta)^2$를 먼저 계산해요.

왜 이렇게 푸는지 함께 따라가요

$\mathcal{L}(\boldsymbol{\theta}) = -\sum_{n=1}^{N} \log \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2}{2\sigma^2}\right)$

$= \frac{1}{2\sigma^2}\sum_{n=1}^{N} (y_n - \mathbf{x}_n^\top \boldsymbol{\theta})^2 + \frac{N}{2}\log(2\pi\sigma^2)$

상수항: $N = 3$, $\sigma^2 = 1$이면 $\frac{3}{2}\log(2\pi) \approx 2.757$이에요. $\boldsymbol{\theta}$와 상관없어요.

$\boldsymbol{\theta}_A$: 추정치 $[1, 3, 5]^\top$, 잔차 $[0, 1, -1]^\top$, 제곱합 $2$라서 첫 항은 $\frac{2}{2} = 1$이에요.

$\mathcal{L}(\boldsymbol{\theta}_A) = 1 + \frac{3}{2}\log(2\pi) \approx 3.757$

$\boldsymbol{\theta}_B$: 추정치 $[\tfrac{3}{2}, 3, \tfrac{9}{2}]^\top$, 잔차 $[-\tfrac{1}{2}, 1, -\tfrac{1}{2}]^\top$, 제곱합 $\tfrac{3}{2}$라서 첫 항은 $\frac{3}{4}$이에요.

$\mathcal{L}(\boldsymbol{\theta}_B) = \frac{3}{4} + \frac{3}{2}\log(2\pi) \approx 3.507$

$\boldsymbol{\theta}_B$가 더 작아요. 상수항이 같으니 순서는 제곱합($2$ 대 $\tfrac{3}{2}$)이 정하고, 제곱 손실로 비교한 순서와 같아요.

수업과의 연결: 칠판에서 $\frac{N}{2}\log(2\pi\sigma^2)$ 같은 상수항은 "무시하고" 넘어가고, 음의 로그우도 최소화가 최소제곱과 같은 해를 준다고 결론 낸 부분이에요 (0914 69:54–71:15).

(a)

정규화 상수의 음의 로그는 예제마다 log(2π)/2이고 세 번 더해요.

(b)

별도 계산에서 A=3.7568156…, B=3.5068156…이므로 반올림하면 3.757과 3.507예요.

(c)

두 값 차이는 (2−3/2)/2=1/4예요. 같은 양의 배율과 같은 상수이므로 순서가 유지돼요.

완성 답과 검산

(a) 검산

정규화 상수의 음의 로그는 예제마다 log(2π)/2이고 세 번 더해요.

(b) 검산

별도 계산에서 A=3.7568156…, B=3.5068156…이므로 반올림하면 3.757과 3.507예요.

(c) 검산

두 값 차이는 (2−3/2)/2=1/4예요. 같은 양의 배율과 같은 상수이므로 순서가 유지돼요.

정답: $\mathcal{L}(\boldsymbol{\theta}_A) = 1 + \frac{3}{2}\log(2\pi) \approx 3.757$, $\mathcal{L}(\boldsymbol{\theta}_B) = \frac{3}{4} + \frac{3}{2}\log(2\pi) \approx 3.507$이라 $\boldsymbol{\theta}_B$가 더 작고, 최소제곱으로 비교한 순서와 같아요.

여기서 주의해요

로그 상수는 최적 후보 선택에는 지워도 실제 수치 계산에서는 남겨요.

설명을 닫고 다시 해요

  1. $SSE=\sum_n(y_n-x_n^\top\theta)^2$를 먼저 계산해요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 로그 상수는 최적 후보 선택에는 지워도 실제 수치 계산에서는 남겨요.

떠올릴 개념·공식

i.i.d. 가우시안은 우도가 곱이고 로그우도는 합이에요. 음의 로그우도(negative log likelihood)는 $SSE/(2\sigma^2)+N\log(2\pi\sigma^2)/2$예요.

첫 줄

$SSE=\sum_n(y_n-x_n^\top\theta)^2$를 먼저 계산해요.

검산

정규화 상수의 음의 로그는 예제마다 log(2π)/2이고 세 번 더해요. 별도 계산에서 A=3.7568156…, B=3.5068156…이므로 반올림하면 3.757과 3.507예요. 두 값 차이는 (2−3/2)/2=1/4예요. 같은 양의 배율과 같은 상수이므로 순서가 유지돼요.

조건·구분

공통 분산을 고정했으므로 SSE에 같은 양의 배율과 상수를 더해도 후보 순서는 같아요. NLL의 실제 수치에는 로그 상수항을 남겨요.

P6. 두 벡터 사이의 유클리드 거리

MML Exercise 3.3 · 원 문제 보기

주어진 조건

두 벡터 $\mathbf{x} = [1, 2, 3]^\top$, $\mathbf{y} = [-1, -1, 0]^\top$이 있어요.

구할 것

내적을 $\langle \mathbf{x}, \mathbf{y} \rangle := \mathbf{x}^\top \mathbf{y}$로 둘 때, 두 벡터 사이의 거리 $d(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|$를 구해 보세요.

무엇을 구하는 문제인가요?

두 벡터 사이의 유클리드 거리를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

유클리드 거리(Euclidean distance)는 차이 벡터의 길이예요. $d=\sqrt{(x-y)^\top(x-y)}$에서 내적은 대응 성분 곱의 합이에요. 이 문제는 표준 내적을 지정했어요.

종이에 적을 첫 줄

$x-y=[2,3,3]^\top$예요.

왜 이렇게 푸는지 함께 따라가요

풀이

차이 벡터: $\mathbf{x} - \mathbf{y} = [1 - (-1), 2 - (-1), 3 - 0]^\top = [2, 3, 3]^\top$

자기 내적: $(\mathbf{x} - \mathbf{y})^\top(\mathbf{x} - \mathbf{y}) = 4 + 9 + 9 = 22$

$d(\mathbf{x}, \mathbf{y}) = \sqrt{22} \approx 4.690$

수업과의 연결: 교수님이 2-노름 $\|\boldsymbol{\theta}\|_2$를 "원점에서의 거리"라고 설명했어요. 여기서는 원점 대신 $\mathbf{y}$에서 잰 거리예요 (0914 49:56).

완성 답과 검산

검산

반대로 y−x=[−2,−3,−3]을 써도 제곱합은22, 거리는 $\sqrt{22}$예요.

정답: $d(\mathbf{x}, \mathbf{y}) = \sqrt{22} \approx 4.690$

여기서 주의해요

22는 거리의 제곱이에요. 거리에는 제곱근이 필요해요.

설명을 닫고 다시 해요

  1. $x-y=[2,3,3]^\top$예요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 22는 거리의 제곱이에요. 거리에는 제곱근이 필요해요.

떠올릴 개념·공식

유클리드 거리(Euclidean distance)는 차이 벡터의 길이예요. $d=\sqrt{(x-y)^\top(x-y)}$

첫 줄

$x-y=[2,3,3]^\top$예요.

검산

반대로 y−x=[−2,−3,−3]을 써도 제곱합은22, 거리는 $\sqrt{22}$예요.

조건·구분

$22$는 거리의 제곱이고 표준 내적에서 거리는 $\sqrt{22}$예요.

P7. 삼차함수의 정상점과 종류

MML Exercise 7.1 · 원 문제 보기

주어진 조건

일변수 함수 $f(x) = x^3 + 6x^2 - 3x - 5$가 있어요.

구할 것

정상점(stationary point)을 모두 찾고, 각각 극대인지 극소인지 안장점인지 판정해 보세요.

무엇을 구하는 문제인가요?

삼차함수의 정상점과 종류를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

정상점(stationary point)은 미분이 0인 점이에요. $f\prime\prime$이 음이면 극대, 양이면 극소예요. 도함수 0만으로 최대/최소라고 결론내리지 않아요.

종이에 적을 첫 줄

$f\prime(x)=3x^2+12x-3$을 먼저 적어요.

왜 이렇게 푸는지 함께 따라가요

풀이

$f'(x) = 3x^2 + 12x - 3$

$f'(x) = 0 \Rightarrow x^2 + 4x - 1 = 0 \Rightarrow x = -2 \pm \sqrt{5}$

정상점은 $x = -2 + \sqrt{5} \approx 0.236$과 $x = -2 - \sqrt{5} \approx -4.236$ 두 개예요.

$f''(x) = 6x + 12$

$x = -2 + \sqrt{5}$: $f'' = 6\sqrt{5} \gt 0$이라 극소예요.

$x = -2 - \sqrt{5}$: $f'' = -6\sqrt{5} \lt 0$이라 극대예요.

함숫값: $x^2 = 1 - 4x$를 쓰면 $f(x) = -10x - 3$으로 줄어요.

그래서 $f(-2 + \sqrt{5}) = 17 - 10\sqrt{5} \approx -5.36$, $f(-2 - \sqrt{5}) = 17 + 10\sqrt{5} \approx 39.36$이에요.

수업과의 연결: 교수님은 $\boldsymbol{\theta}$를 하나씩 바꿔 보는 무식한 방법 대신 least squares 알고리즘과 pseudo-inverse 같은 체계적인 방법이 있다고 했어요. 그런 방법이 찾는 것도 이 문제처럼 목적함수가 가장 작아지는 점이에요 (0914 40:04–41:07).

완성 답과 검산

검산

아래 독립 symbolic 미분으로 도함수의 근과 각 근에서 이계도함수 부호를 확인해요. 삼차함수는 양끝이 반대 방향으로 무한히 가므로 전역 극값이라고 쓰지 않아요.

정답: $x = -2 + \sqrt{5}$에서 극소($f = 17 - 10\sqrt{5} \approx -5.36$), $x = -2 - \sqrt{5}$에서 극대($f = 17 + 10\sqrt{5} \approx 39.36$)예요. 안장점은 없어요.

여기서 주의해요

국소 극값과 전체 실수 구간의 전역 최대·최소는 다른 질문이에요.

설명을 닫고 다시 해요

  1. $f\prime(x)=3x^2+12x-3$을 먼저 적어요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 국소 극값과 전체 실수 구간의 전역 최대·최소는 다른 질문이에요.

떠올릴 개념·공식

정상점(stationary point)은 미분이 0인 점이에요. $f\prime\prime$이 음이면 극대, 양이면 극소예요.

첫 줄

$f\prime(x)=3x^2+12x-3$을 먼저 적어요.

검산

아래 독립 symbolic 미분으로 도함수의 근과 각 근에서 이계도함수 부호를 확인해요. 삼차함수는 양끝이 반대 방향으로 무한히 가므로 전역 극값이라고 쓰지 않아요.

조건·구분

정상점 $x=-2-\sqrt5$에서는 $f^{\prime\prime}<0$이라 국소 극대, $x=-2+\sqrt5$에서는 $f^{\prime\prime}>0$이라 국소 극소예요. 도함수 0만으로 판정하지 않으며, 이 삼차함수의 전역 최대·최소와 구별해요.
