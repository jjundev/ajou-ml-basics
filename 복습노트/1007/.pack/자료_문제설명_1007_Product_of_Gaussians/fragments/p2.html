무엇을 구하는 문제인가요?

한 점에서 본 함수값의 평균과 분산를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

한 점의 함수값은 랜덤 계수의 스칼라 가중합이에요. $E[f]=\phi^\top E[\theta]$, $Var(f)=\phi^\top S_0\phi$이고 S0=I/2예요. 각 계수의 분산에 특징의 제곱을 곱해 더해요.

종이에 적을 첫 줄

$\phi(0)=[1,0,0,0,0,0]^\top$예요.

왜 이렇게 푸는지 함께 따라가요

풀이

$x_*$를 고정하면 $\mathbf{A} = \boldsymbol{\phi}(x_*)^\top$ ($1 \times 6$ 행벡터), $\mathbf{b} = 0$으로 놓을 수 있어요. 그러면 $f(x_*) = \mathbf{A}\boldsymbol{\theta} + \mathbf{b}$예요.

평균은 $E[\mathbf{A}\mathbf{X} + \mathbf{b}] = \mathbf{A}E[\mathbf{X}] + \mathbf{b}$로 구해요. $$E[f(x_*)] = \boldsymbol{\phi}(x_*)^\top E[\boldsymbol{\theta}] = \boldsymbol{\phi}(x_*)^\top\mathbf{0} = 0$$ 어느 $x_*$에서든 평균은 0이에요.

분산은 $\mathbf{A}\Sigma_{\mathbf{X}}\mathbf{A}^\top$로 구해요. $\Sigma_{\boldsymbol{\theta}} = \frac{1}{2}\mathbf{I}$이니까 $$\mathrm{var}[f(x_*)] = \boldsymbol{\phi}(x_*)^\top\left(\frac{1}{2}\mathbf{I}\right)\boldsymbol{\phi}(x_*) = \frac{1}{2}\boldsymbol{\phi}(x_*)^\top\boldsymbol{\phi}(x_*) = \frac{1}{2}\sum_{k=0}^{5} x_*^{2k}$$

$x_* = 0$이면 $\boldsymbol{\phi}(0) = [1, 0, 0, 0, 0, 0]^\top$이라서 $\boldsymbol{\phi}(0)^\top\boldsymbol{\phi}(0) = 1$이에요. $$\mathrm{var}[f(0)] = \frac{1}{2} \cdot 1 = \frac{1}{2}$$

$x_* = 1$이면 $\boldsymbol{\phi}(1) = [1, 1, 1, 1, 1, 1]^\top$이라서 $\boldsymbol{\phi}(1)^\top\boldsymbol{\phi}(1) = 6$이에요. $$\mathrm{var}[f(1)] = \frac{1}{2} \cdot 6 = 3$$

가우시안의 아핀 변환은 가우시안이니까 $p(f(0)) = \mathcal{N}\left(0, \frac{1}{2}\right)$, $p(f(1)) = \mathcal{N}(0, 3)$이에요.

완성 답과 검산

검산

0에서는 상수계수만 남아분산1/2예요. 1에서는 독립계수6개의 합이라6×1/2=3이에요. 평균은 두 점 모두0이에요.

정답: 평균은 두 점 모두 $E[f(x_*)] = 0$이에요. 분산은 $\mathrm{var}[f(0)] = \frac{1}{2}$, $\mathrm{var}[f(1)] = 3$이에요.

여기서 주의해요

분산1/2를 표준편차로 읽지 않아요. 특징 길이가6이라고 항상 분산3인 것도 아니에요.

설명을 닫고 다시 해요

  1. $\phi(0)=[1,0,0,0,0,0]^\top$예요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 분산1/2를 표준편차로 읽지 않아요. 특징 길이가6이라고 항상 분산3인 것도 아니에요.
