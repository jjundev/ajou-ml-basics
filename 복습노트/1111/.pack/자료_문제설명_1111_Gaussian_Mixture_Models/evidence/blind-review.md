# 1111 문제·소문항 독립 풀이

입력은 work/blind-problems.html 및 P3 그림이다. 아래 결과와 검산기를 먼저 고정하고 원래 카드의 답과 풀이, manifest 답안, answers.py는 이후에만 확인한다. 전산 검산은 work/blind-review-calculations.py, 유리수는 Fraction, 가우시안 밀도는 Decimal 정밀도 72자리를 사용했다.

| 문항 | 독립 풀이와 결과 |
|---|---|
| P1(a) | 각 뽑기의 미국 동전 확률은 3/10, 그 외는 7/10이다. 복원하고 다시 뽑으므로 순서가 있는 네 경우를 계산한다. X=0: (7/10)²=49/100. X=1: 2(3/10)(7/10)=21/50. X=2: (3/10)²=9/100. |
| P1(b) | (49+42+9)/100=1. |
| P2(a) | 전체 빈도 90, x₃열은 3+6+9=18, y₂행은 2+4+6+8+10=30. P(X=x₃)=18/90=1/5, P(Y=y₂)=30/90=1/3. |
| P2(b) | 교차 빈도 6, 교차 확률 6/90. y₂를 x₃에 조건부로 읽으면 (6/90)/(18/90)=6/18=1/3, x₃를 y₂에 조건부로 읽으면 (6/90)/(30/90)=6/30=1/5. |
| P3(a) | 결합 밀도 그림의 왼쪽 아래쪽과 오른쪽 중앙에 높은 닫힌 등고선 무리가 하나씩 있다. 각 무리 안의 별 표시도 봉우리 위치와 일치하므로 2개다. |
| P3(b) | 위 X₁ 곡선은 골짜기로 분리된 두 봉우리를 보여 2개로 결합 밀도와 같다. 오른쪽 X₂ 곡선은 오른쪽으로 가장 많이 돌출된 봉우리 하나를 보여 1개로 결합 밀도와 다르다. |
| P4(a) | x=0이면 0.7⁰·0.3¹=0.3, x=1이면 0.7¹·0.3⁰=0.7. |
| P4(b) | E[X]=0·(3/10)+1·(7/10)=7/10. |
| P5(a) | 지지 구간 왼쪽의 밀도가 0이다. 0≤t≤1에서는 F_X(t)=∫₀ᵗ3x² dx=[x³]₀ᵗ=t³. |
| P5(b) | F_X(1/2)=(1/2)³=1/8. |
| P6(a) | p(x)=(N(x｜−4,1)+N(x｜0,1/5)+N(x｜8,3))/3. x=0에서 세 가중 성분은 각각 0.00004461007525496178, 0.2973540193587952, 0.000001789590683182301. 합은 0.297400419024733330이고 넷째 자리까지 0.2974. |
| P6(b) | 위 세 가중 밀도를 비교하면 2번이 최대다. |
| P7(a) | `a_k(x)=exp(−(x−μ_k)²/(2σ_k²))/sqrt(σ_k²)`로 두면 공통인 1/(3sqrt(2π))가 약분된다. 각 a_k를 a₁+a₂+a₃으로 나눈다. x=−1: (0.05706947239711159, 0.9429264613639668, 0.000004066238921561) → (0.057,0.943,0.000). x=2: (0.000009937083619908, 0.06623686999396746, 0.9337531929224126) → (0.000,0.066,0.934). |
| P7(b) | 최대는 x=−1에서 성분 2, x=2에서 성분 3. |
| P8(a) | 주어진 표의 열별 합은 2+0.057+0.001=2.058, 0.943+0.999+0.066=2.008, 0.934+1+1=2.934. 세 합의 합은 7로 모든 행의 합 1을 더한 값과 같다. |
| P8(b) | 2.934>2.058>2.008이므로 성분 3. |

P6에 나열된 일곱 관측값은 x=0의 밀도와 가중 성분 최대값을 구하는 데 필요하지 않다. P7의 0.000은 양수인 극소 책임도를 반올림한 표기다. P8은 원자료의 재계산이 아니라 주어진 반올림 수의 정확한 합을 묻는다. 현재 문항 입력은 위 16개 계산을 독립적으로 재현하는 데 충분하다.
