문제에서 주어진 것과 구할 것

연속확률변수 $X$의 확률밀도함수가 $0 \le x \le 1$에서 $f_X(x)=3x^2$이고 그 밖에서는 $0$이에요.

구간 $0 \le t \le 1$에서 누적분포함수 $F_X(t)=P(X \le t)$를 적분으로 유도하고, $t=\frac{1}{2}$에서의 누적확률 $P(X \le \frac{1}{2})$를 구해요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘밀도에서 $P(X \le t)$’라는 조건에서 누적분포함수(cumulative distribution function, CDF)와 정적분을 떠올려요.

연속확률변수의 누적분포함수는 밀도를 왼쪽 끝($-\infty$)부터 $t$까지 적분한 면적이에요:

$$F_X(t) = P(X \le t) = \int_{-\infty}^t f_X(u)\,du$$

$u < 0$에서 밀도가 $0$이므로 실제 적분 하한은 $0$으로 설정해요. 거듭제곱 적분 공식 $\int 3u^2\,du = u^3$을 써요.

밀도의 적분과 구간 확률

종이에 적을 첫 줄

$0 \le t \le 1$에서 하한을 0으로 둔 정적분 식 $F_X(t) = \int_0^t 3u^2\,du$를 적어요.

풀이 로드맵: 1. 적분 하한 설정 및 피적분함수 대입 → 2. 부정적분 계산 및 끝값 대입으로 $F_X(t)$ 유도 → 3. $t=\frac{1}{2}$ 대입.

왜 이렇게 푸는지 함께 따라가요

(a)

최종 답 구조: $0 \le t \le 1$에서 누적분포함수는 $F_X(t) = t^3$이에요.

  1. $$F_X(t) = \int_0^t 3u^2\,du$$

    0 미만은 밀도 0이므로 하한을 0으로 잡아요

  2. $$\hphantom{F_X(t)}= [u^3]_0^t$$

    3u^2의 부정적분 u^3을 구해요

  3. $$\hphantom{F_X(t)}= t^3 - 0^3 = t^3$$

    위끝 t와 아래끝 0을 대입해 얻은 결과예요

$t\lt0$이면 누적확률은 0이고, $t\gt1$이면 밀도 전체를 적분해 1이에요.

(b)

최종 답 요약: 누적확률은 $P\left(X \le \frac{1}{2}\right) = \frac{1}{8}$이에요.

  1. $$P\left(X \le \frac{1}{2}\right) = F_X\left(\frac{1}{2}\right)$$

    누적분포함수의 정의에 t=1/2을 대입해요

  2. $$\hphantom{P\left(X \le \frac{1}{2}\right)}= \left(\frac{1}{2}\right)^3 = \frac{1}{8}$$

    (a)의 결과 식 t^3을 계산해요

전체 면적 1 중 절반 지점까지의 누적확률은 $\frac{1}{8} = 0.125$로, 밀도가 $x$가 커질수록 증가하는 특성을 보여줘요.

완성 답과 검산

(a) 검산

$0\lt t\lt1$에서 $F_X(t)=t^3$을 미분하면 $\frac{d}{dt}(t^3) = 3t^2 = f_X(t)$로 원래 밀도가 복원되고, 양 끝값 $F_X(0)=0$, $F_X(1)=1$을 만족해요.

(b) 검산

남은 구간 $[\frac{1}{2}, 1]$의 확률은 $\int_{1/2}^1 3u^2\,du = [u^3]_{1/2}^1 = 1 - \frac{1}{8} = \frac{7}{8}$이며, $\frac{1}{8} + \frac{7}{8} = 1$로 전체 확률이 보존돼요.

여기서 헷갈리기 쉬워요

$P(X \le \frac{1}{2})$를 구할 때 밀도함수에 직접 대입해 $f_X(\frac{1}{2}) = 3(\frac{1}{2})^2 = \frac{3}{4}$를 답으로 쓰지 않아야 해요. 밀도의 높이는 확률이 아니며, 확률은 반드시 적분 면적으로 구해야 해요.

다시 풀 때 확인할 것

원 문제만 펼친 상태에서 풀이의 첫 줄을 적어요.

  1. 밀도가 정의된 구간의 시작점(0)을 적분 하한으로 정해요.
  2. 밀도식을 정적분해 누적분포함수를 구하고 $t=\frac{1}{2}$를 대입해요.

떠올릴 개념·공식

누적분포함수 $F_X(t)$는 밀도를 적분해 구해요. $0\le t\le1$에서는 $F_X(t)=\int_0^t 3u^2\,du=t^3$이에요. $t\lt0$이면 0이고, $t\gt1$이면 1이에요.

첫 줄과 검산

$F_X(t)=t^3$ ($0 \le t \le 1$)이고, $F_X(\frac{1}{2}) = \frac{1}{8}$이에요. 미분과 끝값으로 검산해요.

용어

확률밀도함수(probability density function, PDF)
연속확률변수의 특정 구간 확률을 정적분 면적으로 정의하는 함수예요.
누적분포함수(cumulative distribution function, CDF)
확률변수가 주어진 값 이하일 확률 $P(X \le t)$를 나타내는 함수예요.
