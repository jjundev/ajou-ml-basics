문제에서 주어진 것과 구할 것

7개 관측값에 대한 3개 성분의 $7 \times 3$ 책임도 행렬 $R$이 주어져요 (행: 관측값, 열: 성분 1, 2, 3).

$r_{nk}$는 관측 $n$에 대한 성분 $k$의 책임도예요. 표에 표시된 값으로 세 성분의 총 책임도 $N_k = \sum_{n=1}^7 r_{nk}$를 구하고, 총 책임도가 가장 큰 성분을 찾아요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘책임도 행렬의 열 합 $N_k$’라는 조건에서 GMM의 총 책임도(total responsibility)와 유효 표본 수(effective number of points)를 떠올려요.

성분 $k$의 총 책임도는 행렬 $R$에서 열 방향(세로 방향)으로 모든 관측값의 책임도를 합산해요:

$$N_k = \sum_{n=1}^7 r_{nk}$$

반올림 전 책임도는 관측값마다 세 성분에 대한 확률분포를 이루므로 각 행의 합이 1이에요. 이 문제의 표에서도 각 행의 표시값을 더하면 $\sum_{k=1}^3 r_{nk}=1$이에요. 따라서 세 성분의 총 책임도를 더하면 전체 관측 수 $N=7$과 일치해요.

$$\sum_{k=1}^3 N_k = \sum_{k=1}^3 \sum_{n=1}^7 r_{nk} = \sum_{n=1}^7 \sum_{k=1}^3 r_{nk} = \sum_{n=1}^7 1 = 7$$

책임도 표의 행과 열

종이에 적을 첫 줄

행렬 $R$의 첫 번째 열을 세로로 따라가며 $N_1 = 1.0 + 1.0 + 0.057 + 0.001$을 적어요 (0은 합에 영향 없음).

풀이 로드맵: 1. 각 열별 원소 식별 및 열 합 계산 표 작성 → 2. 세 성분의 총 책임도 $N_1, N_2, N_3$ 산출 → 3. 총합 7 검증 및 최댓값 성분 판정.

왜 이렇게 푸는지 함께 따라가요

(a)

최종 답 구조: 세 성분의 총 책임도는 $(N_1, N_2, N_3) = (2.058, 2.008, 2.934)$예요.

대표 1항으로 성분 1의 총 책임도는 1열의 원소를 더해 $N_1 = 1.0 + 1.0 + 0.057 + 0.001 = 2.058$이에요. 7개 관측의 책임도 행렬과 열 합을 표로 정리해요.

관측 $n$ 성분 1 ($r_{n1}$) 성분 2 ($r_{n2}$) 성분 3 ($r_{n3}$) 행 합 ($\sum_k r_{nk}$)
1 $1.0$ $0.0$ $0.0$ $1.0$
2 $1.0$ $0.0$ $0.0$ $1.0$
3 $0.057$ $0.943$ $0.0$ $1.0$
4 $0.001$ $0.999$ $0.0$ $1.0$
5 $0.0$ $0.066$ $0.934$ $1.0$
6 $0.0$ $0.0$ $1.0$ $1.0$
7 $0.0$ $0.0$ $1.0$ $1.0$
총 책임도 ($N_k$) $2.058$ $2.008$ $2.934$ 전체 합: $7.000$

각 열의 합 계산은 다음과 같아요:

$$N_1 = 1.0 + 1.0 + 0.057 + 0.001 = 2.058$$

$$N_2 = 0.943 + 0.999 + 0.066 = 2.008$$

$$N_3 = 0.934 + 1.0 + 1.0 = 2.934$$

(b)

최종 답 요약: 전체 관측에 대한 총 책임도가 가장 큰 성분은 성분 3이에요.

세 열 합의 크기를 비교하면 $N_3 = 2.934 > N_1 = 2.058 > N_2 = 2.008$이에요. 따라서 전체 7개 관측점 중 성분 3이 가장 많은 유효 점 수(약 2.934개)를 차지해요.

완성 답과 검산

(a) 검산

세 열 합의 총합은 $N_1 + N_2 + N_3 = 2.058 + 2.008 + 2.934 = 7.000$으로 전체 관측 수 $N=7$과 정확히 일치해요.

(b) 검산

표의 두 열을 각각 성분 3의 열과 비교하면 $N_3-N_1=0.876$, $N_3-N_2=0.926$으로 두 차이가 모두 양수예요.

여기서 헷갈리기 쉬워요

이 표의 행 합은 한 관측값에 대한 성분별 책임도 합이라 1이에요. 열 합 $N_k$는 여러 관측값의 책임도를 성분별로 모은 값이라 이 문제의 성분 3처럼 1을 넘을 수도 있어요.

다시 풀 때 확인할 것

원 문제만 펼친 상태에서 풀이의 첫 줄을 적어요.

  1. 행렬의 각 열을 세로로 더해 세 성분의 총 책임도 N1, N2, N3을 계산해요.
  2. 세 열 합의 총합이 전체 데이터 수인 7이 되는지 확인하고 최댓값을 골라요.

떠올릴 개념·공식

총 책임도 $N_k = \sum_{n=1}^7 r_{nk}$는 성분 $k$ 열의 합이에요. 세 열 합의 총합은 전체 관측 수 7이에요.

첫 줄과 검산

$N_1=2.058, N_2=2.008, N_3=2.934$이고 성분 3이 가장 커요. 총합은 $2.058+2.008+2.934=7.000$이에요.

용어

책임도 행렬(responsibility matrix)
행은 각 데이터 관측값, 열은 각 혼합 성분을 나타내며, 각 칸에는 해당 사후확률이 저장되는 행렬이에요.
총 책임도(total responsibility)
한 성분이 전체 데이터로부터 할당받은 확률의 총합 $N_k = \sum_n r_{nk}$으로, 해당 성분의 유효 데이터 개수를 뜻해요.
