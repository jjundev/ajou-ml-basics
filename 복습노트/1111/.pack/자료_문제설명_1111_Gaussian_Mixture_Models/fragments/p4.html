문제에서 주어진 것과 구할 것

상태가 $0$ 또는 $1$인 베르누이 확률변수 $X$에서 모수 $\mu = 0.7$일 때의 확률질량함수가 주어져요.

두 상태의 확률 $p(0\mid\mu)$와 $p(1\mid\mu)$를 구하고, 이를 가중치로 써서 기댓값 $E[X]$를 계산해요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘상태가 0 또는 1’이라는 조건에서 베르누이 분포(Bernoulli distribution)와 이산 기댓값(expectation)을 떠올려요.

베르누이 PMF 공식 $p(x\mid\mu) = \mu^x (1-\mu)^{1-x}$에서 $a^0 = 1, a^1 = a$를 적용해요.

이산 기댓값 공식은 각 상태의 값과 그 확률을 곱해 합산하는 가중평균이에요:

$$E[X] = \sum_{x \in \{0, 1\}} x \cdot p(x\mid\mu) = 0 \cdot p(0\mid\mu) + 1 \cdot p(1\mid\mu)$$

이산 기댓값

종이에 적을 첫 줄

$\mu = 0.7$을 대입해 $p(0\mid 0.7) = 1 - 0.7 = 0.3$, $p(1\mid 0.7) = 0.7$을 적어요.

풀이 로드맵: 1. x=0, 1 대입으로 상태별 확률 산출 → 2. 상태별 값과 확률을 정리하는 기댓값 표 구성 → 3. 가중합 E[X] 산출.

왜 이렇게 푸는지 함께 따라가요

(a)

최종 답 구조: 두 상태의 확률은 $p(0\mid\mu) = 0.3$, $p(1\mid\mu) = 0.7$이에요.

주어진 확률질량함수 $p(x\mid\mu) = \mu^x(1-\mu)^{1-x}$에 $\mu=0.7$을 넣고 각 상태를 대입해요.

$x=0$일 때: $p(0\mid 0.7) = 0.7^0 \cdot (1-0.7)^{1-0} = 1 \cdot 0.3^1 = 0.3$

$x=1$일 때: $p(1\mid 0.7) = 0.7^1 \cdot (1-0.7)^{1-1} = 0.7 \cdot 0.3^0 = 0.7$

상태 0의 확률은 실패 확률 $1-\mu=0.3$, 상태 1의 확률은 성공 확률 $\mu=0.7$과 정확히 일치해요.

(b)

최종 답 요약: 기댓값은 $E[X] = 0.7$이에요.

상태 0의 값에 확률 0.3을 곱한 가중 기여는 $0 \times 0.3 = 0.0$이에요. 두 상태의 가중합을 표로 계산해요.

상태 $x$ 확률 $p(x\mid\mu)$ 가중 기여 $x \cdot p(x\mid\mu)$ 해석
0 0.3 $0 \times 0.3 = 0.0$ 값 0의 기여는 소거됨
1 0.7 $1 \times 0.7 = 0.7$ 값 1의 확률이 그대로 기댓값이 됨
합계 1.0 $E[X] = 0.7$ 확률 가중평균

값 0은 기여가 0이므로, 기댓값은 성공 확률 $\mu=0.7$ 자체와 같아져 $E[X] = 0.7$이에요.

완성 답과 검산

(a) 검산

$p(0\mid\mu) + p(1\mid\mu) = 0.3 + 0.7 = 1.0$으로 확률의 총합이 1이고 두 값 모두 $0$ 이상이에요.

(b) 검산

베르누이 분포의 기댓값 일반 공식 $E[X] = 1 \cdot \mu + 0 \cdot (1-\mu) = \mu$에 $\mu=0.7$을 대입한 결과와 정확히 일치해요.

여기서 헷갈리기 쉬워요

기댓값을 구할 때 0과 1의 산술평균인 $\frac{0+1}{2} = 0.5$로 단순 계산하면 안 돼요. 각 상태의 발생 확률인 $0.3$과 $0.7$을 가중치로 곱해야 해요.

다시 풀 때 확인할 것

원 문제만 펼친 상태에서 풀이의 첫 줄을 적어요.

  1. PMF 식에 x=0과 x=1을 대입해 각 확률을 먼저 구해요.
  2. 각 상태의 값과 확률을 곱해 합산하는 가중합 표를 작성해요.

떠올릴 개념·공식

$p(0\mid\mu)=1-\mu$, $p(1\mid\mu)=\mu$예요. 이산 기댓값은 값과 확률의 곱을 더해요.

첫 줄과 검산

$p(0)=0.3, p(1)=0.7$이고 $E[X] = 0\cdot 0.3 + 1\cdot 0.7 = 0.7$이에요.

용어

베르누이 분포(Bernoulli distribution)
결과가 0(실패) 또는 1(성공)의 두 가지만 가능한 이산확률분포예요.
기댓값(expectation)
확률변수가 취할 수 있는 모든 값들을 각 확률로 가중평균한 값이에요.
