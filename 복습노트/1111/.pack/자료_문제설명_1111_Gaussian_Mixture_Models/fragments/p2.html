문제에서 주어진 것과 구할 것

확률변수 $X$와 $Y$의 $3 \times 5$ 관측 빈도표(전체 90건)에서 무작위로 한 건을 추출해요.

특정 열과 행의 주변확률 $P(X=x_3)$과 $P(Y=y_2)$를 구하고, 두 방향의 조건부확률 $P(Y=y_2\mid X=x_3)$과 $P(X=x_3\mid Y=y_2)$를 기약분수로 나타내요.

이 문제를 봤을 때 떠올릴 개념과 공식

‘빈도표에서 무작위 추출’이라는 조건에서 주변확률(marginal probability)과 조건부확률(conditional probability)을 떠올려요.

$n(y_j,x_k)$는 $y_j$ 행과 $x_k$ 열이 만나는 칸의 관측 빈도예요. 주변확률은 해당 행이나 열의 빈도 합을 전체 표본 수 $N=90$으로 나누어 구해요.

$$P(X=x_3) = \frac{\sum_j n(y_j, x_3)}{N}, \qquad P(Y=y_2) = \frac{\sum_k n(y_2, x_k)}{N}$$

조건부확률은 조건에 해당하는 행이나 열로 표본공간을 축소한 뒤, 교차 칸의 빈도를 나눈 값이에요:

$$P(Y=y_2 \mid X=x_3) = \frac{n(y_2, x_3)}{\sum_j n(y_j, x_3)}, \qquad P(X=x_3 \mid Y=y_2) = \frac{n(y_2, x_3)}{\sum_k n(y_2, x_k)}$$

조건부확률과 베이즈 정리

종이에 적을 첫 줄

$x_3$ 열의 합 $3+6+9=18$, $y_2$ 행의 합 $2+4+6+8+10=30$, 전체 합 $15+30+45=90$을 적어요.

풀이 로드맵: 1. 행 합·열 합·전체 빈도 집계 → 2. 주변확률 계산 및 약분 → 3. 교차 빈도(6)를 조건의 합으로 나누어 조건부확률 산출.

왜 이렇게 푸는지 함께 따라가요

(a)

최종 답 구조: 주변확률은 $P(X=x_3) = \frac{1}{5}$, $P(Y=y_2) = \frac{1}{3}$이에요.

$X=x_3$ 열의 빈도 합은 $3+6+9=18$이고, 전체 빈도는 $90$이므로 대표 확률은 $P(X=x_3) = \frac{18}{90} = \frac{1}{5}$예요. 빈도와 주변확률을 표로 정리해요.

사건 구성 칸 빈도 합 전체 대비 비율 기약분수
$X=x_3$ (3열) $3 + 6 + 9$ 18 $\frac{18}{90}$ $\frac{1}{5}$
$Y=y_2$ (2행) $2 + 4 + 6 + 8 + 10$ 30 $\frac{30}{90}$ $\frac{1}{3}$
전체 ($N$) $y_1(15) + y_2(30) + y_3(45)$ 90 $\frac{90}{90}$ $1$

전체 90건 중 $x_3$ 열은 5분의 1, $y_2$ 행은 3분의 1을 차지해요.

(b)

최종 답 요약: 조건부확률은 $P(Y=y_2\mid X=x_3) = \frac{1}{3}$, $P(X=x_3\mid Y=y_2) = \frac{1}{5}$이에요.

교차 칸의 빈도가 $n(y_2,x_3)=6$이므로 결합확률은 $6/90$이에요. 이 값을 (a)의 주변확률 $P(X=x_3)=18/90$ 또는 $P(Y=y_2)=30/90$으로 각각 나눠요. 분자와 분모의 $90$이 약분되어 아래와 같이 빈도의 비율이 돼요.

조건부확률 분자(교차 칸) 분모(조건의 합) 계산 식 기약분수
$P(Y=y_2 \mid X=x_3)$ $n(y_2, x_3) = 6$ $x_3$ 열 합 $= 18$ $\frac{6}{18}$ $\frac{1}{3}$
$P(X=x_3 \mid Y=y_2)$ $n(y_2, x_3) = 6$ $y_2$ 행 합 $= 30$ $\frac{6}{30}$ $\frac{1}{5}$

조건이 $X=x_3$이면 18개 중 6개이므로 $\frac{1}{3}$이고, 조건이 $Y=y_2$이면 30개 중 6개이므로 $\frac{1}{5}$이에요.

완성 답과 검산

(a) 검산

모든 행에서 $x_3$ 칸은 행 합의 $\frac{1}{5}$이고, 모든 열에서 $y_2$ 칸은 열 합의 $\frac{1}{3}$이에요. 예를 들어 $y_2$ 행에서 $6/30=1/5$이고 $x_3$ 열에서 $6/18=1/3$이에요. 각 비율이 표 전체에서도 유지되므로 (a)의 주변확률과 일치해요.

(b) 검산

곱셈정리 $P(X=x_3, Y=y_2) = P(X=x_3)P(Y=y_2\mid X=x_3) = \frac{1}{5}\cdot\frac{1}{3}=\frac{1}{15}$이고, 반대 방향 $P(Y=y_2)P(X=x_3\mid Y=y_2) = \frac{1}{3}\cdot\frac{1}{5}=\frac{1}{15}=\frac{6}{90}$로 양방향 결합확률이 일치해요.

여기서 헷갈리기 쉬워요

조건부 기호 $\mid$ 오른쪽이 분모를 결정해요. $P(Y=y_2\mid X=x_3)$의 분모는 열 합(18)이고, $P(X=x_3\mid Y=y_2)$의 분모는 행 합(30)인데, 분모를 서로 바꾸거나 전체 90으로 나누지 않도록 주의해요.

다시 풀 때 확인할 것

원 문제만 펼친 상태에서 풀이의 첫 줄을 적어요.

  1. 조건부 기호 오른쪽의 조건에 해당하는 행 합 또는 열 합을 분모로 먼저 찾아요.
  2. 교차 칸의 빈도를 분모로 나누고 기약분수로 약분해요.

떠올릴 개념·공식

주변확률은 행·열 합을 전체 90으로 나눠요. 조건부확률은 교차 칸을 조건에 해당하는 행·열 합으로 나눠요.

첫 줄과 검산

주변확률은 $\frac{1}{5}, \frac{1}{3}$이고 조건부확률은 $\frac{1}{3}, \frac{1}{5}$예요. 결합확률 $\frac{6}{90}=\frac{1}{15}$로 검산해요.

용어

주변확률(marginal probability)
다른 변수들의 값을 모두 합산(적분)하여 얻는 특정 변수만의 확률이에요.
조건부확률(conditional probability)
어떤 사건이 일어났다는 조건하에서 다른 사건이 발생할 확률이에요.
