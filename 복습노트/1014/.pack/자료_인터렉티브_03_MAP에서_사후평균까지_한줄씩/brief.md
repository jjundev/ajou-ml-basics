# MAP에서 사후평균까지: 한 줄씩 쓰는 수식 노트
목표: MAP 두 식의 변환과 사후평균 식의 동일성을 한 줄씩 누적해서 이해한다.
사용자 요청: 식을 하나씩 써 내려가는 느낌, 두 식 비교, 1014·1019 평균·분산 연결.
모드: 사전 비교(6줄), 평균 연결(6줄), 예측 연결(5줄). 수동 다음/이전, 좌우 방향키, 초기화.
조작: 사전평균 m₀ -4~4 (0.5), 사전분산 s₀ .25~4 (.25).
학습용 데이터: K=1, 한 관측 φ=1,y=4,σ²=1. 예측은 φ★=2. 정규 사전, 알려진 독립 가우시안 잡음. S₀ SPD 가정.
관찰: 두 계산 경로가 같은 평균을 주고, m₀는 공분산을 바꾸지 않는다. 공분산의 σ²은 평균처럼 소거할 수 없다.
근거: L03 p25, L04 p12–14, MML 9.2.3·9.3.3, STT 0928·1014·1019, 해당 복습노트.
보충: MAP↔사후평균 등식 정리, 임시 A_b,A_g,q_b,q_g 표기, 숫자 예시. 강의 PDF p12 요약식의 σ 지수 혼동은 본문 전개/1014 노트와 교과서에 따라 σ⁻²로 교정.
디자인: 공통 Canvas 셸 보존. 주제 훅의 ref로 stage에 접근 가능한 DOM 수식 노트 보조 오버레이를 장착한다. 로컬 KaTeX, 수식만 가로 스크롤, 논리 단계 수동 진행(자동재생 없음). 렌더러·셸·vendor 수정 없음.
검산: 유리수 독립 정답, 가우시안 사후평균 경로 vs MAP 정규방정식 경로, 행렬 2×2 독립 소거법.
