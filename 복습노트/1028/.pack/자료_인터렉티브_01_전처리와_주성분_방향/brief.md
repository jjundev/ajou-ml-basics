# 전처리와 주성분 방향

대상: 1028 정리노트 2.1·2.2절(S1–S5, 그림으로 보는 전처리). 점 구름이 평행이동, 축 스케일 맞추기, 사영, 되돌리기를 거치는 과정을 재생하고, 표준화가 첫 방향을 어떻게 바꾸는지 비교한다.

조작 변수: x₁의 표준편차 σ₁(0.5–5, 0.1), 상관 ρ(0.2–0.95, 0.05). x₂의 표준편차는 1, 표본 평균은 (3, 2)로 고정.

관찰할 변화: 단계 모드에서는 표본 평균·표준편차가 S1에서 평균 0, S2에서 표준편차 1, S5에서 원래 평균으로 바뀐다. 스케일 모드에서는 표준화 전 b₁이 긴 축으로 끌려가고, 표준화 후에는 45°로 고정된다.

모드: 단계(playback f 0–5), 스케일(playback 없음, 표준화 토글). 시점은 평면 정면 고정.

출처: Lecture05 실제 PDF 8–9쪽, 1028 STT P03–P05, 정리노트 s2-steps·s2-preprocess, MML 10.1(실제 PDF 324–325쪽).

학습용 데이터: 고정 seed 1028로 만든 40점(칠판 예시 N=40)을 평균 0·공분산 I로 정확히 맞춘 뒤 입력값대로 변환한다. 평균·분산은 수업처럼 N으로 나눈다.

단순화와 보충: D=2, M=1. ρ는 수업 밖 보충 입력이다. ρ=0이면 표준화 뒤 고윳값이 같아 방향이 정해지지 않으므로 범위를 0.2 이상으로 둔다. 축은 추상 x₁, x₂이고 가로세로 비율은 같으며 눈금은 입력에 맞춰 자동 조정된다. 고유벡터 선택은 수업에서 들은 결론만 쓰고 유도는 넣지 않는다.

교과서 밖 관찰: 2×2 표준화 공분산 행렬의 대각이 모두 1이라 방향이 ±45°로 고정된다(D=2 한정). S5 뒤 잔차는 원래 좌표의 직선과 수직이 아니다.
