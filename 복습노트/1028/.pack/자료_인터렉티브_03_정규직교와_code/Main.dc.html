D는 데이터 차원, M은 기저 벡터 수예요. x는 D×1, B는 D×M, z는 M×1, BBᵀx는 다시 D×1이에요.

길이 모드는 D=2, M=1이고, 사잇각 모드는 D=3, M=2예요. 사잇각 모드의 기저는 복습문제 P2의 (3,4)/5, (4,−3)/5 방향을 z=0 평면에 놓고 길이와 사잇각을 바꾼 학습용 예시예요.

일반 공식에 BᵀB = I를 대입하는 과정은 교수님이 쓰지 않은 강의 공식 연결용 재표현이에요. 어떤 B를 고를지는 1028 수업에서 정하지 않았어요.
