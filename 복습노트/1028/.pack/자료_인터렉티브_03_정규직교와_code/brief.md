# 정규직교와 code

대상: 1028 정리노트 4.2절. z = Bᵀx가 언제 사영 계수와 같은지, 길이와 직교 조건을 하나씩 깨며 확인한다. 복습문제 P2·P3의 함정과 이어진다.

조작 변수: 길이 모드는 ‖b‖(0.5–2.5, 0.1), θ(0–175, 5), x₁·x₂(−4–4, 0.1). 사잇각 모드는 φ(30–150, 5), ‖b₁‖·‖b₂‖(0.5–2, 0.1), x=(2,1,2) 고정.

관찰할 변화: 길이가 1이 아니면 z는 λ*의 bᵀb배가 되고 zb는 사영점에서 벗어난다. 수직이 깨지면 BᵀB의 비대각이 0이 아니게 되고 BBᵀx가 Bλ와 달라진다. 부분공간이 같으면 Bλ와 거리는 그대로다.

모드: 길이(D=2, M=1, 평면 정면), 사잇각(D=3, M=2, 회전 가능), 수식(한 줄씩 전개). 시간 진행이 없어 playback은 쓰지 않는다.

출처: Lecture05 실제 PDF 11–12쪽, 1028 STT P07–P08, 정리노트 s4-code·s5-encoder-decoder, MML Definition 3.9(실제 PDF 85쪽), 3.8절(실제 PDF 88–91쪽), Example 10.1(실제 PDF 324쪽).

학습용 예시: 노트의 b=[2,0], x=[1,0]. 사잇각 모드의 기저는 복습문제 P2의 (3,4)/5, (4,−3)/5 방향을 z=0 평면에 놓고 길이와 사잇각을 바꾼 것이다.

단순화와 보충: 일반 공식에 BᵀB=I를 대입하는 과정은 교수님이 쓰지 않은 강의 공식 연결용 재표현이다. 어떤 B를 고를지는 다루지 않는다.
