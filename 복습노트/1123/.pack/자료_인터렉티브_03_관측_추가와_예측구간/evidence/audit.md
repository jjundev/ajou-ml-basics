# 보충 관측 확장 설명 감사

대상은 1123 관측 추가와 예측구간의 보충 관측 안내, 30개 프리셋과 수식이다. 1123 정리노트와 기존 10–12개 재현값을 대조했다.

- Critical 0 / Important 0 / Minor 1 / 미해결 0
- 프리셋의 설명에서 측정 잡음 분산을 더하는 대상이 새 관측값의 분산임을 명시했다.
- 11·12번째의 실습 관측과 13번째부터의 보충 관측을 구분했다. 시드 1123으로 보충 관측 18개를 재현했다.

| 설명 | 재현한 연결 | 판단 |
|---|---|---|
| 30개 관측 후 두 구간의 폭 | x=0에서 함수값 구간 폭은 약 0.29, 새 관측값 구간 폭은 약 0.84이다. 새 관측값 분산은 함수값 분산에 0.04를 더한 값이다. | 기존 식과 결과의 차이가 보이고, 추가 유도 없이 실험을 따라갈 수 있다. |

## 직접 추가 모드

Critical 0 / Important 0 / Minor 1 / 미해결 0. 첫 추가 이전에 직전 폭 타일을 대시로 표시했다. 고른 x에서 y를 생성하는 방법과 x*의 직전·직후 비교를 확인했다.
