# 관측 추가와 예측구간

조교 실습 자료 15–20쪽의 4차 베이지안 회귀를 재현한다. 사전 표준편차는 2, 관측 잡음 표준편차는 0.2이다. 관측 수 슬라이더를 10개에서 30개까지 한 점씩 움직이고, 예측을 읽을 입력을 선택해 두 구간의 폭을 비교한다.

처음 10개에는 시드 19 재현값을, 다음 두 점에는 실습의 양 끝 관측을 쓴다. 13번째 점은 x=0이며, 나머지 17개 입력은 [−5, 5]를 나눈 동일 폭 구간에서 하나씩 뽑아 순서를 섞었다. 보충 관측은 시드 1123으로 입력과 잡음을 한 번 생성하고, 생성 함수에 표준편차 0.2인 독립 가우시안 잡음을 더해 정했다. 결과를 고정해 슬라이더를 되돌리면 같은 관측을 다시 사용한다.

직접 추가 모드는 처음 관측 10개에서 선택한 x마다 점을 하나 생성한다. y는 생성 함수에 시드 1123에서 뽑은 독립 잡음 표본을 더한다. 마지막 점을 추가하기 직전과 직후의 예측구간 폭을 같은 x*에서 비교한다. 실습 순서와 직접 추가는 독립된 상태를 쓴다.
