Q1. 직선의 예측값

실습처럼 np.polyfit(x, y, 1)로 직선을 맞췄더니 계수가 $[2,-3]$ 순서로 나왔어요. 새 입력 $x=4$에서 예측값을 정수로 입력하세요.

힌트 보기

이 함수가 가장 높은 차수의 계수를 배열 어디에 놓는지 떠올려 보세요.

풀이 보기
  1. 첫 번째 계수 2가 기울기이고 두 번째 계수 −3이 절편이에요.
  2. 새 입력에서 기울기 항은 2×4=8이에요.
  3. 절편을 더하면 8−3=5예요.

정답: 5

Q2. 두 곡선의 비교

같은 관측점 10개에 곡선을 맞췄더니 훈련 잔차제곱합은 4차에서 0.32, 9차에서 거의 0이었어요. 학습에 쓰지 않은 $x=-5$에서 생성 함수의 값은 1.13이고 4차와 9차의 예측값은 각각 1.81과 21.61이에요. 9차의 결과를 어떻게 해석할 수 있나요?

  1. 모형의 표현력이 부족해서 새 입력에서 과소적합이 나타나요.
  2. 훈련점에 맞춘 굽힘이 새 입력으로 잘 이어지지 않아 과적합의 징후가 보여요.
  3. 새로 관측한 값에 섞인 잡음 때문에 생성 함수와 큰 차이가 났어요.
  4. 입력의 수치 스케일만 조정하면 9차가 새 입력에도 잘 맞아요.
힌트 보기

훈련점과 미관측 입력에서 같은 모델의 결과가 어떻게 달랐는지 보세요.

풀이 보기
  1. "새 입력의 오차가 크면 과소적합이라고 판단함" — 9차는 훈련점의 오차를 거의 0까지 줄였어요. 관찰된 문제는 훈련점 적합에 치중해 다른 입력에서 크게 빗나갔다는 점이에요.
  2. 훈련 오차는 4차보다 작지만, 새 입력에서 9차의 절대오차 약 20.48은 4차의 약 0.68보다 커요.
  3. "잡음 없는 생성 함수와 잡음이 포함된 관측값을 혼동함" — 비교 기준 1.13은 관측값이 아니라 잡음 없는 생성 함수의 값이에요.
  4. "수치 스케일 조정만으로 과적합을 없앨 수 있다고 봄" — 스케일 조정은 계산에 쓰는 열의 크기를 줄여요. 같은 차수에서 정규화 없이 맞추는 다항식의 함수 집합은 그대로예요.

정답: B

Q3. 입력 스케일링과 특성

실습처럼 $z=x/5$를 쓰고 설계행렬 한 행의 첫 세 열에 $(1,z,z^2)$을 넣어요. 입력이 $x=-2$일 때 세 번째 열의 값을 기약분수로 입력하세요.

힌트 보기

한 행에서 상수항이 몇 번째 열인지 세어 보고 입력을 먼저 바꿔 보세요.

풀이 보기
  1. x=−2를 5로 나누면 z=−2/5예요.
  2. 세 번째 열은 z²이므로 (−2/5)×(−2/5)=4/25예요.

정답: 4/25

Q4. 정규화 강도를 올리면

관측점, 9차 특성, 입력 스케일을 고정해요. 목적함수에 $\lambda\|\boldsymbol{\theta}\|^2$를 더한 뒤 $\lambda$를 0.01에서 1로 올렸어요. 실습에서 관찰한 변화는 무엇인가요?

  1. 계수 제곱합과 훈련 잔차제곱합이 모두 줄어요.
  2. 계수 제곱합이 늘고 훈련 잔차제곱합이 줄어요.
  3. 차수가 그대로이므로 계수 제곱합과 훈련 잔차제곱합도 그대로예요.
  4. 계수 제곱합이 줄고 훈련 잔차제곱합이 늘어요.
힌트 보기

목적함수의 두 항 중 새 계수에 더 큰 비용을 매기는 항을 살펴보세요.

풀이 보기
  1. "규제 강화가 두 항을 모두 줄인다고 봄" — 계수는 작아졌지만 훈련 잔차제곱합은 늘었어요.
  2. "정규화 변화의 방향을 반대로 봄" — 계수에 더 큰 비용을 붙이면 이번 실습에서는 계수 제곱합이 줄고 훈련 잔차가 늘었어요.
  3. "고정 차수를 고정 계수와 동일시함" — 차수가 같아도 해를 고르는 기준이 바뀌므로 두 값이 달라져요.
  4. 실습에서 큰 정규화 강도는 계수의 크기를 줄이는 쪽에 더 큰 비중을 뒀어요.

정답: D

Q5. 겹치는 예측평균

같은 관측과 4차 특성으로 가우시안 사전분포와 가우시안 관측 잡음을 사용해요. 하나는 MAP 계수로, 다른 하나는 계수의 사후평균으로 곡선을 그렸어요. 두 곡선이 겹치는 근거는 무엇인가요?

  1. 같은 가우시안 사후분포의 평균과 최빈값이 일치해요.
  2. 사전분포의 중심과 모든 사후분포의 중심이 같아요.
  3. 4차 곡선의 계수는 관측 수에 관계없이 한 가지로 정해져요.
  4. 가우시안 잡음의 평균이 0이면 계수의 사후공분산도 0이에요.
힌트 보기

두 방법이 같은 사후분포에서 각각 어느 값을 가져오는지 비교하세요.

풀이 보기
  1. MAP은 사후밀도의 최빈값을 고르고 이 가우시안의 최빈값은 평균과 같아요.
  2. "사후평균을 사전평균과 항상 같다고 봄" — 관측을 반영하면 사후평균이 사전평균에서 이동할 수 있어요.
  3. "차수만으로 계수가 고정된다고 봄" — 4차는 계수가 다섯 개라는 뜻이에요. 값은 관측과 추정 조건에 따라 달라져요.
  4. "잡음 평균과 계수 불확실성을 혼동함" — 잡음 평균과 계수 공분산은 다른 양이에요. 실습에서는 공분산으로 예측의 퍼짐도 계산해요.

정답: A

Q6. 새 관측값의 분산

한 입력에서 잡음 없는 함수값의 사후분산이 $3/20$이에요. 새 관측에는 계수 및 기존 잡음과 독립인 분산 $1/10$의 가우시안 잡음이 더해져요. 새 관측값의 예측분산을 기약분수로 입력하세요.

힌트 보기

함수값과 새 잡음을 더할 때 두 항이 독립인지 확인하세요.

풀이 보기
  1. 함수값에 독립인 새 잡음을 더하므로 두 분산을 더해요.
  2. 3/20+1/10=3/20+2/20=5/20=1/4예요.

정답: 1/4

Q7. 새 입력과 새 관측

이미 관측 10개로 계수의 사후분포를 구했어요. 먼저 $x=-5$에서 예측을 요청받아요. 나중에 같은 위치에서 실제 $y$를 얻어요. 기존 사후분포를 언제 갱신하나요?

  1. 입력을 처음 지정할 때만 갱신하고, 새 관측값을 얻으면 기존 분포를 써요.
  2. 입력을 처음 지정할 때 한 번, 실제 관측값을 얻으면 한 번 더 갱신해요.
  3. 입력만 있을 때는 현재 분포로 예측하고, 실제 관측값을 받으면 갱신해요.
  4. 입력과 실제 관측값을 얻는 두 단계 모두 기존 사후분포로 예측만 해요.
힌트 보기

두 상황에서 관측값 y가 주어졌는지 확인하세요.

풀이 보기
  1. "입력만 있는 시점을 갱신으로 오해함" — 입력만으로는 관측값의 우도를 계산할 수 없어요. 실제 관측 쌍을 받을 때 갱신해요.
  2. "질의 입력을 별개의 학습 관측으로 셈" — 새 입력을 지정하는 단계에서는 현재 사후분포로 예측하고, 실제 관측을 반영할 때 한 번 갱신해요.
  3. 같은 입력이라도 관측값 y가 추가된 시점에 새 관측 우도로 사후분포를 갱신해요.
  4. "새 출력도 예측에만 사용한다고 봄" — 실제 관측 쌍을 받은 뒤에는 기존 사후분포에 새 우도를 반영할 수 있어요.

정답: C
