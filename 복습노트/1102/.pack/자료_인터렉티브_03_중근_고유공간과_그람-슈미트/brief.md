# 중근 고유공간과 그람-슈미트

대상: 1102 정리노트 3.2(예제: 3×3 대칭행렬). A = [[3,2,2],[2,3,2],[2,2,3]]의 중근 λ = 1 고유공간 E₁(평면 x+y+z = 0)에서 고른 두 고유벡터가 자동으로 수직이 아님을 보고, 그람-슈미트로 직교화해야 PDPᵀ = A가 성립함을 확인한다. λ = 7 고유 방향 E₇ = span[(1,1,1)]은 어떤 고르기에서도 평면과 수직이다.

조작 변수: E₁ 평면 안 두 단위벡터의 각도 α, β(0–175°, 5). 기준 q₁ = (−1,1,0)/√2에서 q₂ = (−1,−1,2)/√6 쪽으로 잰다. 토글: 그람-슈미트 적용, 이름표.

관찰할 변화: 두 벡터는 모두 Av = v인 고유벡터지만 사잇각이 α−β로 자유롭다. 노트의 예 (−1,1,0), (−1,0,1)은 α = 0, β = 60이고 v₁ᵀv₂ = 1/2이다. 이때 P = [v₁ v₂ p₃]로 PDP⁻¹ = A는 성립하지만 PDPᵀ ≠ A다(PᵀP ≠ I). 그람-슈미트를 켜면 u₂ ∝ (−1,−1,2)로 바뀌고 PDPᵀ 오차가 0이 된다. |α−β| = 90이면 처음부터 수직이라 그람-슈미트가 아무것도 바꾸지 않는다. α = β이면 두 벡터가 평면을 덮지 못해 P가 가역이 아니다.

모드: 고유공간(그래프, 3차원 회전 가능, playback 없음). 한 모드.

출처: Lecture05 실제 PDF 19쪽(Spectral Theorem). 1102 STT P05(3×3 예제, 중근, 고유벡터 정규화), P02(Gram–Schmidt orthonormalization 언급). 정리노트 s3-spectral-example. MML 예 4.8(실제 PDF 118쪽, 식 4.40)과 정리 4.15(118쪽).

학습용 예시: 노트와 MML의 같은 3×3 행렬. 벡터는 길이 1로 정규화해서 보여 준다(노트의 (−1,0,1)은 길이 √2인 원본).

단순화와 보충: 각도 입력은 평면 안 방향을 고르는 학습용 매개변수다. 그람-슈미트의 일반 절차는 수업에서 다루지 않았고 노트 3.2의 한 줄 공식(x₂' = x₂ − (x₁ᵀx₂ / x₁ᵀx₁)x₁)만 쓴다. 서로 다른 고윳값의 고유벡터가 수직인 이유(대칭행렬 성질)는 결과만 보여 준다.
