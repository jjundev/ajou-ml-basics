가로세로 눈금 비율이 같고, 눈금은 벡터 크기에 맞춰 자동으로 바뀌어요.

왜 D = P⁻¹AP가 대각행렬이 되나요?

P = [p₁, p₂]의 열은 A의 고유벡터라서 Ap₁ = λ₁p₁, Ap₂ = λ₂p₂예요. 고유기저 좌표 c = (c₁, c₂)를 표준 좌표 x = Pc = c₁p₁ + c₂p₂로 바꾼 뒤 A를 곱하면 Ax = (λ₁c₁)p₁ + (λ₂c₂)p₂가 되고, 다시 P⁻¹로 고유기저 눈금을 읽으면 (λ₁c₁, λ₂c₂) = Dc가 되어 축마다 λᵢ배 늘이기만 하는 대각행렬 D로 작동해요.
