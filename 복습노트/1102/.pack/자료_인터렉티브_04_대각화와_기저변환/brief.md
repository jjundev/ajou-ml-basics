# 대각화와 기저변환

대상: 1102 정리노트 2.2(대각행렬과 대각화), 2.3(고윳값 분해, EVD). 2×2 행렬 A의 고유벡터를 열로 모은 행렬 P = [p₁, p₂]와 고유기저 좌표 c = (c₁, c₂)를 조작하며, 원래 공간의 변환 Ax와 고유기저 모눈에서 본 대각 변환 Dc = (λ₁c₁, λ₂c₂)가 같은 벡터의 서로 다른 좌표 표현임을 확인한다. 대각화 모드는 D = P⁻¹AP의 세 단계(P 표준 좌표로 → A 변환하기 → P⁻¹ 고유기저로 읽기)를 오른쪽에서 왼쪽 순서로 재생하고, 비교 모드는 AP = PD에서 갈라지는 D = P⁻¹AP(대각화)와 A = PDP⁻¹(EVD), 그리고 대칭행렬일 때의 직교 대각화(D = PᵀAP)를 수식으로 비교한다.

조작 변수: 행렬 성분 a₁₁, a₁₂, a₂₁, a₂₂(−3–3, 0.1), 고유기저 좌표 c₁, c₂(−2–2, 0.5). 대각화 모드는 재생 위치 f(0–3).

관찰할 변화: 모눈 모드에서 고유벡터 p₁, p₂가 만드는 기울어진 고유기저 모눈 위에서 c = (c₁, c₂)를 잡으면 표준 좌표에서는 x = Pc = c₁p₁ + c₂p₂가 되고, A를 곱한 Ax = λ₁c₁p₁ + λ₂c₂p₂는 고유기저 모눈에서 회전이나 비틀림 없이 p₁ 방향으로 λ₁배, p₂ 방향으로 λ₂배 늘어난 Dc = (λ₁c₁, λ₂c₂)로 읽힌다. 대칭행렬이면 고유기저 모눈이 직사각형(수직 회전)이고 P⁻¹ = Pᵀ이지만, 비대칭행렬이면 평행사변형 모눈이고 P⁻¹ ≠ Pᵀ이다. 대각화 모드에서 f: 0 → 1(P 곱하기)은 고유기저 좌표 c를 표준 공간의 x = Pc로 번역하고, f: 1 → 2(A 곱하기)는 표준 공간에서 Ax로 변환하며, f: 2 → 3(P⁻¹ 곱하기)은 고유벡터 p₁, p₂를 좌표축 e₁, e₂로 정렬해 결과가 정확히 Dc = (λ₁c₁, λ₂c₂)가 됨을 보여 준다.

모드: 모눈(그래프, 평면 고정, playback 없음), 대각화(그래프, playback f 0–3: 처음 → P 표준 좌표로 → A 변환하기 → P⁻¹ 고유기저로 읽기), 비교(수식 전개, view:'formula', AP = PD에서 D = P⁻¹AP와 A = PDP⁻¹ 및 직교 대각화 D = PᵀAP 비교).

학습용 예시: 대칭 [[2,1],[1,2]](λ = 3, 1, c = (1, 1)), MML 예 4.11의 ½[[5,−2],[−2,5]] = [[2.5,−1],[−1,2.5]](λ = 3.5, 1.5, c = (1, −1)), 비대칭 [[2,1],[0,1]](λ = 2, 1, c = (1, 1)), 결함 행렬 [[1,1],[0,1]].

단순화와 보충: n = 2, 실수 고윳값만 다룬다. 실수 고유벡터 2개가 기저를 이루지 못하는 행렬(복소 고윳값 또는 결함 행렬)은 P⁻¹이 존재하지 않음을 안내한다. 대각화 모드의 단계 사이 애니메이션은 시각화를 위한 보간이며 단계 끝 지점(f = 0, 1, 2, 3)만 수학적 의미가 있다. 고유벡터 부호는 det P > 0이 되게 고른다.

중복 확인: 기존 인터렉티브 02(고유벡터와 대칭행렬)는 단위원 위의 x = (cos θ, sin θ) 회전과 A = PDP⁻¹ 세 단계만 다룬다. 이 자료는 고유기저 좌표 c = (c₁, c₂)와 기울어진 고유벡터 모눈, 그리고 D = P⁻¹AP의 P → A → P⁻¹ 세 단계 좌표 번역과 AP = PD 양방향 수식 비교를 다루어 2.2절(대각화)을 직접 시각화한다.
