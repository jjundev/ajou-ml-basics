무엇을 구하는 문제인가요?

해가 없는 연립방정식를 주어진 조건에서 차례로 구해요. 원문 아래의 각 소문항이 모두 풀이 대상이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

연립방정식(linear system)은 확대행렬 [A|b]의 행 소거로 일관성을 봐요. 0인 계수행에 우변만0이 아니면 해가 없어요. rank(A)와 rank([A|b])도 비교할 수 있어요.

종이에 적을 첫 줄

확대행렬 [A|b]를 적고 R2−2R1부터 해요.

왜 이렇게 푸는지 함께 따라가요

풀이

첫 행으로 아래를 지워요. $R_2 - 2R_1$, $R_3 - 2R_1$, $R_4 - 5R_1$을 하면 $[0, 3, -5, -3 \mid -4]$, $[0, -3, 3, 5 \mid 2]$, $[0, -3, 1, 7 \mid 1]$이 돼요.

둘째 행을 더해 지워요. $R_3 + R_2 = [0, 0, -2, 2 \mid -2]$, $R_4 + R_2 = [0, 0, -4, 4 \mid -3]$이에요.

$R_4 - 2R_3 = [0, 0, 0, 0 \mid 1]$이에요. 이 행은 $0 = 1$이라는 뜻이라 어떤 $\mathbf{x}$로도 맞출 수 없어요.

계수로 보면 $\mathrm{rk}(\mathbf{A}) = 3$인데 $\mathrm{rk}([\mathbf{A} \mid \mathbf{b}]) = 4$라서 모순이에요. 그래서 $S = \emptyset$이에요.

수업과의 연결: 선수 선형대수 복습이에요. 데이터 개수 $N$이 파라미터 수 $D$보다 많으면 $\mathbf{y} = \mathbf{X}\boldsymbol{\theta}$도 이렇게 딱 맞는 해가 없는 게 보통이에요. 그래서 0923 수업은 등식을 맞추는 대신 $\frac{1}{2\sigma^2}\|\mathbf{y} - \mathbf{X}\boldsymbol{\theta}\|^2$을 가장 작게 하는 least squares 문제로 풀었어요.

완성 답과 검산

검산

독립 행소거와 rank 계산에서 rank(A)=3, 확대행렬rank=4예요. 좌영공간 벡터 u는 uᵀA=0인데 uᵀb≠0이라 일관된 해가 없음을 별도로 보증해요.

정답: $S = \emptyset$ (소거하면 $0 = 1$인 행이 나와요)

여기서 주의해요

최소제곱 근사해와 Ax=b의 정확한 해 집합은 달라요.

설명을 닫고 다시 해요

  1. 확대행렬 [A|b]를 적고 R2−2R1부터 해요.
  2. 각 소문항의 계산과 이유를 직접 적어요.
  3. 최소제곱 근사해와 Ax=b의 정확한 해 집합은 달라요.
