# 주제 선정

H2/H3 설명·STT·강의에서 변수를 움직이면 관계가 달라지는 후보를 찾는다. 이웃 절의 같은 관계는 합친다. 예고를 이미 배운 내용으로 확대하지 않는다.

| 판단 | 점수 | 예 |
|---|---:|---|
| 입력과 결과의 변화 비교 | +3 | 사전 강도→사후 평균/공분산 |
| 분포·그래프·벡터 기하가 핵심 | +2 | 예측 띠, 정사영, 가우시안 곱 |
| 짝 개념을 같은 조건에서 비교 | +2 | 함수값/관측값 불확실성 |
| 독립 정답과 근거 가능 | +1 | 작은 해석 모형 |
| 정의만 외움 | −3 | 용어 목록 |
| 기존 동일 실험과 중복 | 제외 | 같은 조작, 제목만 변경 |

날짜는 높은 후보 2–4개, 주제는 1개가 기본이다. 부족하면 그만큼만 만든다. 브리프는 목표·범위·관찰 안내·모드·preset·근거·검산·단순화를 담는다. 수업 밖 보충은 표시한다.
1014 예: 사전/사후 가중치 분포와 회귀선, 같은 평균의 함수값/새 관측값 분포를 띠와 밀도로 비교한다.
