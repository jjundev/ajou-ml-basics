# ML 실험 화면

상단 모드·테마, 조작 패널, 캔버스, 설명 패널을 유지한다. 1024px 미만은 drawer다. 375×812에서도 전체 그래프가 보이도록 fit에 여유를 준다.

- 왼쪽은 변수와 단계, 오른쪽은 수치·범례·공식·오해를 둔다. 조작마다 label·현재 값·min/max/step을 제공하고 빈 숫자나 step 격자 밖의 값은 마지막 유효값으로 되돌린다.
- 분포·회귀·벡터 관계는 평면 정면 시점이 기본이다. 3차원 기하 이해에 도움이 될 때만 회전한다. 시간 진행이 없으면 playback=null이다.
- 눈금·곡선·점·선택 표시는 같은 data→scene 변환을 쓴다. 축 이름·단위와 자동 범위 조정을 안내한다. 공분산 등고선은 축 단위 비율을 같게 유지한다.
- 그래프와 패널은 같은 compute 결과를 읽는다. 단계는 mode와 입력 preset을 함께 바꾼다. 초기화는 같은 seed 표본을 재현한다.
- PAL 역할 색과 범례 이름을 함께 쓰며 두 테마 대비를 확인한다. 밀도 peak·전체 띠가 잘리지 않아야 한다.
- 공식은 로컬 KaTeX, 수치 갱신은 일반 DOM이다. 큰 공식은 명시적 스크롤 영역을 사용할 수 있으나 일반 설명·조작은 가로 넘침이 없어야 한다.
- 해요체로 관찰할 차이를 안내한다. 분산/표준편차·밀도/확률·함수값/관측값을 구분한다. 학습용 데이터·차원 축소를 표시한다.
- 버튼은 44px 이상, 상태는 aria-pressed, 캔버스는 aria-label이다. 색은 토큰/구멍으로만 쓴다. 감소된 움직임 설정을 존중한다.
