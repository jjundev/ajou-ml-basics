## 문제풀이 입문 설명

로컬 스킬 `ml-problem-explain`은 기존 복습문제와 과제 카드의 첫 줄, 풀이 이유, 완성 답과 검산을 펼친 HTML·MD를 만듭니다.

- `/ml-problem-explain 1007`: 해당 날짜 복습문제.
- `/ml-problem-explain 0909-0916`: 기간 내 날짜별 복습문제.
- `/ml-problem-explain 과제1`: 과제1 풀이 설명.
- `/ml-problem-explain <HTML경로>`: 기존 카드 파일을 명시합니다. 인자 없이 호출하면 최신 복습문제를 선택합니다.

카드 HTML이 먼저 필요합니다. 에이전트가 설명을 저작하고 원문·내용·독립 답·화면 검토를 완료한 뒤 발행합니다. CLI는 추출·조립·검사·발행을 담당하며 설명을 자동 저작하지 않습니다. 검토 누락·답 충돌·해시 변경은 해당 팩의 발행을 보류합니다.

복습 결과는 `복습노트/<날짜>/문제설명_<날짜>_<slug>.html`(MD·그림·자료는 날짜 폴더의 `.pack/` 아래), 과제 결과는 `과제/과제<N>/과제<N>_문제설명_<slug>.html/.md`에 저장합니다. 원 문제·정리노트·PDF는 보존합니다. 자세한 절차는 [스킬](.claude/skills/ml-problem-explain/SKILL.md)을 참고하세요.


## 머신러닝 인터랙티브

`/ml-interactive 1014` 또는 `/ml-interactive 가우시안 곱`으로 수치·분포·그래프를 조작하는 실험을 만들고 정리노트 설명에 새 탭 링크를 연결합니다. “기존 인터랙티브 전체 연결”은 기존 자료를 읽어 연결만 수행합니다.

HTML은 날짜 폴더, 원본·근거·연결 명세는 `.pack/자료_인터렉티브_NN_이름/`, 로컬 수식·폰트는 `.pack/vendor/ml-interactive/`에 저장합니다. 팩 재생성 뒤에도 저장된 상대 명세로 연결을 복원합니다. [스킬](.agents/skills/ml-interactive/SKILL.md)을 참고하세요.

- [1014 사전분포와 사후분포](복습노트/1014/인터렉티브_01_사전분포와_사후분포.html): 데이터 수·사전 강도와 분포/회귀선 비교.
- [1014 함수와 관측값의 예측분포](복습노트/1014/인터렉티브_02_함수와_관측값의_예측분포.html): 입력 위치·잡음분산과 예측 띠/밀도 비교.
