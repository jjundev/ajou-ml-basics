# 별도 최종 검토와 수정

2026-10-19, 작성 문맥을 넘기지 않은 새 최종 검토자가 읽기 전용으로 카드 10개·설명·제작/검증 코드·테스트·출처·PDF/HTML 화면과 실제 과제 및 L04 원본을 확인했다.

- Critical 0, Important 2, Minor 0.
- p4(a): 해설지 PDF에 ΦᵀΦ·Φᵀy만 있고 요청한 Φ 행렬이 누락됨. Φ의 3×2 행렬을 소문항 (a) 풀이에 추가했다.
- p7(a): 해설지 PDF가 2σ²를 곱하는 단계부터 시작하여 요청한 음의 로그 사후밀도가 누락됨. scaling 이전의 잔차/(2σ²)+prior 거리/(2τ²)+C를 (a)에 명시했다.
- 두 항목 모두 새 회귀 검사가 실제로 실패함을 확인했고, 수정 후 검사 PASS 및 새 PDF의 4/7쪽 렌더링을 눈으로 확인했다. 설명의 같은 소문항에도 식을 명시했다.
- 검토자가 추가 수치 오류·범위 위반·존재하지 않는 교과서 문항 번호·문제지 정답 유출을 발견하지 않았다. blind-input의 조건/질문 10개는 현재 카드와 모두 같음을 독립 확인했다.
- 새로운 재검토자를 반복 호출하지 않고, 수정 검사의 RED→GREEN과 전체 검사로 한 번의 수정 작업을 검증했다.
- 검토에서 판단하지 않은 사항: 실제 향후 시험 문항과의 일치율. 이는 현 자료로 입증할 수 없으며 예상문제라는 표현을 유지한다.

작업상 결정: 대형 원본을 복제하는 별도 worktree 대신 현재 체크아웃의 새 codex/ml-midterm-practice 브랜치와 새 예상문제 폴더에 작업했다. 공유 파일·기존 자료를 건드리지 않았으며, 추가 분리가 필요하면 새 생성 폴더를 옮기면 된다. 커밋·푸시는 요청 범위에 없어 수행하지 않았다.
