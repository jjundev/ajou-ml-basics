## 1. 요약

- 과제 문제 중 **MML 연습문제를 그대로 가져온 것**은 P3, P4(d), P6, P7이에요.

## 3. 문제별 출처

### 3.1 MML 연습문제와 정확히 일치

| 과제1 | MML | 일치 내용 |
|---|---|---|
| P3 | Ex 2.4 (b), (c) | A=[[1,2,3],[4,5,6],[7,8,9]], B=[[1,1,0],[0,1,1],[1,0,1]]로 AB, BA |
| P4(d) | Ex 4.1 | [[1,3,5],[2,4,6],[0,2,4]]의 행렬식을 첫 행 전개와 Sarrus로 구함 (문장까지 같음) |
| P6 | Ex 2.10 (a) | x₁=(2,-1,3), x₂=(1,1,-2), x₃=(3,-3,8)의 선형독립 |
| P7 | Ex 2.11 | y=(1,-2,5)를 x₁=(1,1,1), x₂=(1,2,3), x₃=(2,-1,1)의 선형결합으로 |

- 참고: P6의 x₃ = 2x₁ − x₂이라 세 벡터는 선형종속이에요. P4(d)의 행렬식은 0이에요.

### 3.3 MML과 구조는 같지만 숫자가 다른 것

| 과제1 | MML 위치 | 비고 |
|---|---|---|
| P5 | Ex 2.8 | 역행렬, 다른 행렬 |
| P11 | Ex 5.5, 5.3절 | Jacobian, 다른 함수 |
| P14 | Ex 6.10(a) | 완전제곱으로 유도 |
| P21 | Def. 6.9 | 분모 N인 표본 공분산 |
| P22 | 6.4.4절 (6.50–6.52), Ex 6.12 | 아핀 변환의 평균, 공분산, 교차공분산 |
| P25 | Ex 6.10, 6.5.2절 | 가우시안 곱 공식, 숫자는 다름 |
| P15–P19, P23–P24 | 9.2절 (9.5b, 9.10b, 9.11–9.12, 9.19, 9.28, 9.31–9.34) | ML, MAP, ridge. MML 9장에는 연습문제가 없음 |

- P18의 λ = σ²/b²은 MML 9.2절에 명시돼 있어요.
- P20(Φᵀ Φ가 특이한 경우)은 교수님이 추가한 교육용 문제로 보여요.
- P24의 prior N(1,1)은 MML이 아니라 Lecture03의 일반 prior N(m₀,S₀) 설명과 맞아요.
- P10은 gradient를 열벡터로 쓰는데, MML은 행벡터로 써요. 슬라이드와 Boyd *Convex Optimization* 부록 A.4는 열벡터 규약이에요.

### 3.4 출처를 못 찾은 것

P1, P2, P8, P9(숫자), P10, P12, P13, P16(숫자), P20, P21 등은 일반적인 연습이에요. 특정 교재와 일치하지 않았어요.
