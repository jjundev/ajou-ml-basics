문제를 내 말로 읽어요

같은 평균을 갖는 두 관측으로 스칼라 계수 하나를 추정해요. prior를 곱해 만든 목적함수에서 데이터 항과 prior 항을 구분하고, 분산만 바꿔 벌점 세기를 비교해요.

이 문제를 봤을 때 떠올릴 개념과 공식

“prior와 MAP”가 나오면 Bayes 법칙 $p(\theta\mid D)=p(D\mid\theta)p(\theta)/p(D)$를 떠올려요. $p(D)$는 모수를 적분한 evidence라 현재 비교하는 $\theta$와 무관해요. Gaussian의 음의 로그는 중심에서의 제곱거리/분산을 남겨요. 따라서 prior 분산이 작을수록 평균 0에서 멀어지는 벌점이 커져요. 여기서는 $\theta\in\mathbb R^{1\times1}$인 스칼라라 미분도 $1\times1$이에요. ridge는 데이터 제곱오차에 양의 계수로 $\theta^2$를 더한 형태예요.

종이에 쓰는 첫 줄

$$p(D\mid\theta)=\mathcal N(1\mid\theta,1)\mathcal N(3\mid\theta,1).$$ 여기에 prior 밀도를 곱해요.

왜 이렇게 푸는지 함께 따라가요

(a)

Bayes 법칙에서 $p(D)=\int p(D\mid u)p(u)\,du$는 $\theta$와 무관해요. 그러므로 $$p(\theta\mid D)\propto \mathcal N(1\mid\theta,1)\mathcal N(3\mid\theta,1)\mathcal N(\theta\mid0,1).$$ 즉 $p(\theta\mid D)\propto\exp[-\{(1-\theta)^2+(3-\theta)^2+\theta^2\}/2]$예요.

(b)

상수항을 제외하면 $$J(\theta)=\frac12[(1-\theta)^2+(3-\theta)^2]+\frac12\theta^2.$$ 양수 2를 곱하면 데이터 제곱합 $Q$에 $\theta^2$가 더해져요. 따라서 $Q+\lambda\theta^2$로 쓴 ridge 계수는 $\lambda=1$이에요.

(c)

$$J\prime(\theta)=(\theta-1)+(\theta-3)+\theta=3\theta-4.$$ 0으로 놓으면 $\hat\theta_{\rm MAP}=4/3$이에요. prior를 제외하면 $Q/2$의 미분은 $2\theta-4$여서 $\hat\theta_{\rm ML}=2$예요. $J\prime\prime=3>0$이고 데이터 항도 곡률 2가 양수라 두 최소점은 각각 유일해요. MAP가 prior 평균 0에 더 가까워요.

(d)

prior 분산이 $1/4$이면 prior 벌점은 $\theta^2/(2\cdot1/4)=2\theta^2$예요. $$J_{1/4}\prime=(\theta-1)+(\theta-3)+4\theta=6\theta-4.$$ 따라서 MAP는 $2/3$이에요. $Q$ 기준 벌점계수는 $\lambda=4$로 커지고, $2>4/3>2/3>0$이므로 더 강하게 0 쪽으로 줄었어요.

완성 답과 검산

(a) 검산

세 Gaussian의 지수 분모가 모두 2이므로 세 제곱이 동일한 가중치로 더해져요. 분모 evidence를 생략했으므로 등식 대신 비례식이에요.

(b) 검산

$2J=Q+\theta^2$라 제곱오차 항과 벌점항의 상대계수가 1이에요. 양의 배수는 최소점을 바꾸지 않아요.

(c) 검산

$3(4/3)-4=0$, $2\cdot2-4=0$예요. 상수 곡률 3과 2는 양수라 정지점이 실제 최소점이에요.

(d) 검산

$6(2/3)-4=0$이고 곡률 6은 양수예요. 분산의 역수 4가 미분의 prior 항에 들어간 것도 확인해요.

여기서 헷갈리기 쉬워요

prior 분산 $1/4$를 벌점계수 $1/4$로 쓰지 않아요. 여기서는 역수 4가 벌점 세기예요. likelihood를 모수의 정규화된 분포라고 부르지 않아요.

설명을 닫고 다시 풀어요

  • Bayes 식에서 evidence가 모수와 무관한 이유를 말해요.
  • prior 분산을 바꿔 목적함수부터 다시 미분해요.

떠올릴 개념·공식

$J=Q/2+\theta^2/2$. ML $2$, MAP $4/3$. prior 분산 $1/4$→$J=Q/2+2\theta^2$→MAP $2/3$.

적용 조건

모수1개; 독립 잡음분산1; prior 분산1 또는1/4

해설에 쓰인 용어

사전분포 (prior)

데이터를 보기 전 계수의 분포예요. 이 문제의 평균 0은 벌점의 중심, 분산은 그 벌점의 역세기를 정해요.

사후분포 (posterior)

likelihood와 prior를 곱해 데이터에 맞게 갱신한 계수 분포예요. 그 밀도의 최대점이 MAP예요.

ridge penalty

평균 0에서 벗어난 계수의 제곱에 벌점을 줘요. 이 문제에서 $Q+\lambda\theta^2$의 $\lambda$는 prior 분산 1이면 1, 1/4이면 4예요.
