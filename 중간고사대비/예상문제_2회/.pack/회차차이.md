# 중간고사 예상문제 2회 — 난이도 중하

사용자 요청에 따라 1회차의 HTML·PDF 공통 템플릿과 상세 해설 규칙을 그대로 사용하고, 문제 조건·계산량·요구 범위를 조정했다. 범위는 처음부터 1019 직교투영까지이며, 10대문항 중 앞 5문항은 과제 변형, 뒤 5문항은 모델 분석이다. 실제 시험시간·배점은 지정하지 않았다. 난이도는 제작·독립 검토 판단이며 공식 시험 난이도나 출제 예측 확률을 뜻하지 않는다.

| 문항 | 1회차 | 2회차와 난이도 조정 |
|---|---|---|
| 1 | 3차원 종속벡터, 일반해·해 없음, Gram 역행렬 | 2차원 축 방향 두 벡터의 독립성·유일한 표현·명백한 종속관계 |
| 2 | 비선형 Jacobian, 교차항 이차형식, Hessian·양의 정부호 | 단순 제곱합의 행 미분, 상수 Jacobian, 제곱의 비음수성으로 최소점 |
| 3 | 분산이 서로 다른 Gaussian 곱 | 같은 분산 2인 1차원 Gaussian 곱; 정수 중심으로 완전제곱 |
| 4 | 소수·분수 추정과 x=2 외삽 | 정확한 직선 데이터와 대각 Gram, 공식 사용 허용, x=0 예측 |
| 5 | 3점의 분수 공분산·좌표혼합, 무상관과 독립 판단 | 대칭 4점의 단위 공분산, 대각변환, 이동의 역할만 설명 |
| 6 | 일반 N·분산, 일반 유일성 증명, 비선형 특징 해석까지 | 관측 2개·특징 2개·분산1, 4단계 유도 후 대각 Gram 해 |
| 7 | 일반 K·비영 prior 평균·열종속, 가역성 증명·극한 | 평균0 prior를 둔 스칼라 평균모델, 미분 1줄과 두 분산 비교 |

| 9 | 두 prior 분산·비균등 모델prior, 적분 완전제곱 | 모수 없는 모델과 단순 Gaussian 합, 같은 모델prior, 독립합 공식 허용 |
| 10 | 2차원 부분공간, 일반 변화방향에서 최적조건 유도 | 1차원 직선, 쉬운 내적, rank-one P와 짧은 직교 거리분해 |

소문항은 42개에서 35개(3×5+4×5)로 줄였다. 모델 분석은 앞 결과를 다음 단계에 쓰도록 유지했고, 도출할 최종 정규방정식·MAP 답을 문제 조건에 제공하지 않았다. 공식 사용형은 공식→대입→결론으로, 요구된 유도·증명형은 필요한 중간 단계로 설명한다.

미분은 새 문제 전체에서 행벡터, 변수는 열벡터, Jacobian은 출력×입력이다. 과제 원 PDF의 열 gradient 문구는 원자료로 보존하고, 이 회차는 강의 관례로 새로 만든 변형임을 구별한다. 문제·참고 풀이·상세 해설·요약·용어·MD·PDF에 같은 관례를 적용한다.

과거 삭제된 2회차는 읽거나 복원하지 않았다. 현재 1회차의 최신 cards/explanations와 실제 과제·MML·교안·1019 STT를 바탕으로 새로 작성했다.
