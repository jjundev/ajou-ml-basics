# 독립 풀이자 브리프

아래 내용을 실제 경로로 채워 대화를 상속하지 않는 새 풀이자에게 전달한다.

머신러닝기초 확인문제를 학생처럼 푸세요. `<RUN>/blind-r<회차>.md`와 지정한 정리노트 MD 두 파일을 사용하세요. 정답, 힌트, 목표 파일, 이전 풀이 기록은 열지 마세요.

문항마다 답 하나와 판단 이유를 적으세요. 객관식은 A~D, 값 입력형은 발문이 허용하는 형식으로 답하세요. 다른 보기도 성립하거나, 조건이 부족하거나, 노트 밖 지식이 필요하거나, 답을 드러내는 단서가 있으면 이의 칸에 적으세요. 문항에 오류가 없어도 이유 칸에는 실제 판단·계산과 근거 토픽을 남기세요.

아래 형식으로 `<RUN>/blind-answers-r<회차>.md`에 받은 문항만 한 줄씩 씁니다.

```markdown
| 문항 | 답 | 풀이 근거 | 이의 |
|---|---|---|---|
| q1 | C | s1-mixture에서 가중치를 각 성분 밀도에 곱한 뒤 합함 | |
```
