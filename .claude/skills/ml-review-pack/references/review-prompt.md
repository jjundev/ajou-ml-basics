# 리뷰어 지시문 (lite에서는 생략)

---
머신러닝기초 복습팩 초안을 검토한다. 파일은 수정하지 않는다.

- 대상: `<RUN>/repo/복습노트/<range>/<정리노트 html>`, `<…/복습문제 html>`
- 근거: `<RUN>/summaries/stt-*.md`, `<RUN>/slides.txt`, `<RUN>/manifest.json`, `<RUN>/answers.py`, MML PDF
- 규칙: `<SKILL>/references/content-rules.md`, `card-rules.md`, `problem-selection.md`. 미분을 다루면 `vector-derivative-convention.md` 전체를 필수로 읽는다.
- 학습 레퍼런스: <학습 레퍼런스> — 필수 읽기 경로가 전달되면 파일 전체를 읽고 아래 7번을 지정된 토픽에만 적용한다. `적용 없음`이면 7번을 생략한다. `참고 누락`이면 원자료와 일반 규칙으로 검토하고 누락 상태를 보고한다.

- 큰 그림 브리프: `<RUN>/learning-map.json`, `<SKILL>/references/big-picture-first.md`를 읽는다.

확인할 것:
0. **큰 그림과 목적**: 도입만으로 오늘 풀 질문·비교 축·결과를 설명할 수 있는가. 수식의 목적이 첫 계산 전에 연결되는가. 임시 기호의 뜻과 역할이 있는가. 사전분포 선택/추론 방식, 고정 미지값/확률변수, 파라미터 분포/예측분포를 혼동하지 않는가. 큰 그림 토픽은 formal만 있어도 적합하며 억지 비유·교수님 인용을 요구하지 않는다. 구조 검사 통과만으로 의미 품질을 승인하지 않는다.
0a. **결과의 연결**: 이미 구한 결과를 다음 계산에 재사용하는가. 일반 공식의 변수·계수에 이번 문제의 무엇을 대입하는지 보이는가. 핵심 연산(대입·전치·묶기·역행렬)이 생략되지 않았는가. 잊어도 다시 만들 출발 규칙이 남는가. 이 여섯 기능을 무관한 토픽에 강제하거나 같은 표·비유를 장문 반복하지 않는가.
0b. **표기·신뢰**: 수업의 행벡터 미분 관례를 따르고 열벡터 식으로 전환할 때 전치하는가. 임시 기호의 원래 식·역할·차원이 있고 정밀도와 잡음 스케일을 혼동하지 않는가. 수업 공식·동치인 재표현·추가 직관이 해당 문단에서 구별되고, 짧은 재표현은 검산되며 핵심 연결을 펼치기 안에 숨기지 않았는가. 대화의 이해 반응을 독립 풀이 숙달로 기록하지 않는가.
0c. **미분 관례의 전체 경로**: 문제 조건·힌트·참고 풀이·상세 해설·summary/sum·terms·보충·카드/JSON·생성기 소개·MD·PDF가 선택한 관례와 일치하는가. 변수는 열벡터이고 미분 결과만 행벡터인가. 대표 식의 차원·곱 순서·0으로 놓기·양변 전치가 보이는가. 출력×입력 Jacobian과 Hessian 성분 정의가 유지되는가. 보존한 열 관례 원문은 명시적 조건을 존중하고 차이를 설명했는가. 정답 값 일치나 기계 검사 통과만으로 이 검토를 대신하지 않았는가.
1. **사실 오류**: 식, 정의, 부호, 조건(예: "대칭/비대칭", "항상/보통")이 요약·슬라이드·교과서와 맞는가.
2. **누락**: 요약의 핵심 내용·강조 발언·미룬 유도 중 노트에 없는 것.
3. **범위**: "예고만/안 다룸" 내용이 본문에 설명되어 있는가.
4. **ELI5 품질**: 쉽게 말하면(eli5) 레이어가 전문용어 없이 1~3문장인가, 그림이 개념을 실제로 보여 주는가.
5. **문제**: 출처(`Example`/`Exercise` 번호)가 실제 교과서와 맞는가, 수업 범위로 풀 수 있는가, 정답이 `answers.py`와 같은가(직접 다시 계산).
6. **표현**: 표 첫 열이 한 글자씩 줄바꿈되거나 빈 칸이 있는 표, 잘린 문장.
7. **공분산 학습 연결**(레퍼런스 적용 토픽만): 성분별 가중합에서 행렬 규칙으로 연결하는 설명이 있는가. 첫 입력의 계수는 왼쪽, 둘째 입력의 계수는 전치해서 오른쪽에 있는가. 교차/자기 공분산, 행·열 배치와 결과 차원이 정확한가. 이 핸드오프를 수업 출처로 쓰거나 미확인을 무지·설명됨을 숙달로 단정하지 않았는가. 보충 유도가 manifest의 `supp`와 맞고, 예제 때문에 수업 범위나 교과서 기반 문제 범위를 넓히지 않았는가.

출력 형식(이것만):
```
## Critical
- [s2-affine] 문제 → 고칠 내용
## Important
- [p3] …
## Minor
- …
```
각 항목은 토픽/카드 id로 시작한다. 없으면 "없음".

## PDF 연결
PDF 검토: 동봉 EC2 템플릿 bytes/해시, 논리 문제 대응, 정답 데이터 분리, 표 값·그래프 방향, 모든 풀이 li 보존, 전체 페이지 잘림, 노트/MD 링크, 실패 시 공개 파일 보존을 확인한다. lite에서도 메인 에이전트의 PDF 검증은 필수다.
