# 학습자 설명 기준: 대상의 관계와 선택 이유 연결하기

## 근거와 적용 범위

2026-11-06의 1102 노트 학습 대화에서 관찰한 설명 요구를 기록한다. 사용자는 이 대화를 분석해 기존 노트와 앞으로의 `ml-review-pack` 작성에 반영하도록 요청했다. 아래 내용은 학습자에게 설명을 연결하는 기준이며, 수업 범위·공식·교수님 발언의 근거는 STT·강의자료·MML이다.

신규 생성, 기존 설명 수정, lite에서 메인·정리노트 작성자·리뷰어가 전체 읽는다. 일반 원칙 중 현재 토픽의 연결 공백을 메우는 것만 적용한다. 선형대수 사례 전체를 다른 주제에 삽입하지 않는다. 생성 중 사용자에게 지식을 확인하느라 멈추지 않는다.

2026-11-09에는 사용자가 `P⁻¹ = Pᵀ`를 열벡터들의 수직성·길이 1과 연결해 질문하고, 이 연결을 정리노트와 향후 생성에 반영하도록 요청했다. 노트에는 조건과 내적의 1·0이 있었지만, 각 칸의 계산과 그 의미를 연결하는 전개가 압축되어 있었다. 질문과 설명 요청의 증거이며 독립 계산 숙달은 확인하지 않았다.

| “중근이 아닌 단일근들만 가진다 → 무조건 직교?” | 앞 조건을 새로운 경우에 적용할 때 직교 보장의 범위를 질문했다 | 성질을 실제로 적용하는 문장에도 대칭행렬 조건을 붙인다. 조건을 앞 단락에서만 제시하고 일반 명제로 읽히게 두지 않는다 |
| “P-1 = P^T라는건, P의 모든 벡터들이 서로 수직이고, 크기가 1이라는 말이야?” | 압축된 행렬 등식을 열벡터의 조건으로 해석해 확인했다 | 관련 식을 각 칸의 내적으로 펼치고 대각선 1·나머지 0의 의미를 연결한 뒤 전체 등식으로 다시 묶는다. 실수 정방행렬이라는 조건과 동치 방향을 유지한다 |

이 사례는 대상·목적·조건의 연결이 유효한 설명 전략임을 뒷받침한다. 모든 주제에서 같은 설명 순서가 최선이라는 증거는 아니다. ‘시각 학습자’, ‘수학 기초 부족’, ‘고유벡터 숙달’ 같은 고정된 학습자 유형·능력 판정을 만들지 않는다.

## 사영 복습과변형 후 성질 보존의 연결

2026-11-09 후속 대화에서 사용자는 Gram–Schmidt의 계수가 앞선 사영 공식인지 질문했다. 사영 계수·사영 벡터·빼고 남은 벡터를 구별해 연결한 뒤 이해했다고 응답했다. 이어 벡터를 바꿨는데 왜 세 번째 벡터와 수직인지 물었고, 내적의 선형성 설명 뒤에도 “어떤 c에서도” 유지되는 이유를 다시 질문했다. 세 번째 벡터 방향을 새 z축, 나머지 두 벡터가 만드는 공간을 새 xy평면으로 보는 설명을 제공하자 “xy 평면에서 어떤 방향으로 만들더라도 여전히 z 축 벡터에는 수직”이라고 재서술했다. 이는 해당 공간 관계의 재서술 증거이며 독립 계산 숙달이나 고정된 학습자 유형의 증거는 아니다.

- 관련된 이전 개념이 있으면 공식과 위치를 짧게 상기하고, 예전 기호와 현재 기호의 대응·계산 결과의 쓰임을 구별한다. 여기서는 사영 벡터를 구하는 것과 그 벡터를 빼 직교화하는 것의 연결이다.
- 대상이 바뀌어도 성질이 유지된다고 할 때는 허용되는 변화의 범위와 유지되는 이유를 먼저 설명한다. 공간적 설명이 유효하면 익숙한 축·평면에 대응하고 짧은 대수식으로 검증한다. 원래 좌표와 새 좌표, 개념도의 투영과 실제 각도를 구별한다. 모든 주제에 공간 비유를 강제하지 않는다.
- 자유롭게 바꿔도 유지되는 성질과 특정 계수를 골라 추가로 달성하는 조건을 나눈다. 이 예제에서는 모든 c에서 x₃과의 수직성이 유지되고, c=1/2을 골라 x₁과도 수직으로 만든다. 같은 고유공간 안에 머물러 고유벡터 성질도 유지되는 것과 연결하되, 수직성 보존과 고유벡터 보존의 근거를 구별한다.
- 실제 본문을 읽고 “왜 변형해도 유지되는가 / 조절하는 값으로 무엇을 추가로 달성하는가”에 답한다. 결과의 내적이 0이라는 사후 검산만으로 보존 이유까지 설명됐다고 판단하지 않는다. 이미 충분한 연결은 반복하지 않는다.

## 실제로 실패한 설명과 원인

처음 설명은 P가 직교행렬인 경우의 회전·반사와 내적에서 출발했다. 이어서 비스듬한 축으로도 가중합을 만들 수 있다는 예제를 제시했다. 사용자는 계속 ‘축을 새로 정한다면 직교하게 고르면 되지 않는가’를 물었다.

그 시점에 빠진 연결은 **대각화를 위한 P는 A의 고유벡터들을 열로 모은 행렬이며, 고유벡터 조건이 축 선택을 제한한다**는 설명이었다. 이 연결과 고유값·고유벡터의 관계를 설명한 뒤 사용자가 핵심 관계를 재서술했다. 동일 주제의 fresh-context baseline에서도 기존 스킬만으로는 비스듬한 축의 가능성부터 설명하고, 대각화에서의 선택 제약을 빠뜨릴 수 있음을 확인했다.

후속 대화에서는 `Ax = λx`를 열별로 모은 `AP = PD`와 P·D의 구성을 재서술했지만, Gram–Schmidt의 계산에 들어가자 직교화의 뜻부터 설명해 달라고 지적했다. 노트에는 내적을 0으로 놓는 계수 유도와 같은 고윳값 안의 선형결합이 허용되는 이유가 이미 있었다. 빠진 것은 계산 자체가 아니라, 그 조작이 무엇을 바꾸고 무엇을 유지하는지에 대한 본문의 연결이었다. 이어 단일근이면 항상 직교하는지를 물었을 때는 실수 대칭행렬이라는 조건을 적용 지점에서 다시 밝혀야 했다. 설명을 제공한 사실과 사용자가 관계를 재서술한 사실을 기록하며, 독립 계산 숙달로 확대하지 않는다.

설명을 늘리기 전에 현재 독자가 대상을 어떤 것으로 이해하고 있는지 검토한다. 빠진 관계를 연결하지 않은 채 계산·비유·반례를 추가하면 같은 질문이 남을 수 있다.

## 작성 방법

1. **핵심 답과 대상:** 무엇의 관계를 설명하는지 짧게 먼저 말한다. 행렬이면 무엇을 모은 것인지, 분포이면 누구의 분포인지, 계수이면 어디에 쓰는 값인지 밝힌다.
2. **익숙한 연결:** 사용할 기존 개념을 상기하고 새 대상에 대응시킨다. 현재 토픽에 필요하지 않은 기초 정의 전체를 반복하지 않는다. 기존 관계를 행렬·분포 등으로 묶는 새 식이면 무엇을 어떤 단위로 모았는지 짧게 연결한다.
3. **목적과 선택 제약:** ‘무엇이 가능한가’와 ‘이번 목적 때문에 무엇을 골라야 하는가’를 구별한다. 상식적인 대안이 있다면 그 대안으로도 목표가 달성되는지 설명한다.
4. **조건에서 성질로:** 정의에 포함된 조건, 편의를 위해 추가로 선택한 조건, 정리에 의해 보장되는 성질을 구별한다. 단위벡터·직교벡터·독립벡터를 같은 조건으로 취급하지 않는다. 조건부 성질을 새 문단이나 예제에 적용할 때는 필요한 조건을 그 문장에서도 짧게 밝힌다.
5. **최소 예제와 계산:** 빠진 연결을 확인하는 작은 예제 하나를 사용한다. 필요할 때 기존 공식의 대입·연산을 보인다. 계산을 먼저 제시하고 계산 목적을 뒤늦게 붙이지 않는다. 새 방법이 처음 등장하면 입력·출력과 목적, 유지·변경하는 대상을 밝히고 작은 예의 조작에서 실제 공식으로 연결한다. 의미 설명이 없는 방법 이름 뒤에 계산 절차만 나열하지 않는다.
6. **짧은 복원:** 무엇을 모았고, 어떤 조건이 필요하며, 그래서 어느 식을 쓸 수 있는지 다시 만들 수 있게 한다. 본문에 없는 조건을 우측 요약에만 추가하지 않는다.

수식이 성질을 압축해 나타내는 곳에서는 **필요한 부분의 성분·익숙한 연산 → 각 값의 의미 → 전체 식의 조건·역할**을 연결한다. 예를 들어 실수 정방행렬에서 `(PᵀP)ᵢⱼ = pᵢᵀpⱼ`를 보이면 대각선 1은 길이 1, 나머지 0은 수직으로 읽히고 `P⁻¹ = Pᵀ`로 묶인다. 조건을 선언한 문장이 있다는 것만으로 이 연결이 설명됐다고 판단하지 않는다. 짧은 정의나 이미 연결이 충분한 식까지 모두 전개하지 않으며, 같은 예제를 무관한 주제에 복사하지 않는다.

위 항목은 설명 설계 도구다. 모든 토픽에 여섯 소제목이나 고정 분량을 강제하지 않는다. 이미 연결이 명확한 짧은 정의·예고는 필요한 부분만 쓴다. 기존 `big-picture-first.md`의 출발식·대입·재사용 규칙을 대체하지 않는다.

## 선형대수 사례: 자유로운 축 선택과 고유기저 선택

대각화의 목적은 A의 작용을 축별 배율로 표현하는 것이다. 따라서 새 축으로 쓸 벡터는 `Apᵢ = λᵢpᵢ`를 만족해야 한다. pᵢ는 고유벡터이고 λᵢ는 대응하는 배율이다. 독립인 고유벡터 n개를 열로 모으면 P이고, 같은 순서의 배율들을 대각에 모으면 D다.

```text
P = [p₁ … pₙ],  D = diag(λ₁, …, λₙ)
AP = PD
D = P⁻¹AP
```

일반적인 좌표축을 자유롭게 선택하는 것과, 대각화를 위해 고유벡터로 제한하는 것을 구별한다. 예를 들어 `A = [[1,1],[0,2]]`에서는 `A(1,0) = 1·(1,0)`, `A(1,1) = 2·(1,1)`이지만 두 방향은 수직이 아니다. 각 길이를 1로 맞춰도 각도는 변하지 않는다. `(0,1)`을 대신 고르면 직각 좌표계는 되지만 `A(0,1) = (1,2)`이므로 고유벡터 조건을 잃는다.

실수 대칭행렬은 정규직교 고유기저를 선택할 수 있다. 서로 다른 고윳값의 고유벡터는 직교하고, 중근의 고유공간에서는 기저를 직교화한 뒤 정규화할 수 있다. 그러한 P에서는 P⁻¹ = Pᵀ이다. 임의의 기저변환 P에 고유벡터 조건을 요구하거나, 대칭행렬의 임의로 고른 모든 고유벡터들이 자동으로 정규직교한다고 쓰지 않는다.

Gram–Schmidt는 독립인 벡터들이 만드는 공간을 유지하며 서로 수직인 기저로 바꾸는 방법이다. `u=(1,0)`, `v=(1,1)`에서 `u`는 두고 `v`의 `u` 방향 성분을 빼면 `w=(0,1)`이 된다. `w=v-u`, `v=w+u`이므로 두 기저는 같은 평면을 표현한다. 일반적으로 `w=v-cu`에서 `uᵀw=0`을 요구하면 `c=(uᵀv)/(uᵀu)`가 나온다. 사영 성분을 빼 직교화하는 것과 길이로 나눠 정규화하는 것을 구별한다. 고유기저를 유지하려면 같은 고윳값의 고유공간 안에서 적용한다. 대칭행렬의 중근에서도 이미 직교하는 기저를 골랐다면 직교화는 생략한다. 일반 행렬에서 중근이라는 사실만으로 독립인 고유벡터 수를 단정하거나, 서로 다른 고윳값이면 항상 직교한다고 일반화하지 않는다.

좌표 관계는 `x = Pz`, 역변환은 `z = P⁻¹x`다. 정규직교한 정방 P에서는 `z = Pᵀx`로 내적해서 좌표를 읽는다. 일부 축만 남긴 직사각 B에는 일반적인 역행렬이 없으므로 같은 역변환 설명을 그대로 옮기지 않는다.

이 예제는 학습자 연결의 사례다. 관련 수업 범위와 기존 보충 계약을 확인하고 설명용 재구성으로 쓴다. 새 복습문제 카드·PDF에 자동 편입하지 않는다.

## 메인·작성자·리뷰어에 전달할 내용

메인은 `RUN/learning-map.json`의 기존 저작 브리프에 적용 토픽별로 **현재 질문 / 익숙한 연결 / 대상의 구성·역할 / 목적·선택 제약 / 성립 조건 / 짧은 복원 문장** 중 필요한 내용을 적는다. 새 manifest 필드나 필수 HTML 속성은 추가하지 않는다. 관련 연결이 이미 충분한 토픽은 추가 설명 불필요라고 기록한다.

작성자와 리뷰어에게 이 레퍼런스의 필수 읽기 경로 및 해당 토픽의 브리프를 전달한다. 기존 공분산 레퍼런스는 관련 토픽에서 별도로 계속 적용한다. 이 문서가 없거나 읽히지 않으면 일반 작성 규칙으로 진행하고 참고 누락을 보고한다.

검토자는 실제 본문과 요약을 읽고 다음에 답한다.

- 독자가 각 기호가 무엇으로 구성되며 어떤 역할인지 말할 수 있는가?
- 조건·예외를 선언하기 전에 그 조건을 요구하는 대상과 목적이 연결되는가?
- 독자가 생각할 법한 자연스러운 대안에 대해 이번 목표와의 관계를 설명하는가?
- 일반적인 가능성과 이번 목적의 제약, 정의와 추가 조건, 보장과 선택을 구별하는가?
- 처음 등장하는 방법은 계산 전에 무엇을 바꾸고 유지하는지 설명하며, 작은 예의 조작에서 실제 계산으로 이어지는가?
- 조건부 성질은 적용 문장과 본문 요약에서도 성립 조건을 유지하는가?
- 압축된 식에서 필요한 성분·내적 등의 연산을 펼쳐 각 값의 의미와 전체 조건을 읽을 수 있는가? 선언 문장만 있거나 핵심 연결이 펼치기 안에 숨지 않았는가?
- 작은 예제는 빠진 관계를 확인하며, 같은 설명을 장문으로 반복하지 않는가?
- 질문·이해 반응·설명 제공·독립 수행의 증거를 구분했는가?

검사 단어가 있다는 사실만으로 통과시키지 않는다. 적용 토픽·사용한 연결·미해결을 보고한다. 관련 없는 주제에는 선형대수 사례를 복사하지 않는다.
