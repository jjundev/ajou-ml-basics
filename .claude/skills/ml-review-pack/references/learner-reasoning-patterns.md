# 학습자 설명 기준: 대상의 관계와 선택 이유 연결하기

## 근거와 적용 범위

2026-11-06의 1102 노트 학습 대화에서 관찰한 설명 요구를 기록한다. 사용자는 이 대화를 분석해 기존 노트와 앞으로의 `ml-review-pack` 작성에 반영하도록 요청했다. 아래 내용은 학습자에게 설명을 연결하는 기준이며, 수업 범위·공식·교수님 발언의 근거는 STT·강의자료·MML이다.

신규 생성, 기존 설명 수정, lite에서 메인·정리노트 작성자·리뷰어가 전체 읽는다. 일반 원칙 중 현재 토픽의 연결 공백을 메우는 것만 적용한다. 선형대수 사례 전체를 다른 주제에 삽입하지 않는다. 생성 중 사용자에게 지식을 확인하느라 멈추지 않는다.

## 관찰한 사실과 설명 전략

| 대화 근거 | 관찰한 사실 | 작성 시 적용할 전략 |
|---|---|---|
| “우리가 방향벡터로 쓰는 x̂, ŷ들이 이런 거야?” | 새 개념을 익숙한 대상에 대응시켰다 | 익숙한 대상과 새 대상이 무엇을 공유하고 무엇이 다른지 밝힌다 |
| “새로운 단위벡터의 가중합으로 표현하기 위해서 P를 사용” | P를 가중합과 좌표 표현의 역할로 해석했다 | 기호의 뜻에 더해 구성 요소와 실제 역할을 연결한다 |
| “새로운 축을 만드는 거면 당연히 직교하는 벡터들로” | 자유롭게 고르는 축이라고 이해한 상태에서 선택 이유를 물었다 | 무엇을 달성하려 하며 어떤 조건이 선택을 제한하는지 먼저 설명한다 |
| “고유벡터랑 고유값은 무슨 관계이지?” | 앞 설명에 필요한 선행 관계를 질문했다 | 현재 설명에 필요한 선행 관계를 짧게 상기한다. 이해 실패를 계산 능력 부족으로 판정하지 않는다 |
| “그 고유벡터들을 모아놓은 게 P…반드시 직교…보장이 없다” | 고유벡터·P·직교성의 관계를 직접 재서술했다 | 핵심 관계를 짧게 복원할 수 있는 설명으로 마친다. 독립 풀이 숙달은 미확인이다 |

이 사례는 대상·목적·조건의 연결이 유효한 설명 전략임을 뒷받침한다. 모든 주제에서 같은 설명 순서가 최선이라는 증거는 아니다. ‘시각 학습자’, ‘수학 기초 부족’, ‘고유벡터 숙달’ 같은 고정된 학습자 유형·능력 판정을 만들지 않는다.

## 실제로 실패한 설명과 원인

처음 설명은 P가 직교행렬인 경우의 회전·반사와 내적에서 출발했다. 이어서 비스듬한 축으로도 가중합을 만들 수 있다는 예제를 제시했다. 사용자는 계속 ‘축을 새로 정한다면 직교하게 고르면 되지 않는가’를 물었다.

그 시점에 빠진 연결은 **대각화를 위한 P는 A의 고유벡터들을 열로 모은 행렬이며, 고유벡터 조건이 축 선택을 제한한다**는 설명이었다. 이 연결과 고유값·고유벡터의 관계를 설명한 뒤 사용자가 핵심 관계를 재서술했다. 동일 주제의 fresh-context baseline에서도 기존 스킬만으로는 비스듬한 축의 가능성부터 설명하고, 대각화에서의 선택 제약을 빠뜨릴 수 있음을 확인했다.

설명을 늘리기 전에 현재 독자가 대상을 어떤 것으로 이해하고 있는지 검토한다. 빠진 관계를 연결하지 않은 채 계산·비유·반례를 추가하면 같은 질문이 남을 수 있다.

## 작성 방법

1. **핵심 답과 대상:** 무엇의 관계를 설명하는지 짧게 먼저 말한다. 행렬이면 무엇을 모은 것인지, 분포이면 누구의 분포인지, 계수이면 어디에 쓰는 값인지 밝힌다.
2. **익숙한 연결:** 사용할 기존 개념을 상기하고 새 대상에 대응시킨다. 현재 토픽에 필요하지 않은 기초 정의 전체를 반복하지 않는다.
3. **목적과 선택 제약:** ‘무엇이 가능한가’와 ‘이번 목적 때문에 무엇을 골라야 하는가’를 구별한다. 상식적인 대안이 있다면 그 대안으로도 목표가 달성되는지 설명한다.
4. **조건에서 성질로:** 정의에 포함된 조건, 편의를 위해 추가로 선택한 조건, 정리에 의해 보장되는 성질을 구별한다. 단위벡터·직교벡터·독립벡터를 같은 조건으로 취급하지 않는다.
5. **최소 예제와 계산:** 빠진 연결을 확인하는 작은 예제 하나를 사용한다. 필요할 때 기존 공식의 대입·연산을 보인다. 계산을 먼저 제시하고 계산 목적을 뒤늦게 붙이지 않는다.
6. **짧은 복원:** 무엇을 모았고, 어떤 조건이 필요하며, 그래서 어느 식을 쓸 수 있는지 다시 만들 수 있게 한다. 본문에 없는 조건을 우측 요약에만 추가하지 않는다.

위 항목은 설명 설계 도구다. 모든 토픽에 여섯 소제목이나 고정 분량을 강제하지 않는다. 이미 연결이 명확한 짧은 정의·예고는 필요한 부분만 쓴다. 기존 `big-picture-first.md`의 출발식·대입·재사용 규칙을 대체하지 않는다.

## 선형대수 사례: 자유로운 축 선택과 고유기저 선택

대각화의 목적은 A의 작용을 축별 배율로 표현하는 것이다. 따라서 새 축으로 쓸 벡터는 `Apᵢ = λᵢpᵢ`를 만족해야 한다. pᵢ는 고유벡터이고 λᵢ는 대응하는 배율이다. 독립인 고유벡터 n개를 열로 모으면 P이고, 같은 순서의 배율들을 대각에 모으면 D다.

```text
P = [p₁ … pₙ],  D = diag(λ₁, …, λₙ)
AP = PD
D = P⁻¹AP
```

일반적인 좌표축을 자유롭게 선택하는 것과, 대각화를 위해 고유벡터로 제한하는 것을 구별한다. 예를 들어 `A = [[1,1],[0,2]]`에서는 `A(1,0) = 1·(1,0)`, `A(1,1) = 2·(1,1)`이지만 두 방향은 수직이 아니다. 각 길이를 1로 맞춰도 각도는 변하지 않는다. `(0,1)`을 대신 고르면 직각 좌표계는 되지만 `A(0,1) = (1,2)`이므로 고유벡터 조건을 잃는다.

실수 대칭행렬은 정규직교 고유기저를 선택할 수 있다. 서로 다른 고윳값의 고유벡터는 직교하고, 중근의 고유공간에서는 기저를 직교화한 뒤 정규화할 수 있다. 그러한 P에서는 P⁻¹ = Pᵀ이다. 임의의 기저변환 P에 고유벡터 조건을 요구하거나, 대칭행렬의 임의로 고른 모든 고유벡터들이 자동으로 정규직교한다고 쓰지 않는다.

좌표 관계는 `x = Pz`, 역변환은 `z = P⁻¹x`다. 정규직교한 정방 P에서는 `z = Pᵀx`로 내적해서 좌표를 읽는다. 일부 축만 남긴 직사각 B에는 일반적인 역행렬이 없으므로 같은 역변환 설명을 그대로 옮기지 않는다.

이 예제는 학습자 연결의 사례다. 관련 수업 범위와 기존 보충 계약을 확인하고 설명용 재구성으로 쓴다. 새 복습문제 카드·PDF에 자동 편입하지 않는다.

## 메인·작성자·리뷰어에 전달할 내용

메인은 `RUN/learning-map.json`의 기존 저작 브리프에 적용 토픽별로 **현재 질문 / 익숙한 연결 / 대상의 구성·역할 / 목적·선택 제약 / 성립 조건 / 짧은 복원 문장** 중 필요한 내용을 적는다. 새 manifest 필드나 필수 HTML 속성은 추가하지 않는다. 관련 연결이 이미 충분한 토픽은 추가 설명 불필요라고 기록한다.

작성자와 리뷰어에게 이 레퍼런스의 필수 읽기 경로 및 해당 토픽의 브리프를 전달한다. 기존 공분산 레퍼런스는 관련 토픽에서 별도로 계속 적용한다. 이 문서가 없거나 읽히지 않으면 일반 작성 규칙으로 진행하고 참고 누락을 보고한다.

검토자는 실제 본문과 요약을 읽고 다음에 답한다.

- 독자가 각 기호가 무엇으로 구성되며 어떤 역할인지 말할 수 있는가?
- 조건·예외를 선언하기 전에 그 조건을 요구하는 대상과 목적이 연결되는가?
- 독자가 생각할 법한 자연스러운 대안에 대해 이번 목표와의 관계를 설명하는가?
- 일반적인 가능성과 이번 목적의 제약, 정의와 추가 조건, 보장과 선택을 구별하는가?
- 작은 예제는 빠진 관계를 확인하며, 같은 설명을 장문으로 반복하지 않는가?
- 질문·이해 반응·설명 제공·독립 수행의 증거를 구분했는가?

검사 단어가 있다는 사실만으로 통과시키지 않는다. 적용 토픽·사용한 연결·미해결을 보고한다. 관련 없는 주제에는 선형대수 사례를 복사하지 않는다.
